# game-cairn 버전 기록

버전 하나(`VERSION` 파일)가 기준이다. 올릴 때는 `python tools/bump_version.py 0.15.0 "한 줄 요약"` —
`VERSION` · `play.html` · `index.html` 의 버전 글자와 이 문서 맨 위 줄을 한 번에 고친다.

- 부 번호(0.x.0): 기능이 늘거나 바뀜. 수 번호(0.x.y): 고침만
- 커밋 제목은 `cairn v0.x.y: …`
- 화면 머리줄에 `화면 v… · 서버 v…` — 둘이 다르면 노란 알림 (서버 재시작이나 새로고침이 필요하다는 뜻)
