  - 세이브 굴리기 · 피해 계산(HP→STR→치명 세이브) 체험 버튼 2개 넣음. 다크 모드 대응.
- [x] `index.html` 대분류 탭 둘: **시스템 요약** · **시나리오 · 블러드 올름** (해시 `#system` · `#scenario`, 소분류 바로가기 각각)
  - 시나리오: 의뢰 · 배경 · 지도 · 방 · NPC · 유물 · 진상 · 워든 원칙. 방 내용 · 능력치 · 진상은 스포일러라 접힌 '워든 전용' 칸에 넣음.
- [x] 세션 진행 기록 `docs/세션_로그.md` (모의 플레이 1회차)
- [x] 루트 `index.html` 목록에 Cairn 링크 카드 추가
- [x] **플레이 블러드 올름** — `index.html` 대분류 탭(누르면 `play.html` 로) + 새 페이지 `play.html`
  - 입장 비밀번호 `12341234` — 서버 `server/cairn.pass` 에만 둠 (커밋 안 함, 없으면 서버가 만든다). 틀리면 403, IP당 1분 6번까지
  - 접속자마다 무작위 색 (이미 있는 색과 색상환에서 가장 먼 쪽). 접속자 목록 · 입장/퇴장 알림
  - 채팅은 HTTP 스트리밍 (`GET /api/stream` NDJSON + `POST /api/send`) — llm-graphic-mud 와 같은 이유로 WebSocket 대신 (ngrok 무료판)
  - `마스터에게` 체크(기본 켬)한 말만 워든이 답한다. 끄면 잡담 — 워든은 다음 차례에 맥락으로만 읽음
  - 워든이 말하는 중에 온 말은 모아 두었다가 끝나면 한 번에 넘긴다
  - 주사위는 워든이 `roll_dice` 도구로 서버에서 굴리고 방 전체에 보인다 (결과를 지어내지 못하게)
  - 기록은 `server/state.json` (커밋 안 함) — 서버를 껐다 켜도, 새로고침해도 이어짐. `/새게임` 으로 처음부터
  - 서버 `server/cairn_server.py` (127.0.0.1:8790, 표준 라이브러리 + `anthropic` SDK), `server/start.ps1` 로 ngrok 까지
  - 서버 주소로 바로 들어가도 `play.html` 이 뜬다. GitHub Pages 에서 열면 '서버 주소' 칸 (기본값: mud 와 같은 ngrok 도메인)
  - 확인: 흉내 워든(키 없음)으로 브라우저 1 + 스크립트 1 접속 — 색 구별 · 잡담/행동 구분 · 주사위 · 글자 흘려 받기 · 새로고침 후 기록 복원
- [x] 워든 두뇌 둘 — **OpenRouter `google/gemini-2.5-flash-lite` (기본)** · Claude `claude-opus-5-5`
  - 고르기: 환경변수 `CAIRN_PROVIDER=openrouter|claude`, OpenRouter 모델은 `CAIRN_OR_MODEL` 로 바꿈
  - 키: `OPENROUTER_API_KEY` / `ANTHROPIC_API_KEY` — setx 로 넣은 Windows 사용자 환경변수를 서버가 직접 읽음 (먼저 떠 있던 프로세스에서 켜도 됨). 또는 `server/openrouter.key` · `server/anthropic.key`
  - 두뇌마다 대화 기록을 따로 둠 (`state.json` 의 `or_messages` · `messages`) — 바꾸면 워든은 처음 보는 셈
  - OpenRouter 는 표준 라이브러리로 SSE 스트림 직접 읽음, 주사위는 같은 `roll_dice` 도구(function calling)
  - 지시문에 룰 원문 p.8–59 (캐릭터 만들기 · 배경 20종 표 · 본드 · 오멘) 추가 — 처음엔 배경 장비를 지어냄(뱃사공에 쇠뇌) → 넣은 뒤 표대로 (궁수 Wych Elm 활 · 톱니 칼 …) 확인
  - 한 차례 도구 반복 한도 8 → 30 (캐릭터 생성 중 끊겼음). 같은 때 굴릴 주사위는 한 번에 여러 개 부르게 지시 → 특성 8개를 한 번에 굴림 확인
  - 빈 워든 말풍선(공백만 온 조각) 안 만들게. `/새게임` 은 모든 화면 기록도 비움 (`reset`)
  - 확인: Gemini 로 캐릭터 생성 → 동료 NPC → 의뢰 전달까지 한 차례에 진행, 주사위 전부 서버에서 굴림
- [ ] Claude 두뇌 실제 응답 확인 — Anthropic API 크레딧 부족(400)으로 못 함. 요청 · 키 인증까지는 닿음
- [x] 캐릭터 그림 — 캐릭터 생성이 끝나면 워든이 설정값(배경 · 외모 특성 · 장비)대로 그림을 그려 방에 띄운다
  - OpenRouter 이미지 모델 `google/gemini-3.1-flash-lite-image` (장당 약 $0.034, 6–10초). `CAIRN_IMG_MODEL` 로 바꿈
  - 워든 도구 `draw_character {name, prompt(영어 외모), caption}` — PC · 동료 NPC 마다 한 번. 두뇌가 Claude 여도 그림은 OpenRouter 키로
  - 화풍 문구(옛 TRPG 책 잉크 · 담채, 전신, 양피지 배경, 글자 없음)는 서버가 앞에 붙임. 세로 3:4 (`image_config.aspect_ratio`) → 896×1200 확인
  - 그림은 `server/images/` (커밋 안 함), `GET /img/<파일>` 로. 화면은 헤더를 붙여 fetch → blob 으로 띄움 (ngrok 경고 페이지 때문에 `<img src>` 직접은 안 됨). 누르면 크게
  - 확인: 실제 플레이(조건희, 장의사 31세)에서 생성 끝에 그림 자동 — 결과의 장의사 마차 · 당나귀까지 그려짐
- [x] 캐릭터 시트 UI — 생성된 그림 등록 · 능력치 · HP · 짐(칸) · 상태 표시, 진행 중 수치 · 아이템이 바뀌면 바로 반영
  - 워든 도구 `update_character` — 처음엔 시트 전부, 그 뒤엔 바뀐 칸만 (hp/str/dex/wil + 최대, armor, gp, fatigue, items 통째 · add_items · remove_items, conditions, traits, bond). 서버가 `state.json` 의 `chars` 에 보관, 바뀔 때마다 `{"type":"chars"}` 방송
  - 그림: `draw_character` 가 같은 이름 시트에 붙임. 시트를 나중에 만들어도 기록의 그림을 찾아 붙임
  - 화면: 넓으면 오른쪽 열, 760px 아래는 머리줄 `시트` 버튼으로 서랍. 막대(HP · STR · DEX · WIL, 최대보다 낮으면 빨간 숫자), 갑옷 · gp · 피로 · 상태 칩, 짐 n/10칸(10칸이면 'HP 0'), 아이템 목록(petty · bulky 표시), 외모 · 본드. 바뀐 칸은 잠깐 반짝임. 사망 상태면 흑백
  - 짐 칸 = 아이템 칸 합 + 피로. 10칸 이상이면 도구 결과로 워든에게 'HP 0 (룰)' 알림
  - Gemini 스키마 호환: `$ref` 대신 인라인, `additionalProperties` 는 안쪽까지 뺌
  - Gemini Flash Lite 가 가끔 도구 호출을 글로 흘림(`<ctrl46>` …) → 감지하면 그 말풍선을 화면에서 지우고(`gm_retract`) 두 번까지 다시 부름
  - 남은 흠: Flash Lite 가 처음 등록 때 DEX · 식량 · 광원을 빠뜨리기도 함 → 도구 설명에 '넷 다, 시작 장비 전부' 명시 (명시 뒤 재확인은 안 함)
  - 확인: 시험 서버(`--port 8791 --state state_test.json`, launch `cairn-test`)에서 힐다 · 렌 시트 등록, DEX 추가 반영, 그림 붙음, 폰 폭 서랍
