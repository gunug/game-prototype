  - 기록은 `server/state.json` (커밋 안 함) — 서버를 껐다 켜도, 새로고침해도 이어짐. `/새게임` 으로 처음부터

  - 서버 주소로 바로 들어가도 `play.html` 이 뜬다. GitHub Pages 에서 열면 '서버 주소' 칸 (기본값: mud 와 같은 ngrok 도메인)
  - 확인: 흉내 워든(키 없음)으로 브라우저 1 + 스크립트 1 접속 — 색 구별 · 잡담/행동 구분 · 주사위 · 글자 흘려 받기 · 새로고침 후 기록 복원
