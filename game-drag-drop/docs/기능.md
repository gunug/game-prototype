# 드래그 드롭

주어진 조각을 판에 끌어다 놓아 칸을 전부 채우는 퍼즐. **회전이 없다.**
조각은 서랍에 나온 그대로 놓아야 한다.

# 화면구성
- [x] 스테이지 고르는 페이지와 푸는 페이지를 나눈다
  - 한 파일 안에서 두 화면을 `hidden` 으로 갈아 끼운다. 페이지 이동이 없어 상태가 유지된다
- [x] 격자는 가로 10칸 세로 10칸. 화면 크기에 맞춰 리사이즈
  - 칸 크기는 (min(가용 너비, 가용 높이) - 16) / 10 을 내림한 정수 px
  - 상단 바와 하단 서랍을 뺀 나머지가 가용 영역
- [x] 하단에 조각 서랍. 아직 안 놓은 조각을 늘어놓는다
  - 조각이 많으면 가로로 스크롤한다. 최소 높이 84px
- [x] 클리어하면 다음 스테이지로 넘어가는 버튼이 뜬다
  - 마지막 스테이지면 `스테이지 목록 →` 으로 바뀐다

# 용어
## 필드
- [x] 조각을 놓을 수 있는 공간. 활성 칸만 채운다
- [x] 필드 외곽에 흰색 글로우 라인
  - 칸마다 테두리를 그리면 모서리가 겹쳐서, 필드와 바깥이 맞닿는 변만 모아
    격자 위에 svg path 한 겹으로 얹는다

## 조각
- [x] 서랍에 놓인 순서대로 늘어놓는다. 회전은 없다
  - 회전이 없으니 조각은 "모양" 이 아니라 "방향까지 정해진 모양" 이다.
    같은 L 라도 돌린 것은 서로 다른 조각으로 친다
  - 서랍 순서는 생성기가 섞는다. 놓은 순서 그대로 두면 답이 새어 나간다
- [x] 조각마다 색이 하나씩 배정된다
  - 황금각(137.5도)으로 색상환을 돌아 이웃한 조각끼리 안 겹치게 한다

# 조작
- [x] 서랍의 조각을 끌어 판에 놓는다
  - 쥔 칸이 포인터 밑에 오도록 붙는다. 조각 밖을 쥐면 가장 가까운 칸으로 당겨 잡는다
    (모양을 정규화해도 (0,0) 이 비어 있을 수 있다. S4 가 그렇다)
- [x] 끄는 동안 놓일 자리를 미리 보여 준다. 못 놓는 자리면 빨갛게
  - 판 위에 걸쳐 있을 때만 빨갛게 표시한다. 서랍 위에서는 아무 표시도 안 한다
- [x] 판에 놓인 조각을 끌면 다시 집어 올린다
- [x] 판에 놓인 조각을 그 자리에서 떼면 서랍으로 돌아간다
  - 못 놓는 자리에서 떼도 서랍으로 돌아간다. 되돌리기가 따로 필요 없다
- [x] `지우기` 는 놓인 조각을 전부 서랍으로 되돌린다
  - 클리어한 판에서는 안 먹는다. 다 맞춘 것을 실수로 날리지 않게
- [x] 포인터는 컨테이너(서랍/격자)에 잡아 둔다
  - 잡는 대상을 자식이 아니라 컨테이너로 두어야, 조각을 놓아 서랍을 다시
    그려도 잡은 것이 안 풀린다. 손가락이 영역 밖으로 나가도 이벤트가 계속 온다

# 클리어 조건
- [x] 필드의 모든 칸이 조각으로 덮이면 클리어
  - 조각을 전부 놓으면 곧 필드가 꽉 찬 것이다. 칸 수가 정확히 맞게 만들었으므로

# 스테이지
- [x] 5개. `tools/generate.py` 가 미리 만들어 굽는다
  - 필드를 먼저 만들고 맞는 조각을 찾는 게 아니라, **조각을 실제로 이어 붙여
    필드를 만든다.** 놓은 자리가 그대로 답이라 풀리는 게 보장된다
  - 조밀도는 후보를 수백 개 뽑아 순위에서 고른다. 가장 뭉툭한 것만 뽑으면
    스테이지마다 비슷한 덩어리가 되고, 가장 사나운 것을 뽑으면 폭 1칸짜리
    촉수가 뻗어 나와 보기에도 풀기에도 나쁘다
  - CP-SAT 은 해를 세는 데만 쓴다. 똑같이 생긴 조각은 서로 바꿔 놔도 같은
    그림이라, 조각별이 아니라 모양별 개수로 모델을 세운다

    | 스테이지 | 조각 | 칸 | 해 |
    |---|---|---|---|
    | 첫 걸음 | 5 | 20 | 1 |
    | 네 칸 | 7 | 28 | 1 |
    | 섞기 | 9 | 35 | 1 |
    | 펜토미노 | 11 | 55 | 1 |
    | 한 판 가득 | 13 | 58 | 1 |

  - `python tools/generate.py --apply` 가 index.html 의 STAGES 까지 갱신한다
- [x] 클리어한 스테이지는 체크 표시하고 LocalStorage 에 저장한다
  - 키(`drag-drop.cleared`)에 넣는 id 는 번호가 아니라 이름과 필드로 매긴다.
    번호로 매기면 스테이지를 하나 끼워 넣을 때 기록이 통째로 밀린다
  - 클리어한 카드는 반투명하게 두고 숨기거나 잠그지 않는다. 다시 풀 수 있다

# 검사
- [x] `node tools/smoke.mjs` — DOM 을 흉내내고 index.html 을 끝까지 실행한다
  - 드래그도 흉내낸다. 판 칸 크기를 알고 있으니 좌표를 만들어
    pointerdown → pointermove → pointerup 을 그대로 쏜다
  - 1스테이지를 직접 되풀어 답을 찾고, 그 답대로 끌어다 놓아 클리어까지 확인한다
  - `generate.py --apply` 가 스테이지 블록을 갈아치우면서 그 안의 `readField`
    까지 날릴 수 있다. 파싱은 통과하므로 스모크로 막는다
  - 조상 없는 `.foo{position:absolute}` 같은 전역 규칙이 카드가 쓰는 클래스와
    겹치는지 CSS 를 훑어 확인한다
