# llm-graphic-mud 기능

로컬 Ollama(`qwen3:8b`)를 진행자로 쓰는 그래픽 머드 프로토타입.

## 기능 목록

- [x] `index.html` 페이지 — 제목만 표기
  - 프로젝트 폴더는 `game-prototype/llm-graphic-mud` (repo 안). 루트 `index.html` 에 링크 버튼 추가.
- [x] 로컬 프록시 + ngrok — GitHub Pages 프론트가 내 PC의 Ollama · ComfyUI 를 쓰게
  - 프록시 `server/proxy.py` (파이썬 표준 라이브러리만), 127.0.0.1:8787
  - 키 확인 (`X-Proxy-Key` 헤더), 키는 `server/proxy.key` 에 두고 커밋 안 함
  - 허용 경로만 통과: Ollama `/ollama/api/chat` · `/ollama/api/tags`, ComfyUI `/comfy/prompt` · `/comfy/history/<id>` · `/comfy/view` · `/comfy/queue`
  - CORS: `https://game.onethelab.com` · localhost 만
  - 분당 요청 수 제한
  - `server/start.ps1` 로 프록시 + ngrok 한 번에 실행. 고정 주소는 `$env:NGROK_DOMAIN`
  - 프론트는 요청마다 `ngrok-skip-browser-warning: 1` 헤더를 붙인다 — 안 붙이면 ngrok 경고 HTML 이 온다 (확인함)
  - 분당 120회 · 본문 4MB · ComfyUI `/view` 는 `output` · `temp` 만, `..` 막음 (스펙에 없던 기본값)
  - 업스트림엔 Origin 을 넘기지 않음 → `OLLAMA_ORIGINS` 설정 불필요
- [x] 연결 테스트 화면 (`index.html`)
  - 프록시 주소 · 키 입력 칸, 브라우저(localStorage)에만 저장
  - Ollama 테스트 버튼 — 짧은 질문 보내고 답 표시
  - ComfyUI 테스트 버튼 — 대기열 상태 표시
  - 프록시 허용 출처에 `localhost:8765` 추가 — repo 루트 개발 서버 포트
- [x] 키 저장 버튼
  - 키는 `저장` 버튼을 눌러야만 localStorage 에 저장 (칸 밖 클릭으로는 저장 안 함)
  - 저장 안 된 변경이 있으면 칸 옆에 `저장되지 않음` 표시, 페이지를 나가려 하면 브라우저 경고
  - Enter 도 저장. 나갈 때 경고 문구는 브라우저 자체 문구로 뜬다 (요즘 브라우저는 페이지 글을 안 씀)
- [x] 키 복사 버튼
  - `저장` 옆 `복사` 버튼 — 키 칸의 지금 값을 클립보드로
  - 클립보드 API 가 막히면 (창 포커스 없음 등) `execCommand("copy")` 로 대신 복사
- [x] 캐릭터 생성 버튼
  - Ollama(`qwen3:8b`)가 새 캐릭터 이름 · 한 줄 소개 · 영문 이미지 프롬프트를 JSON 으로 만든다
  - 그 프롬프트로 ComfyUI z-image turbo 워크플로(`image_z_image_turbo.json` 과 같은 노드 구성)를 돌린다
  - `/comfy/history/<id>` 를 1초마다 확인, 끝나면 `/comfy/view` 로 그림을 받아 화면에 표시
  - 기다리는 동안 로딩바 + 단계 글 (프롬프트 만드는 중 → 그림 그리는 중)
  - 720×1280 · 8 step · cfg 1 (템플릿 기본값, 저장된 워크플로의 cfg 2 대신) · 결과는 ComfyUI `output/llm-mud/char_*.png`
  - 걸린 시간: 첫 실행 97초 (모델 로딩), 다음부터 약 25초. GPU 24GB 를 Ollama 와 나눠 써서 빠듯함
- [ ] 소켓 채팅창 (프록시 HTTP 스트리밍)
  - 처음엔 WebSocket 으로 만들었으나 ngrok 무료판 경고 페이지가 WebSocket 연결을 가로챔 (브라우저 WebSocket 은 우회 헤더를 못 붙임, 확인함) → HTTP 스트리밍으로 바꿈 (사용자 선택)
  - 받기: `GET /chat/stream` 길게 열린 NDJSON 응답 (fetch 로 읽음, 20초마다 ping). 보내기: `POST /chat/send` — `server/chat_hub.py`
  - 왼쪽: 온라인 채팅 — 접속한 사람 모두에게 방송, 닉네임, 접속자 목록, 최근 50줄 기록(메모리)
  - 오른쪽: Ollama 대화 — 시스템 프롬프트 칸 + 대화, 답은 글자 단위로 흘려 받음(스트리밍), 나만 보임
  - 오른쪽 입력에서 `/system <글>` 로 시스템 프롬프트 바꾸기, `/reset` 으로 대화 지우기
