# llm-graphic-mud 기능

로컬 Ollama(`qwen3:8b`)를 진행자로 쓰는 그래픽 머드 프로토타입.

## 기능 목록

- [x] `index.html` 페이지 — 제목만 표기
  - 프로젝트 폴더는 `game-prototype/llm-graphic-mud` (repo 안). 루트 `index.html` 에 링크 버튼 추가.
- [x] 로컬 프록시 + ngrok — GitHub Pages 프론트가 내 PC의 Ollama · ComfyUI 를 쓰게
  - 프록시 `server/proxy.py` (파이썬 표준 라이브러리만), 127.0.0.1:8787
  - 키 확인 (`X-Proxy-Key` 헤더), 키는 `server/proxy.key` 에 두고 커밋 안 함
  - 허용 경로만 통과: Ollama `/ollama/api/chat` · `/ollama/api/tags`, ComfyUI `/comfy/prompt` · `/comfy/history/<id>` · `/comfy/view` · `/comfy/queue`
  - CORS: `https://game.onethelab.com` · localhost 만
  - 분당 요청 수 제한
  - `server/start.ps1` 로 프록시 + ngrok 한 번에 실행. 고정 주소는 `$env:NGROK_DOMAIN`
  - 프론트는 요청마다 `ngrok-skip-browser-warning: 1` 헤더를 붙인다 — 안 붙이면 ngrok 경고 HTML 이 온다 (확인함)
  - 분당 120회 · 본문 4MB · ComfyUI `/view` 는 `output` · `temp` 만, `..` 막음 (스펙에 없던 기본값)
  - 업스트림엔 Origin 을 넘기지 않음 → `OLLAMA_ORIGINS` 설정 불필요
