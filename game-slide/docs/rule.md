# 필드
- [x] 기본 10*10 필드
## 외부
- [x] 외부 상하좌우 2줄은 플레이어가 갈수없는 영역.
  - 각 변마다 2줄. 좌표 0,1 과 8,9. 외부는 64칸
  - 못 가는 것은 플레이어뿐이다. 몬스터는 외부·내부를 다 다닌다
  - 외부는 적이 어디서 나오는지만 보여 주면 되므로 화면에서는 내부 칸의
    1/3 크기로 그린다. 칸 수·좌표·이동·스폰은 그대로다
## 내부
- [x] 내부 6*6 필드는 플레이어가 갈수있는 영역.
  - 격자 좌표 2~7. 플레이어는 가운데(4,4)에서 시작한다

# 몬스터
## 기본규칙
- [x] 외부 필드에서 랜덤한 위치에 생성됨
  - 생성 시점이 규칙에 없어서: 시작할 때 3마리, 이후 플레이어가 실제로
    움직일 때마다 1마리씩 늘린다
  - 이미 차있는 칸은 피한다. 외부에 빈 칸이 없으면 안 나온다
- [x] 몬스터는 서로 겹치지 않음, 이동불가시(필드 막힘) 이동하지 않음
  - 플레이어 칸도 못 밟는다. 전투 규칙이 아직 없어서 겹칠 수가 없다
  - 한 턴에 한 마리씩 차례로 옮긴다. 앞 마리가 비운 칸은 뒷 마리가 쓸 수 있다
## 종류
### 블로커
- [ ] 체력개념이 없음, 공격및 피격할수 없음
- [ ] 블로커가 있는 지역에 이동할 수 없음
- [ ] 그래픽 객체를 다양하게 사용
### 고블린
- [ ] 최대채력 100
- [ ] 민첩 100
- [x] 고블린은 상,하,좌,우 한칸씩 이동한다
  - 대각선은 없다. 한 턴에 한 칸
- [x] 매 턴 플레이어를 향해 이동한다.
  - 플레이어가 실제로 움직인 턴에만 움직인다. 벽·몬스터에 막혀 턴이
    안 넘어가면 고블린도 가만히 있는다
  - 차이가 큰 축을 먼저 시도하고, 막혔으면 다른 축으로 돈다.
    둘 다 막히면 그 자리에 선다
  - 가로세로 차이가 같을 때 어느 쪽을 먼저 볼지가 규칙에 없어서 가로로 정했다
  - 길찾기는 없다. 벽을 끼고 도는 식으로 돌아가지는 못한다
- [x] 플레이어에 4방향에서 인접한 고블린은 공격을 한다.
  - 공격 페이즈에 판정한다. 이동 페이즈에 붙은 놈도 그 턴에 바로 때린다
  - 대각선은 인접이 아니다
  - 붙은 마릿수만큼 각각 때린다. 세 마리가 붙으면 한 턴에 3 깎인다
  - 플레이어 체력이 0이 되면 입력을 막고 `쓰러졌다` 를 띄운다.
    승패 규칙이 아직 없어서 정한 것이다
### 고블린라이더
- [x] 체스의 나이트 처럼 움직인다.
  - 여덟 방향 L 자. 사이에 무엇이 있든 뛰어넘는다
  - 여덟 칸이 다 막혔으면 그 자리에 선다
- [x] 매 턴 플레이어와 인접할 수 있도록 이동한다.
  - 갈 수 있는 여덟 칸 중 "플레이어와의 거리 1" 에 가장 가까운 칸을 고른다
  - 점수가 같으면 정해 둔 차례에서 먼저 나온 칸을 쓴다 (규칙에 없어서 정한 것)
  - 나이트 이동은 `x+y` 의 홀짝을 매번 뒤집는다. 그래서 플레이어와의 거리가
    홀수인 자리에서는 한 수로 인접이 될 수 없다. 규칙의 한계지 버그가 아니다
- [x] 플레이어에 인접한 고블린 라이더는 공격을 한다.
  - 고블린과 같다. 붙어 있으면 때리고 그 턴에는 안 움직인다
- 스텟은 규칙에 없어서 정했다. 체력 3, 공격력 1, 민첩 9
  (말을 탔으니 걸어오는 고블린 8 보다는 빠르고, 플레이어 10 보다는 느리다)
- 스폰 비율도 규칙에 없어서 정했다. 새로 나오는 몬스터의 1/4 이 라이더다
