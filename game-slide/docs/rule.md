# 기본규칙
## 공통
- [x] 플레이어, 몬스터 모두 현재체력/최대체력이 있다.
  - 지금 코드 값은 플레이어 체력 10, 고블린 체력 3, 공격력은 양쪽 다 1 이다.
    아래 `플레이어 > 최대체력 100`, `고블린 > 최대채력 100` 은 아직 반영 안 했다
  - 플레이어 체력은 상단 바에도 숫자로 적는다
- [x] 체력/최대체력을 숫자로도 표시한다
  - 토큰 아래 체력바 위에 `7/10` 처럼 얹는다. 줄을 따로 만들면 칸이 좁아 둘 다 못 읽는다
  - 가득 찼다고 감추지 않는다. 숫자를 보여 주는 것이 목적이라 늘 떠 있다
  - 외부 띠의 토큰은 17px 쯤이라 숫자가 안 읽힌다. 거기서는 바만 남긴다
## 페이즈
- [x] 각 페이즈 행동은 다음의 순서를 따른다.
  - 민첩이 높은 쪽부터. 같으면 생성된 순서대로. 플레이어도 이 줄에 같이 선다
  - 지금 값(플레이어 10, 고블린 8)이면 결과적으로 플레이어 → 몬스터 순이다
  - 플레이어가 실제로 행동한 페이즈만 돈다. 벽이나 다른 물체에 막혀 이동이
    안 되면 페이즈가 시작조차 안 한다 (몬스터도 안 움직이고 스폰도 없다)
  - 더 빠른 몬스터가 먼저 그 칸을 차지하면 플레이어의 이동은 불발된다.
    페이즈는 이미 시작했으므로 행동만 날아간다. 규칙에 없어서 정했다
- [x] 공격과 공격 사이에 딜레이를 둔다. 일제히 공격하지 않는다
  - 한 대가 끝나면 260ms 쉬고 다음 차례로 간다. 세 마리가 붙어 있으면
    한 대씩 세 번, 약 0.4초 간격으로 들어온다
  - 이동은 안 쉰다. 여러 마리가 같이 걸어오는 것은 읽는 데 지장이 없고,
    마리 수만큼 기다리면 한 페이즈가 너무 길어진다
  - 연출이 도는 동안 입력을 막는다. 안 막으면 다음 페이즈가 겹쳐 든다
  - `다시` 를 누르면 돌던 페이즈는 거기서 손을 뗀다. 기다리던 공격이
    새 판의 플레이어를 때리면 안 된다
- [x] 페이즈 중 행동은 한가지만 할수 있고 한가지 행동을 하면 페이즈가 끝난다.
  - 이동과 공격은 따로 도는 페이즈가 아니라 둘 중 하나를 고르는 것이다
  - 고블린: 플레이어에 붙어 있으면 공격, 아니면 이동. 다가가서 붙은 페이즈에는
    이동을 이미 썼으므로 때리지 않는다
  - 플레이어: 짧은 입력이면 이동, 긴 입력이면 공격. 둘 중 하나만 나간다
  - 결과: 도망만 다니면 거의 안 맞는다. 플레이어가 움직여 인접이 깨지면
    고블린은 다시 이동을 골라야 하고, 붙는 순간에는 이미 행동을 써 버린 뒤다.
    한 마리가 뒤를 쫓기만 하는 상황에서는 처음 한 대 말고는 못 맞힌다

## 스텟
- 민첩 : 공격의 우선순위
  - [x] 민첩이 높은 쪽부터 행동한다. 같으면 생성된 순서대로
  - 숫자가 규칙에 없어서 정했다. 플레이어 10, 고블린 8.
    그래서 지금은 늘 플레이어가 먼저다. 더 빠른 몬스터를 넣으면 순서가 뒤집힌다
- 공격력
  - [x] 있다. 플레이어 1, 고블린 1
- 방어력
  - [ ] 아직 없다. 피해를 어떻게 깎는지 규칙이 없다
- 체력 
- 최대체력

## 행동
### 이동
- [x] 한번 이동한다.
### 공격
- [x] 공격할 때 효과음이 난다
  - 음원 파일 없이 그때그때 만든다(WebAudio). 받아 올 것이 없어 한 파일로 돌아간다
  - 감쇠하는 잡음을 대역 필터로 위에서 아래로 훑는 "휘두르는" 소리.
    플레이어는 그대로, 몬스터는 조금 낮게 낸다
  - 헛치는 것도 소리가 난다. 돌진 연출과 같은 자리에서 낸다
  - 상단 바에 끄고 켜는 단추를 뒀다
- [x] 공격한다.
  - 바로 옆 한 칸을 친다. 플레이어 공격력은 1 로 정했다 (규칙에 숫자가 없다).
    고블린 체력이 3 이라 세 번 쳐야 죽는다
  - 빈 칸을 쳐도 행동을 쓴 것이므로 페이즈는 넘어간다. 규칙에 없어서 정했다
  - 외부에 있는 몬스터도 옆이면 맞는다. 플레이어가 못 가는 것이지 못 치는 것이 아니다
- [x] 블럭이 공격하는 방향으로 빠르게 조금 이동후 제자리로 돌아옴.
  - 플레이어와 몬스터 둘 다 같은 연출을 쓴다
### 피격
- [x] 공격당한다.
  - 체력이 0 이 되면 몬스터는 판에서 사라진다. 그 칸은 다시 지나갈 수 있다
  - 때리는 쪽이 뻗고 120ms 뒤에 피해가 들어간다. 동시에 일어나면
    누가 누구를 쳤는지 안 읽힌다
- [x] 블럭이 빠르게 조금 작아진뒤 본래 크기로 돌아옴.
- [x] 체력바가 줄어드는 것이 보인다
  - 0.32초에 걸쳐 줄어든다. 상단 바 숫자도 한 대마다 같이 내려간다
    (페이즈 끝에만 고치면 정작 언제 깎였는지가 안 보인다)
- [x] 입은 피해를 머리 위에 띄운다
  - `-1` 이 위로 떠오르며 사라진다. 플레이어가 입으면 빨강, 몬스터가 입으면 노랑
  - 글자는 칸 크기를 따라가되 11px 밑으로는 안 내려간다.
    외부 띠의 작은 토큰에서도 읽혀야 한다
- [x] 숫자는 무엇보다 앞에 보인다
  - 토큰이 아니라 판에 직접 붙이고 `z-index` 를 올린다. 토큰 안에 두면
    토큰이 만든 쌓임 맥락에 갇혀 옆 토큰 뒤로 숨는다
  - 검은 테를 둘러 스프라이트 위에서도, 남의 체력바 위에서도 읽히게 했다

# 조작
- [x] 화면에 어디라도 상,하,좌,우 스와이프 가능
  - 판 위가 아니라 화면 전체에서 스와이프를 받는다. 방향키/WASD 도 같이 받는다
  - 24px 넘게 움직인 스와이프만 인정하고, 가로·세로 중 더 많이 움직인 쪽으로 정한다
- [x] 슬라이드시 플레이어는 내부 필드에서 움직임
  - 한 칸이 이동한다.
  - 벽 방향으로 스와이프시 아무일도 일어나지 않는다. 턴 진행도 안된다.
- [x] 이동불가 (필드가 다른 물체로 차있음)시 이동하지 않는다. 턴 진행도 안된다.
  - 지금 "다른 물체" 는 몬스터뿐이다. 벽과 똑같이 취급한다
- [x] 스와이프는 이동, 긴 스와이프는 공격
  - 24px 넘게 끌면 이동, 90px 넘게 끌면 공격. 방향은 가로·세로 중 더 많이 움직인 쪽
- [x] WASD·방향키는 이동, 누르고 있으면 공격
  - 300ms 넘게 누르고 있으면 그 순간 공격이 나간다. 그 전에 떼면 이동
  - 짧게 눌렀는지 길게 눌렀는지는 뗄 때까지 알 수 없어서, 이동은 keyup 에 낸다
  - 자동 반복 keydown 은 무시한다. 한 번 누르면 이동이든 공격이든 한 번만 나간다
  - '이동 못하면 공격' 으로 묶지 않고 입력을 따로 뒀다. 나중에 궁수·마법사처럼
    떨어져서 치는 직업이 들어오면 이동 가능 여부와 공격이 무관해지기 때문이다

# 몬스터
## 기본규칙
- [x] 외부 필드에서 랜덤한 위치에 생성됨
  - 생성 시점이 규칙에 없어서: 시작할 때 3마리, 이후 플레이어가 실제로
    움직일 때마다 1마리씩 늘린다
  - 이미 차있는 칸은 피한다. 외부에 빈 칸이 없으면 안 나온다
- [x] 몬스터는 서로 겹치지 않음, 이동불가시(필드 막힘) 이동하지 않음
  - 플레이어 칸도 못 밟는다. 전투 규칙이 아직 없어서 겹칠 수가 없다
  - 한 턴에 한 마리씩 차례로 옮긴다. 앞 마리가 비운 칸은 뒷 마리가 쓸 수 있다
## 종류
### 고블린
- [ ] 최대채력 100
- [x] 고블린은 상,하,좌,우 한칸씩 이동한다
  - 대각선은 없다. 한 턴에 한 칸
- [x] 매 턴 플레이어를 향해 이동한다.
  - 플레이어가 실제로 움직인 턴에만 움직인다. 벽·몬스터에 막혀 턴이
    안 넘어가면 고블린도 가만히 있는다
  - 차이가 큰 축을 먼저 시도하고, 막혔으면 다른 축으로 돈다.
    둘 다 막히면 그 자리에 선다
  - 가로세로 차이가 같을 때 어느 쪽을 먼저 볼지가 규칙에 없어서 가로로 정했다
  - 길찾기는 없다. 벽을 끼고 도는 식으로 돌아가지는 못한다
- [x] 플레이어에 4방향에서 인접한 고블린은 공격을 한다.
  - 턴이 시작될 때(플레이어가 움직인 직후) 붙어 있으면 때린다.
    그 턴에는 움직이지 않는다. 이동과 공격은 택일이다
  - 대각선은 인접이 아니다
  - 붙은 마릿수만큼 각각 때린다. 세 마리가 붙으면 한 턴에 3 깎인다
  - 플레이어 체력이 0이 되면 입력을 막고 `쓰러졌다` 를 띄운다.
    승패 규칙이 아직 없어서 정한 것이다
