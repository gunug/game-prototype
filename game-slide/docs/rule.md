# 기본규칙
## 공통
- [x] 플레이어, 몬스터 모두 현재체력/최대체력이 있다.
  - 숫자는 각 종류의 `스팩` 줄에 있다 (플레이어 100, 고블린 12, 라이더 24)
  - 토큰 아래에 체력바와 숫자
  - 플레이어 체력은 상단 바에도 숫자로 적는다
## 페이즈
- [x] 각 페이즈 행동은 다음의 순서를 따른다.
  - 플레이어 행동
  - 몬스터 행동
  - 민첩이 높은 쪽부터. 같으면 생성된 순서대로. 플레이어도 같은 줄에 선다
    (지금 값이면 플레이어 10 > 라이더 9 > 고블린 8 이라 결과적으로 위 순서다)
- [x] 페이즈 중 행동은 한가지만 할수 있고 한가지 행동을 하면 페이즈가 끝난다.
  - 이동 아니면 공격, 택일이다. 다가가서 붙은 페이즈에는 이동을 이미 썼으므로
    때리지 않는다
- [x] 한 놈이 끝나야 다음 놈이 행동한다. 이동도 공격도 한꺼번에 하지 않는다
  - 공격 뒤 260ms, 걸음 뒤 130ms 쉰다. 걸음마다 공격만큼 쉬면 한 판이 늘어진다
  - 몰릴수록 걸음 간격을 좁혀 걸음 연출 전체를 0.9초 언저리로 묶는다 (하한 55ms)
  - 막혀서 아무것도 못 한 놈은 안 쉰다. 보여 줄 것이 없다
  - 연출이 도는 동안 입력을 막는다. 안 막으면 다음 페이즈가 겹쳐 든다

  - 외부 띠의 작은 토큰(17px)에서는 감춘다. 글자가 2.5px 라 못 읽는다

## 계산방식
- [x] 최종 공격력 = 공격자의 공격력 - 방어자의 방어력
- [x] 계산 후 1보다 작아진다면 1로 친다 (방어력 제외후 최종공격력, 공격력 감쇠 적용후 최종공격력 등)
  - 지금 값으로 실제 나오는 피해:
    플레이어→고블린 5 (12체 → 세 대), 플레이어→라이더 5 (24체 → 다섯 대),
    고블린→플레이어 1, 라이더→플레이어 1
  - 방어력 5 에 막혀 고블린(공2)도 라이더(공5)도 똑같이 1 이 된다.
    지금 값에서는 몬스터끼리의 공격력 차이가 플레이어에게 안 드러난다

# UI
- [x] 1:1 비율 정사각 공간은 플레이 공간
- [x] 나머지 빈 공간에 퀘스트, 스테이트 등이 표시됨.
  - 판 아래에 퀘스트 바. 머리에 `퀘스트 1/3` 과 설명, 그 아래 항목 줄들
  - 항목 줄마다 체크 · 제목 · 진행도(3/5). 여러 번 걸리는 항목만 막대를 함께 둔다
    (한 번에 끝나는 항목은 막대가 체크와 같은 말을 반복한다)
  - 설명에는 남은 출현 마릿수도 적는다
  - 스테이트(체력·턴·몬스터 수)는 상단 바에 있다. 판 위쪽 빈 자리는 아직 비어 있다
## 위험표시
- [x] 적에의해서 다음턴에 공격당할수 있는 필드의 위치 표시
  - 몬스터가 지금 바로 옆에 붙어 있는 칸이다. 두 칸 떨어진 놈은 다가오는 데
    행동을 다 쓰므로 그 턴에는 못 때린다 (이동과 공격은 택일이라서)
  - 대각선은 인접이 아니라 위험이 아니다
  - 내부 6*6 만 칠한다. 외부는 플레이어가 갈 수 없어 알려 줄 것이 없다
  - 외부에 선 몬스터도 내부에 닿는 이웃 칸은 칠한다
- [x] 빈 필드에 옅은 붉은색
  - 누가 서 있는 칸은 안 칠한다. 그래서 플레이어가 선 칸은 표시가 없다.
    "여기 그대로 있으면 맞는가" 는 안 보여 주는 셈이다 (규칙이 "빈 필드" 라서)
- [x] 그 칸으로 갔을 때 받는 피해를 타격 테두리 안에 숫자로 표시
  - 붙어 있는 놈들의 공격력을 다 더한다. 두 마리가 닿는 칸이면 `2`
  - 뾰족뾰족한(12갈래 별) 반투명 딱지 안에 넣는다. 테두리는 얇게.
    글자는 칸의 30% (칸이 커지면 같이 커진다)
  - 방어력 규칙이 아직 없어서 깎지 않고 그대로 적는다
- [x] 플레이어 위에도 타격 테두리 숫자
  - 플레이어가 선 칸은 비어 있지 않아 칠하지 않는다. 대신 토큰 한가운데에 같은
    딱지를 얹어 "그대로 있으면(공격만 하면) 얼마나 맞는지" 를 알린다
  - 칸에 쓰는 것과 같은 모양·같은 크기·같은 반투명도다

  - 플레이어 칸도 못 밟는다. 붙어 있으면 들어가는 대신 때린다

### 고블린
- [x] 스팩: 공2,방5,체12
- [x] 공격할 수 있다면 공격한다
- [x] 공격할 수 없다면 접근한다
  - 둘은 택일이다. 다가가서 붙은 턴에는 이동을 이미 썼으므로 때리지 않는다
- [ ] 최대채력 100
- [ ] 민첩 100

    민첩은 8 로 뒀다 (플레이어 10 보다 느리게)
- [x] 고블린은 상,하,좌,우 한칸씩 이동한다
  - 대각선은 없다. 한 턴에 한 칸
- [x] 매 턴 플레이어를 향해 이동한다.
  - 플레이어가 실제로 움직인 턴에만 움직인다. 벽·몬스터에 막혀 턴이
    안 넘어가면 고블린도 가만히 있는다
  - 차이가 큰 축을 먼저 시도하고, 막혔으면 다른 축으로 돈다.
    둘 다 막히면 그 자리에 선다
  - 가로세로 차이가 같을 때 어느 쪽을 먼저 볼지가 규칙에 없어서 가로로 정했다
  - 길찾기는 없다. 벽을 끼고 도는 식으로 돌아가지는 못한다
- [x] 플레이어에 4방향에서 인접한 고블린은 공격을 한다.
  - 제 차례가 왔을 때 붙어 있으면 때린다. 그 턴에는 움직이지 않는다
  - 대각선은 인접이 아니다
  - 붙은 마릿수만큼 각각 때린다. 지금 값이면 고블린 하나가 1 씩이다
  - 플레이어 체력이 0이 되면 입력을 막고 `쓰러졌다` 를 띄운다.
    승패 규칙이 아직 없어서 정한 것이다
### 고블린라이더

  - 여덟 칸이 다 막혔으면 그 자리에 선다
- [x] 매 턴 플레이어와 인접할 수 있도록 이동한다.
  - 갈 수 있는 여덟 칸 중 "플레이어와의 거리 1" 에 가장 가까운 칸을 고른다
  - 점수가 같으면 정해 둔 차례에서 먼저 나온 칸을 쓴다 (규칙에 없어서 정한 것)

  - 고블린과 같다. 붙어 있으면 때리고 그 턴에는 안 움직인다
- 스텟은 규칙에 없어서 정했다. 체력 3, 공격력 1, 민첩 9
  (말을 탔으니 걸어오는 고블린 8 보다는 빠르고, 플레이어 10 보다는 느리다)

# 퀘스트
- [x] 퀘스트는 묶음 단위로 뜨고, 묶음 안의 항목은 따로 하나씩 깬다
  - 방향 넷은 한 묶음이라 네 개가 한꺼번에 보인다. 순서는 상관없다
  - 묶음 안을 다 깨야 다음 묶음으로 넘어간다
  - 깨면 잠깐 알리고(0.9초) 넘어간다. 그 사이 입력은 막힌다
  - 넘어가면 진행도·턴·출현 수가 다 0 부터 다시 센다
  - 다 깨면 `모든 퀘스트를 깼다` 가 뜨고 더는 아무것도 안 나온다
- [x] 출현 규칙은 묶음이 하나씩 갖는다
  - 항목마다 따로 두면 고블린 묶음과 라이더 묶음이 겹쳐 나올 수 있다
- [x] 몬스터 출현은 전적으로 퀘스트가 정한다
  - 퀘스트에 출현 규칙이 없으면 한 마리도 안 나온다. 시작할 때 깔아 두던
    3마리도 없앴다 (첫 퀘스트가 "아무 몬스터도 출현하지 않음" 이므로)
  - 앞 퀘스트에서 살아남은 몬스터는 그대로 남는다. 치우라는 규칙이 없어서 뒀다
- [x] `다시` 는 지금 퀘스트를 처음부터
  - 규칙에 없어서 정했다. 3번에서 쓰러졌는데 1번부터 하라면 가혹하다
## 위로 / 왼쪽으로 / 오른쪽으로 / 아래로 움직이기
- [x] 네 개를 따로 두고 한 번에 4개 표시
- [x] 아무 몬스터도 출현하지 않음
- [x] 각 항목은 그 방향으로 한 번 움직이면 깬다
  - 같은 방향을 여러 번 눌러도 한 번으로 친다
  - 벽에 막혀 못 간 방향은 안 센다. 실제로 움직여야 한다
## 고블린 5마리 잡기

- [x] 고블린을 5마리 잡으면 깬다
  - 그 퀘스트의 종류만 센다. 남아 있던 라이더를 잡아도 안 오른다
