# 기본규칙
## 공통
- [x] 플레이어, 몬스터 모두 현재체력/최대체력이 있다.
  - 숫자는 각 종류의 `스팩` 줄에 있다 (플레이어 100, 고블린 12, 라이더 24)
  - 토큰 아래에 체력바와 숫자
  - 플레이어 체력은 상단 바에도 숫자로 적는다
## 저장
변수는 두 갈래다. 새 값을 넣을 때 어느 쪽인지부터 정한다.

- [x] **영구저장 변수** — 지역을 벗어나도, 새로고침해도 남는다
  - 코인
  - 무한의 아레나에서 버틴 턴의 최고 기록
- [x] **일시저장 변수** — 그 지역 안에서만 산다. 드나들면 처음으로 돌아간다
  - 체력, 레벨, 경험치
  - 업그레이드(드래프트로 고른 카드)와 그것으로 오른 공격력·최대체력
- [x] 새로고침해도 남는 것은 브라우저에 적어 둔다
  - 막혀 있으면(사생활 보호 창 등) 그 판에서만 기억한다. 못 남겨도 게임은 돈다

## 페이즈
- [x] 각 페이즈 행동은 다음의 순서를 따른다.
  - 플레이어 행동
  - 몬스터 행동
  - 민첩이 높은 쪽부터. 같으면 생성된 순서대로. 플레이어도 같은 줄에 선다
    (지금 값이면 플레이어 10 > 라이더 9 > 고블린 8 이라 결과적으로 위 순서다)
- [x] 페이즈 중 행동은 한가지만 할수 있고 한가지 행동을 하면 페이즈가 끝난다.
  - 이동 아니면 공격, 택일이다. 다가가서 붙은 페이즈에는 이동을 이미 썼으므로
    때리지 않는다
- [x] 한 놈이 끝나야 다음 놈이 행동한다. 이동도 공격도 한꺼번에 하지 않는다
  - 공격 뒤 260ms, 걸음 뒤 130ms 쉰다. 걸음마다 공격만큼 쉬면 한 판이 늘어진다
  - 몰릴수록 걸음 간격을 좁혀 걸음 연출 전체를 0.9초 언저리로 묶는다 (하한 55ms)
  - 막혀서 아무것도 못 한 놈은 안 쉰다. 보여 줄 것이 없다
  - 연출이 도는 동안 입력을 막는다. 안 막으면 다음 페이즈가 겹쳐 든다

## 스텟
- [x] 살아 있는 것은 모두 같은 스텟을 갖는다. 표 하나(`BEINGS`)에 모아 뒀다.
      플레이어도 몬스터도 같은 길로 만들어진다
- [x] 각 블럭 좌상단에 공격력을 표시
  - 칼 아이콘 위에 숫자를 얹는다. 아이콘이 곧 그 블럭의 공격 상태다
  - 체력은 아래, 공격력은 위. 서로 안 겹친다
  - 외부 띠의 작은 토큰(17px)에서는 감춘다. 글자가 2.5px 라 못 읽는다

### 공격 상태 아이콘
아이콘은 그 블럭이 지금 어떻게 때리는지를 나타낸다.
파일 이름을 뜻대로 맞춰 뒀다.

| 상태 | 파일 | 그림 |
|---|---|---|
| 한번공격 | `images/icon/attack1.png` | 칼 한 자루 |
| 두번공격 | `images/icon/attack2.png` | 교차한 칼 두 자루 |

- [x] 처음은 한번공격 상태다 (플레이어도 몬스터도)
- [x] 상태가 바뀌면 아이콘도 따라 바뀐다
  - `atkMode`(`single`/`double`) 를 보고 고른다. CSS 에 파일을 박아 두지 않고
    상태에서 고르므로, 드래프트로 상태를 바꾸면 그림도 저절로 따라온다
- [ ] 두번공격의 실제 효과는 아직 없다
  - 지금은 아이콘만 바뀐다. 몇 번을 어떻게 때리는지가 규칙에 없다
- 공격력
- 체력
- 최대체력
- 민첩 : 행동 순서 (표에 같이 있다)

## 계산방식
- [x] 최종 공격력 = 공격자의 공격력
- [x] 계산 후 1보다 작아진다면 1로 친다 (공격력 감쇠 적용후 최종공격력 등)
  - 지금 값으로 실제 나오는 피해:
    플레이어→몬스터 10 (고블린 12체 → 두 대, 라이더 24체 → 세 대),
    고블린→플레이어 2, 라이더→플레이어 5
  - 방어력을 없애니 몬스터끼리의 공격력 차이가 그대로 드러난다.
    전에는 방어력 5 에 막혀 고블린(공2)도 라이더(공5)도 똑같이 1 이었다
  - 위험 표시에 적히는 숫자도 이 계산을 그대로 쓴다

### 이동
- [ ] 한번 이동한다.
### 대기
- [x] 아무것도 안 하고 턴을 넘긴다
  - 이동·공격과 같은 한 행동이다. 그 사이 몬스터는 다 움직인다
  - 스페이스를 누르거나, 화면 어디든 3초 이상 누르고 있으면 된다
  - 지역 고르는 화면에서는 없다. 넘길 턴이 없다
### 공격
- [ ] 공격한다.
- [ ] 블럭이 공격하는 방향으로 빠르게 조금 이동후 제자리로 돌아옴.
### 피격
- [ ] 공격당한다.
- [x] 블럭이 빠르게 조금 작아진뒤 본래 크기로 돌아옴.
- [x] 맞을 때는 붉게 빛난다
  - 흰빛으로 밝히면 무엇에 맞았는지가 아니라 그냥 밝아진 것으로 보인다.
    붉은 겹을 한 장 덮어 색으로 알린다
  - 판의 블럭이든 드래프트 모달의 카드든 같은 규칙을 쓴다

## 사망
- [x] 피격당하여 현재체력이 0이 되면 사망한다
  - 밀려서 판 밖으로 나가도 같은 길을 탄다 (`defeat`)
- [x] 전리품이 있는 경우에는 전리품을 드랍한다
  - 전리품은 `BEINGS` 표에 몬스터마다 적어 둔다. 0 이면 아무것도 안 튄다
- [x] 드랍한 전리품은 곧바로 플레이어에게 흡수된다
  - 죽은 자리에서 사방으로 튄 뒤 플레이어에게 빨려 든다. 줍는 조작은 없다
  - 흡수가 끝나기 전에는 다음 놈이 행동하지 않는다

## 플레이어

### 경험치 스케일
- 레벨이 n일때
- 경험치 증가량 = 5 * n
- 경험치 증가량 : 5,10,15,20,25,30...
- 경험치 요구량 : 20,25,35,50,70,95,125...
- [x] 무한레벨
  - 요구량의 차분이 곧 증가량이라 닫힌 식이 나온다:
    `요구량(n) = 20 + 5*n*(n-1)/2`. 적어 둔 20,25,35,50,70,95,125 와 그대로 맞는다
  - `n*(n-1)` 은 늘 짝수라 언제나 정수다. 표가 아니라 식이라 레벨에 끝이 없다
    (레벨 100 이면 24770, 1000 이면 2497520)
- [x] 몬스터를 잡으면 그 몬스터의 `경` 만큼 오른다 (고블린 10, 라이더 15)
- [x] 넘치면 레벨이 오르고 남는 만큼은 다음 레벨로 넘긴다
  - 한 번에 여러 레벨이 오를 수도 있다
- [x] 경험치는 체력 밑에 얇은 하늘색 바로만 보여 준다. 수치는 안 적는다
  - 레벨 숫자는 상단 바에 `Lv n` 으로 적는다. 안 그러면 레벨이 올라도
    바가 되감기는 것 말고는 알 길이 없다
