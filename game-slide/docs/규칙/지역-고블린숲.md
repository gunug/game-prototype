## 고블린 숲
- [x] 스테이지 스타일: 퀘스트
- [x] 시작시 블로커 5개 내부 필드에 무작위 배치 (나무)
- [x] 퀘스트1: 고블린 5마리 처치하기. (고블린 5마리가 1턴에 한마리씩 출현)
- [x] 퀘스트2: 고블린 라이더 5마리 처치하기. (고블린 라이더 5마리가 1턴에 한마리씩 출현)
- [x] 퀘스트3: 고블린 대장을 처치하기 (고블린 대장이 한마리 출현)
  - 대장은 묶음이 뜨는 그 자리에서 바로 나온다 (`burst: 1`). 한 마리뿐이라
    턴을 기다릴 까닭이 없다
- [x] 퀘스트3 에 고블린 궁수 5마리가 1턴에 한 마리씩 같이 나온다
  - 깨는 조건은 대장 하나뿐이다. 궁수는 안 잡아도 된다
  - 한 묶음이 출현 규칙을 여럿 가질 수 있게 했다 (`spawn` 에 배열)
- 방향 움직이기·대기 묶음은 여기서 뺐다. 그것은 튜토리얼이 가르친다.
  고블린 숲은 이제 셋 다 싸우는 묶음이다 (진행도도 3묶음으로 센다)
