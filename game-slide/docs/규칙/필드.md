# 필드
- [x] 기본 10*10 필드
## 외부
- [x] 외부 상하좌우 2줄은 플레이어가 갈수없는 영역.
  - 각 변마다 2줄. 좌표 0,1 과 8,9. 외부는 64칸
  - 못 가는 것은 플레이어뿐이다. 몬스터는 외부·내부를 다 다닌다
  - 외부는 적이 어디서 나오는지만 보여 주면 되므로 화면에서는 내부 칸의
    1/3 크기로 그린다. 칸 수·좌표·이동·스폰은 그대로다
## 내부
- [x] 내부 6*6 필드는 플레이어가 갈수있는 영역.
  - 격자 좌표 2~7. 플레이어는 가운데(4,4)에서 시작한다

# 필드 수정계획
- [ ] 기본 11*11 필드
## 외부
- [ ] 외부 4방향 3줄은 플레이어가 갈수없는 영역.
  - 각 변마다 3줄. 좌표 0,1,2과 8,9,10.
  - 못 가는 것은 플레이어 뿐이다. 몬스터는 외부와 내부를 다 다닌다
  - 외부는 적이 어디서 나오는지만 보여주면 됨
    - 외부의 칸 0,1,2는 내부칸의 2/10,3/10,5/10 사이즈 (외부 세칸을 합치면 내부 한칸과 동일)
    - 외부의 칸 8,9,10은 내부칸의 5/10,3/10,2/10 사이즈 (외부 세칸을 합치면 내부 한칸과 동일)
## 내부
- [ ] 내부 5*5 필드는 플레이어가 갈수있는 영역.
  - 격자 좌표 3,4,5,6,7
  - 플레이어는 가운데 (5,5)에서 시작한다.
