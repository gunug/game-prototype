# 명령 블럭
`지역` `다시` `취소` `대기` `종료` 처럼 눌러서 무엇을 시키는 것들을
**명령 블럭** 이라 부른다. 생김새도 고르는 법도 하나로 맞춘다.

- [x] 판의 칸과 같은 꼴이다. 정사각, 같은 모서리, 노란 테
  - 노란 테는 "고를 수 있다" 는 뜻이다. 판에서 기사가 선 칸과 같은 테다
  - 글자는 굵은 이름 한 줄, 필요하면 그 밑에 작은 설명 한 줄
- [x] 고르는 길이 둘이다. 어느 쪽이든 결과는 같다
  - 기사로 친다 (스와이프 · WASD · 방향키)
  - 클릭하거나 탭한다
- [x] 고르면 한 번 움츠러든다
  - 쳐서 고르면 기사가 그 방향으로 뻗고 블럭이 같이 움츠러든다
  - 눌러서 고르면 블럭만 움츠러든다. 기사는 그 자리에 없을 수도 있다
- [x] 지금 못 고르는 것은 흐리게 둔다
  - 지역 고르는 화면의 `대기`·`종료` 가 그렇다. 넘길 턴도 그만둘 판도 없다
- 지금 있는 것
  - 조작영역: `대기`, `종료`
  - 끝난 판 팝업: `지역`, `다시`(`종료` 로 띄웠으면 `취소`)
  - 드래프트: 카드 석 장
- [x] 드래프트 카드도 명령 블럭이다. 눌러도 그 방향으로 친 것과 같다
  - 리롤 칸은 아니다. 잠겨 있어 고를 수 없다

# 플레이 화면 분할
- [x] 게임영역, 정보영역, 조작영역
  - 상단 바 아래를 통째로 둘로 나눈다. 둘을 붙이면 16:9(가로) / 9:16(세로) 다.
    그 상자를 화면 안에 최대로 넣고 가운데 둔다. 남는 자리는 위아래(또는 좌우) 여백이다
  - 크기는 `layout()` 안의 `layoutSplit()` 이 px 로 넣어 준다.
    비율이 딱 맞아떨어지므로 기준 길이 하나(`unit`)만 구하면 나머지는 다 그 배수다
  - 가로/세로는 화면비로 가른다 (`W >= H` 면 가로). 정사각이면 가로로 친다
  - 헤딩 깊이가 어긋나 있던 것(`# 9:16`, `# 9:7`)은 원래 뜻대로 맞춰 적었다
## 16:9
- [x] 왼쪽에 게임영역, 오른쪽에 정보영역
## 9:16
- [x] 아래쪽에 게임영역, 위쪽에 정보영역
  - DOM 순서는 게임 → 정보 하나뿐이다. 세로에서 `column-reverse` 로 뒤집는다

## 조작영역
- [x] 게임영역의 왼쪽(가로) 또는 아래쪽(세로)
- [x] 블럭 일곱 개를 놓을 수 있는 크기
  - 블럭 하나 = 게임영역 한 변의 1/7. 길이는 게임영역 한 변, 두께는 블럭 하나
- [x] 첫 자리는 `대기`. 누르면 제자리에서 턴이 넘어간다 (스페이스·3초 누르기와 같다)
- [x] 마지막 자리는 `종료`. 누르면 게임 오버 팝업이 뜬다
  - 거기서 고르는 것은 `지역` 과 `취소` 다. 취소하면 판으로 돌아간다
  - 그만두려는 것은 아직 끝난 것이 아니다. 판은 그대로 있다
- [x] 가운데 다섯 자리는 아직 빈 자리다. 무엇을 놓을지는 아직 안 정했다
- [x] 지역 고르는 화면에서는 두 단추가 죽어 있다. 넘길 턴도 그만둘 판도 없다

## 게임영역
- [x] 1:1 비율
  - 판(11*11) 은 그 정사각 안에서 여백을 두고 가운데 선다. 영역이 1:1 이지
    판이 영역을 꽉 채우는 것은 아니다

## 정보영역
- [x] 7:9, 9:7 비율(가로, 세로)
### 7:9
- [x] 3.5:3 비율의 카드 2x3배치
### 9:7
- [x] 3:3.5 비율의 카드 3x2배치
- **조작영역이 생기면서 정보영역이 좁아졌다.** 게임(1) + 조작(1/7) 을 16/9 에서
  빼면 남는 것이 정보영역이라, 더는 7:9 / 9:7 이 아니다 (가로 기준 0.635:1)
- 그래서 카드도 3.5:3 을 못 지킨다. 지금은 칸을 그대로 채운다.
  비율을 지키면 좁아진 칸 안에서 카드가 겉돌기만 한다
- 칸 수(2x3 / 3x2)와 여섯 장이라는 것은 그대로다
- 여섯 자리 중 지금 찬 것은 셋(퀘스트, 인스펙터, 조작 안내)이다.
  나머지 셋은 빈 자리로 둔다. 무엇을 담을지는 아직 규칙에 없다

# 인스펙터

- [x] 플레이어 블럭이나 몬스터 블럭을 탭하면 플레이어나 몬스터의 정보를 표시.

  - 보던 몬스터가 죽으면 플레이어로 돌아온다
  - 지금 보고 있는 블럭에는 판에서도 노란 테를 두른다
  - 적는 것: 체력, 공격, 민첩. 몬스터는 드랍(코인·경험치), 플레이어는 레벨·경험치·코인

    판 위 블럭은 칸 크기에 매여 있어 이름을 넣을 자리가 없다
- [x] 업그레이드 내역 아이콘, 이름, 설명 표시

  - 플레이어만 갖는다. 몬스터를 볼 때는 줄 자체가 없다
  - 누적형은 몇 번 쌓였는지 로마자로 적는다. 판 위 블럭의 기술 줄과 같은 규칙이다

  - 스텟은 자리가 되면 두 줄씩 나란히 세운다. 여섯 줄을 한 줄씩 쌓으면
    업그레이드가 카드 밖으로 밀려 스크롤해야만 보인다

# 끝난 판 알리기
- [x] 게임이 끝나면 팝업이 뜬다
- [x] 무한의 아레나은 버틴 턴을 적는다. 실패/성공이 없다
  - 깰 것이 없는 스테이지라 늘 `게임 오버` 다. 못 깬 것이 아니라 거기까지 간 것이다
- [x] 고블린 숲은 퀘스트를 다 깨면 `게임 클리어`, 그 전에 쓰러지면 `게임 오버`
- [x] 팝업에서 고르는 것은 `지역` 과 `다시` (`종료` 로 띄운 것은 `다시` 대신 `취소`)
  - 기사를 움직여서 고른다. 왼쪽이 지역, 오른쪽이 다시. 지역 고르기·드래프트와
    같은 방식이다. 게임 안에서 단추를 누르는 곳이 없어야 조작이 하나로 남는다
  - 고르는 연출도 같다. 기사가 그 방향으로 뻗고, 골린 칸이 움츠러들며 붉게
    번쩍인다. 판에서 몬스터를 때리는 것과 같은 결이다
  - 위·아래는 아무 일도 없다. 고를 것이 둘뿐이다
  - `다시` 는 상단 바의 것과 같다. 다만 다 깬 뒤라면 되돌릴 묶음이 없어서
    그 지역을 처음부터 준다
- 적는 것: 버틴 턴, (퀘스트가 있는 곳이면) 깬 퀘스트, 레벨, 코인
- 팝업이 떠 있는 동안은 판 입력을 안 받는다. 레벨업 드래프트도 안 뜬다.
  팝업이 덮어 아무것도 못 누르게 된다

## 경험치 수집 연출
- [x] 적이 죽으면 경험치 구슬 (사이안 구체)이 적중심 사방으로 흩어진다. (0.3초 애니메이션)
  - 고르게 벌린 뒤 조금씩만 흔든다. 다 같은 각으로 쏘면 줄 세운 것처럼 보인다
- [x] 플레이어에게 구체가 닿으면서 경험치 바가 올라간다. (0.3초 애니메이션)
  - 조금씩 늦게 출발해 하나씩 닿는다. 다 같이 닿으면 바가 한 번에 튄다
  - 빨려 드는 곳은 그때의 플레이어 자리다. 흩어지는 사이에 밀고 갔을 수도 있다
  - 경험치는 구슬이 닿는 그 순간에 오른다. 날아가는 동안은 아직 안 오른 것이다
  - 구슬이 다 들어와야 그 행동이 끝난다. 안 기다리면 레벨업이 페이즈 끝을
    놓쳐 다음 턴에야 뜬다
- [x] 경험치 바는 뒤로 안 간다
  - 레벨이 오르면 ① 끝까지 차오르고 → ② `LEVEL UP` 이 뜨고 → ③ 연출 없이 0 으로
    되감고 → ④ 남은 만큼 다시 찬다
  - 한 번에 여러 레벨이 오르면 그 횟수만큼 되풀이한다
  - 그냥 새 값을 넣으면 90% 에서 12% 로 거꾸로 줄어드는 것이 보인다
- [x] 1당 경험치 구슬 1개. 10개 단위로 사이즈가 더 큰 경험치 구슬1개로 치환.
  - 경험치 증가율은 나누기 전에 먹는다. 구슬마다 반올림하면 모자라진다
    (10 을 +10% 로 받으면 11 → 큰 것 하나 + 작은 것 하나)

## 위험표시
- [x] 적에의해서 다음턴에 공격당할수 있는 필드의 위치 표시
  - 몬스터가 지금 바로 옆에 붙어 있는 칸이다. 두 칸 떨어진 놈은 다가오는 데
    행동을 다 쓰므로 그 턴에는 못 때린다 (이동과 공격은 택일이라서)
  - 대각선은 인접이 아니라 위험이 아니다
  - 내부 6*6 만 칠한다. 외부는 플레이어가 갈 수 없어 알려 줄 것이 없다
  - 외부에 선 몬스터도 내부에 닿는 이웃 칸은 칠한다
- [x] 빈 필드에 옅은 붉은색
- [x] 보일 때도 60% 불투명도로만 올린다
  - 위험은 알려 주되 판을 덮지 않게. 칸 색과 타격 딱지가 같은 값을 쓴다
  - 누가 서 있는 칸은 안 칠한다. 그래서 플레이어가 선 칸은 표시가 없다.
    "여기 그대로 있으면 맞는가" 는 안 보여 주는 셈이다 (규칙이 "빈 필드" 라서)
- [x] 움직이는 동안에는 위험표시를 감춘다
  - 페이즈가 시작되면 먼저 흐려 없애고(90ms), 다 사라진 뒤에 첫 걸음이 나간다
  - 움직이는 내내 안 보인다. 옮기기 전 상태를 그대로 두면 이미 틀린 그림을
    보고 있게 되고, 칸마다 따로 바뀌면 어지럽다
  - 페이즈가 끝나면 새로 계산해서 다시 띄운다 (같은 90ms)
- [x] 그 칸으로 갔을 때 받는 피해를 타격 테두리 안에 숫자로 표시
  - 붙어 있는 놈들의 공격력을 다 더한다. 두 마리가 닿는 칸이면 `2`
  - `images/icon/hit.png` (타격 이펙트)를 배경에 깔고 그 위에 숫자를 얹는다.
    글자는 칸의 30% (칸이 커지면 같이 커진다)
  - 방어력이 없으므로 공격력을 그대로 적는다
- [x] 플레이어 위에도 타격 테두리 숫자
  - 플레이어가 선 칸은 비어 있지 않아 칠하지 않는다. 대신 토큰 한가운데에 같은
    딱지를 얹어 "그대로 있으면(공격만 하면) 얼마나 맞는지" 를 알린다
  - 칸에 쓰는 것과 같은 모양·같은 크기·같은 반투명도다

# 조작
- [x] 화면에 어디라도 상,하,좌,우 스와이프 가능
  - 판 위가 아니라 화면 전체에서 스와이프를 받는다. 방향키/WASD 도 같이 받는다
  - 24px 넘게 움직인 스와이프만 인정하고, 가로·세로 중 더 많이 움직인 쪽으로 정한다
- [x] 스페이스로 제자리에서 턴 넘기기

  - 스와이프와 같다. 화면 어디서 시작하든 조작이 같아야 한다
  - 누르는 동안 기사에 노란 테가 차오른다. 어디를 눌렀든 기다리는 것은 기사다
  - 손가락이 조금이라도 끌리면 스와이프로 치고 대기는 취소한다

    막는다. 안 막으면 3초를 채우기 전에 끊긴다
