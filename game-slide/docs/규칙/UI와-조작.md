# 플레이 화면 분할
- [x] 게임영역, 정보영역
  - 상단 바 아래를 통째로 둘로 나눈다. 둘을 붙이면 16:9(가로) / 9:16(세로) 다.
    그 상자를 화면 안에 최대로 넣고 가운데 둔다. 남는 자리는 위아래(또는 좌우) 여백이다
  - 크기는 `layout()` 안의 `layoutSplit()` 이 px 로 넣어 준다.
    비율이 딱 맞아떨어지므로 기준 길이 하나(`unit`)만 구하면 나머지는 다 그 배수다
  - 가로/세로는 화면비로 가른다 (`W >= H` 면 가로). 정사각이면 가로로 친다
  - 헤딩 깊이가 어긋나 있던 것(`# 9:16`, `# 9:7`)은 원래 뜻대로 맞춰 적었다

## 경험치 수집 연출
- [x] 적이 죽으면 경험치 구슬 (사이안 구체)이 적중심 사방으로 흩어진다. (0.3초 애니메이션)
  - 고르게 벌린 뒤 조금씩만 흔든다. 다 같은 각으로 쏘면 줄 세운 것처럼 보인다
- [x] 플레이어에게 구체가 닿으면서 경험치 바가 올라간다. (0.3초 애니메이션)
  - 조금씩 늦게 출발해 하나씩 닿는다. 다 같이 닿으면 바가 한 번에 튄다
  - 빨려 드는 곳은 그때의 플레이어 자리다. 흩어지는 사이에 밀고 갔을 수도 있다
  - 경험치는 구슬이 닿는 그 순간에 오른다. 날아가는 동안은 아직 안 오른 것이다
  - 구슬이 다 들어와야 그 행동이 끝난다. 안 기다리면 레벨업이 페이즈 끝을
    놓쳐 다음 턴에야 뜬다
- [x] 1당 경험치 구슬 1개. 10개 단위로 사이즈가 더 큰 경험치 구슬1개로 치환.
  - 경험치 증가율은 나누기 전에 먹는다. 구슬마다 반올림하면 모자라진다
    (10 을 +10% 로 받으면 11 → 큰 것 하나 + 작은 것 하나)

## 위험표시
- [x] 적에의해서 다음턴에 공격당할수 있는 필드의 위치 표시
  - 몬스터가 지금 바로 옆에 붙어 있는 칸이다. 두 칸 떨어진 놈은 다가오는 데
    행동을 다 쓰므로 그 턴에는 못 때린다 (이동과 공격은 택일이라서)
  - 대각선은 인접이 아니라 위험이 아니다
  - 내부 6*6 만 칠한다. 외부는 플레이어가 갈 수 없어 알려 줄 것이 없다
  - 외부에 선 몬스터도 내부에 닿는 이웃 칸은 칠한다
- [x] 빈 필드에 옅은 붉은색
- [x] 보일 때도 60% 불투명도로만 올린다
  - 위험은 알려 주되 판을 덮지 않게. 칸 색과 타격 딱지가 같은 값을 쓴다
  - 누가 서 있는 칸은 안 칠한다. 그래서 플레이어가 선 칸은 표시가 없다.
    "여기 그대로 있으면 맞는가" 는 안 보여 주는 셈이다 (규칙이 "빈 필드" 라서)
- [x] 움직이는 동안에는 위험표시를 감춘다
  - 페이즈가 시작되면 먼저 흐려 없애고(90ms), 다 사라진 뒤에 첫 걸음이 나간다
  - 움직이는 내내 안 보인다. 옮기기 전 상태를 그대로 두면 이미 틀린 그림을
    보고 있게 되고, 칸마다 따로 바뀌면 어지럽다
  - 페이즈가 끝나면 새로 계산해서 다시 띄운다 (같은 90ms)
- [x] 그 칸으로 갔을 때 받는 피해를 타격 테두리 안에 숫자로 표시
  - 붙어 있는 놈들의 공격력을 다 더한다. 두 마리가 닿는 칸이면 `2`
  - `images/icon/hit.png` (타격 이펙트)를 배경에 깔고 그 위에 숫자를 얹는다.
    글자는 칸의 30% (칸이 커지면 같이 커진다)
  - 방어력이 없으므로 공격력을 그대로 적는다
- [x] 플레이어 위에도 타격 테두리 숫자
  - 플레이어가 선 칸은 비어 있지 않아 칠하지 않는다. 대신 토큰 한가운데에 같은
    딱지를 얹어 "그대로 있으면(공격만 하면) 얼마나 맞는지" 를 알린다
  - 칸에 쓰는 것과 같은 모양·같은 크기·같은 반투명도다

# 조작
- [x] 화면에 어디라도 상,하,좌,우 스와이프 가능
  - 판 위가 아니라 화면 전체에서 스와이프를 받는다. 방향키/WASD 도 같이 받는다
  - 24px 넘게 움직인 스와이프만 인정하고, 가로·세로 중 더 많이 움직인 쪽으로 정한다
- [x] 슬라이드시 플레이어는 내부 필드에서 움직임
  - 한 칸이 이동한다.
  - 벽 방향으로 스와이프시 아무일도 일어나지 않는다. 턴 진행도 안된다.
- [x] 이동불가 (필드가 다른 물체로 차있음)시 이동하지 않는다. 턴 진행도 안된다.
  - 지금 "다른 물체" 는 몬스터뿐이다. 벽과 똑같이 취급한다
