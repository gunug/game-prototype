# 드래프트
- [x] 레벨업 시 드래프트카드 3개 중 하나를 골라 플레이어에 적용
  - 레벨당 한 번씩. 한 번에 두 레벨이 오르면 연달아 두 번 고른다
  - 페이즈가 다 끝난 뒤에 뜬다. 몬스터까지 움직이고 난 판을 보고 고르게 된다
    (규칙에 시점이 없어서 정했다. 잡은 그 순간에 띄우면 남은 몬스터가
    아직 안 움직인, 반쯤 지난 판을 보고 고르게 된다)
- [x] 모달창에 플레이어를 가운데두고, 드래프트 카드 3개가 좌,상,우에 있음
  - 모달을 게임판과 같은 꼴로 짰다. 정사각 칸, 칸 대비 간격 2/52, 모서리 6% 를
    그대로 맞췄다. 가운데는 판에 서 있는 그 블럭(스프라이트·공방 딱지·체력·경험치)
  - 방향으로 고르는 조작이 판 위에서 움직이는 것과 같은 손놀림이 된다
- [x] 레벨업 하면 모달보다 먼저 `LEVEL UP` 글씨와 소리가 뜬다
  - 0.9초. 도-미-솔-도를 한 음씩 늦게 쌓아 올린다
  - 뜨는 때는 경험치 바가 다 찬 그 순간이다. 모달도 곧바로 이어서 열린다
- [x] 레벨이 오르면 그 자리에서 바로 고른다
  - 예전에는 페이즈 끝(몬스터가 다 움직인 뒤)에 몰아서 열었다. 오른 것과
    고르는 것이 멀어져 무엇 때문에 골랐는지가 흐려졌다
  - 여러 레벨이 한꺼번에 오르면 오를 때마다 한 번씩 고른다
- [x] 방향을 고르면 그 방향으로 치는 모션이 먼저 나간다
  - 판에서 때릴 때와 같은 연출(`lunge`)이라 소리도 같이 난다.
    고른다는 것이 곧 그 카드를 치는 것으로 보인다
- [x] 고른 카드는 맞는 모션을 낸다
  - 판에서 몬스터가 맞을 때와 같은 결. 움츠러들며 붉게 번쩍인다
- [x] 카드에는 이름만 적는다
  - 방향 글씨(위·왼쪽·오른쪽)는 뺐다. 어느 칸인지는 자리로 이미 안다
  - 설명이 제목과 같은 말이면 두 번 안 적는다 (`공격력+5` / `공격력 +5`)
- [x] 친 다음 카드 그림이 블럭 쪽으로 날아가고, 닿아 사라진 뒤에 실제로 붙는다
  - 날아가는 0.48초 동안에는 아직 안 붙는다. 닿으면 한 번 튀면서 바뀐다
  - 닿는 곳은 늘 블럭의 아이콘 줄이다. 거기 그대로 쌓인다
  - 수치를 올리는 카드(`공격력+5`)는 닿을 때 그 수치 딱지가 같이 튄다
  - 판 위 블럭과 모달 안 블럭이 같이 바뀐다
- [x] 블럭에 지금까지 가진 카드의 그림을 한 줄로 보여 준다
  - 체력바 바로 위. 왼쪽부터 채운다
  - 누적형은 몇 번 쌓였는지 로마자로 적는다 (`I` `II` `III` …)
  - 숫자는 그림 위 오른아래 귀퉁이에 얹는다. 옆에 세우면 이웃 그림과 겹친다
  - 기능형은 늘 한 번이라 숫자를 안 적는다
- [x] 판 위 블럭과 모달 안 블럭이 똑같이 보인다
  - 플레이어를 그리는 규칙이 한 벌이다. 어느 쪽을 보든 같은 것을 읽는다
  - 가진 카드 줄은 블럭 크기의 0.23배. 다른 표시들에 밀리지 않게 작게 둔다
  - 외부 띠의 작은 토큰에서는 감춘다 (공격력 딱지와 같은 이유)
  - 날아가는 중에 또 고르면 안 먹는다. 한 번만 먹는다
- [x] 아래쪽은 리롤용 (해금되지 않았음으로 비활성화)
  - 아래로 밀어도 아무 일도 없다
- [x] 플레이어가 wasd또는 스와이프로 공격처럼 선택하면 해당 드래프트 선택완료.
  - 고르는 동안 판은 멈춘다. 그때의 방향 입력은 전부 카드 선택으로 간다
- [x] 드래프트 카드는 순차적으로 구현될 예정. 현재는 구현된 카드만 등장
  - 구현된 카드가 3장보다 적으면 같은 카드가 여러 칸에 온다.
    지금 나올 수 있는 것은 석 장(`공격력+5`, `경험치+10%`, 밀치기 계열 하나)이라
    세 칸이 다 다르다. 밀치기 계열을 다 배우면 두 장으로 줄어 한 칸이 겹친다
- [x] 기능형 카드는 한 번 배우면 다시 안 나온다. 연계 카드는 앞 기술을 배워야 나온다
  - 배운 것과 아직 못 여는 것을 빼고 남은 것에서만 뽑는다
- [x] 기술 카드에는 그림을 얹는다
- [x] 게임 클리어 상태일 때는 레벨업을 했더라도 드래프트 하지 않는다
  - 판을 나가면 업그레이드는 어차피 다 지워진다. 고르라고 세워 두면 헛품이다
  - "클리어로 끝나는 판" 은 셋 중 하나다
    ① 이미 클리어로 끝나 팝업이 떠 있다
    ② 묶음을 다 깼다
    ③ 지금 묶음을 깼고 남은 묶음이 `hold`(눌러서 끝내는 것) 뿐이다
  - ③ 때문에 마지막 한 마리를 잡고 오른 레벨에서도 안 뜬다. 그 잡은 순간이
    곧 클리어라 팝업보다 드래프트가 먼저 뜨던 자리다
  - **버티기 지역(무한의 아레나)은 늘 뜬다.** 깰 것이 없으니 "끝나는 판" 도 없다.
    모든 구간에서 고를 수 있어야 한다
  - 레벨업 알림은 그대로 뜬다. 오른 것은 오른 것이다
## 드래프트 카드
* 누적형: 계속 수치를 올려서 계속 세짐
* 기능형: 새로운 패턴이나 기능을 갖음(누적되기가 어렵다), 연계(앞 기술을 배우면 다음에 뒷 기술을 배울 가능성이 열림)

### 경험치 증가 +10%
- [x] 경험치 증가량 +10% (누적형)
  - 더해서 쌓인다. 두 번 고르면 +20%
- [x] skill_exp_up.png
  - 얻는 경험치 전부에 먹는다. 지금은 몬스터를 잡는 것뿐이지만 다른 데서
    들어와도 같이 오른다
  - 반올림이다. 라이더(경15)를 +10% 로 잡으면 16.5 → 17
### 공격력+5
- [x] 공격력+5 (누적형)
  - 더해서 쌓인다. 두 번 고르면 +10
  - `다시` 를 누르면 스텟이 표의 기본값으로 돌아간다
- [x] skill_attack_up.png
### 밀치기 (기능형 · 연계)
#### 밀치기
- [x] 공격방향으로 적을 밀어냄
- [x] skill_push.png
  - 공격 방향으로 붙어 있는 적을 전부 한 칸 민다. 사이가 떠 있으면 밀리지 않는다.
    빈 칸에서 끊긴다
  - 때려 죽인 자리도 빈 칸이다. 앞의 적을 잡아 버리면 뒤의 적은 안 밀린다
  - 때린 다음에 민다. 맞고 죽은 놈은 이미 빠졌으므로 밀 것도 없다
  - 판 밖으로 밀려 나가면 죽는다. 때려 잡은 것과 같이 친다
    (경험치가 들어오고 퀘스트 마릿수도 올라간다)
  - 기능형이라 쌓이지 않는다. 한 번 배우면 카드가 다시 안 나온다
  - 빈 칸을 치면 밀 것이 없으니 아무 일도 없다
#### 밀고가기
- [x] 공격방향으로 적을 밀고 이동함
- [x] skill_push_move.png
  - `밀치기` 를 배워야 나온다. 배우면 `밀치기` 자리를 이 카드가 잇는다 (연계)
  - 밀고 나서 앞칸이 비었으면 그 칸으로 간다. 밀어서 비웠든 때려 죽여서
    비웠든 같다
  - 빈 칸을 헛치면 안 간다. 안 그러면 공격이 곧 이동이 되어 버린다
  - 이동과 같은 규칙을 탄다. 앞칸이 외부 띠면 안 나간다
- [x] 둘 다 `다시` 를 누르면 잊는다
