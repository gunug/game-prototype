- [x] 블로커가 있는 지역에 이동할 수 없음

- [x] 그래픽 객체를 다양하게 사용
  - 무엇으로 막는지는 스테이지가 정한다. 고블린 숲은 나무, 무한의 아레나는 돌
  - `images/blocker/blocker_tree.png`, `images/blocker/blocker_stone.png`
- [x] 블로커는 고립지역을 만들지 않는다
  - 하나 놓을 때마다 남은 빈 칸이 여전히 한 덩어리인지 본다. 갈라지면 그 자리는 버린다
  - 판 전체(11*11)로 본다. 안쪽만 보면 바깥 띠와 끊기는 것을 못 잡는다
  - 놓을 자리가 다 떨어지면 그만큼만 놓는다. 억지로 채우느니 몇 개 적은 편이 낫다
- 어디에 몇 개를 놓는지는 스테이지가 정한다 ([[규칙/지역과-스테이지|지역과 스테이지]]).
  무한의 아레나과 고블린 숲은 시작할 때 안쪽 5*5 에 5개를 무작위로 놓는다

# 몬스터

## 기본규칙
- [x] 외부 필드에서 랜덤한 위치에 생성됨
  - 언제 몇 마리가 나오는지는 퀘스트가 정한다 (`퀘스트` 절 참고).
    출현 규칙이 없는 퀘스트에서는 한 마리도 안 나온다
  - 이미 차있는 칸은 피한다. 외부에 빈 칸이 없으면 안 나온다
- [x] 몬스터는 서로 겹치지 않음, 이동불가시(필드 막힘) 이동하지 않음
  - 플레이어 칸도 못 밟는다. 붙어 있으면 들어가는 대신 때린다
  - 한 턴에 한 마리씩 차례로 옮긴다. 앞 마리가 비운 칸은 뒷 마리가 쓸 수 있다
## 종류
### 토끼
- [ ] 대기-대기-도망 패턴
### 고블린
- [x] 스팩: 공2,체12
- [x] 전리품: 코인5,경험치10
- [x] 공격할 수 있다면 공격한다
- [x] 공격할 수 없다면 접근한다
  - 둘은 택일이다. 다가가서 붙은 턴에는 이동을 이미 썼으므로 때리지 않는다
- [x] 고블린은 상,하,좌,우 한칸씩 이동한다
  - 대각선은 없다. 한 턴에 한 칸
- [x] 매 턴 플레이어를 향해 이동한다.
  - 플레이어가 실제로 움직인 턴에만 움직인다. 벽·몬스터에 막혀 턴이
    안 넘어가면 고블린도 가만히 있는다
- [x] 길을 찾아 돌아간다 (A*)
  - 벽(기물)과 다른 몬스터를 피해 플레이어 옆까지 가는 최단 길을 찾고 첫 한 칸만 간다
  - 블로커가 생기면서 필요해졌다. 예전 방식은 벽 뒤에서 영영 제자리걸음이었다
- [x] 플레이어가 고립되어 못 닿으면, 갈 수 있는 칸 중 거리상 가장 가까운 곳으로 간다
  - 거리는 실제 거리(가로+세로)로 잰다. 같으면 덜 걸어도 되는 쪽
  - 더 가까워질 곳이 없으면 그 자리에 선다. 길이 열리는 순간 바로 다시 다가온다
  - 예전의 "차이가 큰 축부터 한 칸" 방식은 없앴다. 이 규칙이 그 자리를 대신하고,
    남겨 두면 제자리에서 왔다갔다 하게 만든다 (라이더가 실제로 그랬다)
- [x] 플레이어에 4방향에서 인접한 고블린은 공격을 한다.
  - 제 차례가 왔을 때 붙어 있으면 때린다. 그 턴에는 움직이지 않는다
  - 대각선은 인접이 아니다
  - 붙은 마릿수만큼 각각 때린다. 지금 값이면 고블린 하나가 1 씩이다
  - 플레이어 체력이 0이 되면 입력을 막고 `쓰러졌다` 를 띄운다.
    승패 규칙이 아직 없어서 정한 것이다
### 고블린라이더
- [x] 스팩: 공5,체24
- [x] 전리품: 코인10,경험치15
- [x] 체스의 나이트 처럼 움직인다.
  - 여덟 방향 L 자. 사이에 무엇이 있든 뛰어넘는다
  - 여덟 칸이 다 막혔으면 그 자리에 선다
- [x] 매 턴 플레이어와 인접할 수 있도록 이동한다.
  - 나이트 이동으로 길을 찾는다 (고블린과 같은 A*, 갈 수 있는 방향만 다르다).
    여러 수를 내다보므로 벽에 갇혀도 돌아 나온다
  - 못 닿으면 고블린과 같다: 갈 수 있는 칸 중 제일 가까운 곳으로, 더 나은 곳이
    없으면 제자리
  - 점수가 같으면 정해 둔 차례에서 먼저 나온 칸을 쓴다 (규칙에 없어서 정한 것)
  - 나이트 이동은 `x+y` 의 홀짝을 매번 뒤집는다. 그래서 플레이어와의 거리가
    홀수인 자리에서는 한 수로 인접이 될 수 없다. 규칙의 한계지 버그가 아니다
- [x] 플레이어에 인접한 고블린 라이더는 공격을 한다.
  - 고블린과 같다. 붙어 있으면 때리고 그 턴에는 안 움직인다
- 민첩은 규칙에 없어서 정했다. 9 (플레이어 10 보다 느리고 고블린 8 보다 빠르다)
  (말을 탔으니 걸어오는 고블린 8 보다는 빠르고, 플레이어 10 보다는 느리다)
- 스폰 비율도 규칙에 없어서 정했다. 새로 나오는 몬스터의 1/4 이 라이더다
