# 스테이지 고르기
- [x] 게임을 시작하면 스테이지 고르는 화면부터 시작
- [x] 게임판 그대로에서 고른다 (11*11, 안쪽 5*5)
  - 판·이동·공격 규칙을 그대로 쓴다. 고르는 조작이 곧 게임 조작이다
  - 몬스터도 퀘스트도 없다. 스테이지 블럭 셋과 기사뿐이다
- [x] 기사가 이동해서 스테이지 블럭을 공격하면 그 스테이지로 들어간다
  - 치는 모션(0.2초)이 끝나야 들어간다. 몬스터를 때리는 것과 같은 손맛이어야
    "공격해서 고른다" 가 말이 된다
- [x] 내놓는 것: 고블린 숲, 토끼굴(잠김), 무한의 탑
  - 토끼굴은 규칙이 없다. 쳐도 안 들어가고 안내 문구만 바뀐다
- [x] 스테이지에서 쓰러지면 단추 둘: `다시`(그 스테이지를 처음부터), `지역`
  - `지역` 단추는 고르는 화면에서는 감춘다. 이미 거기 있다
  - `다시` 는 지금 퀘스트 묶음을 처음부터다. 스테이지를 통째로 되돌리지 않는다
    (전에 정해 둔 규칙 그대로. 3번에서 쓰러졌는데 1번부터는 가혹하다)

    기사(5,5) 에서 한 칸 띄웠다. 붙여 두면 스와이프 한 번에 들어가 버려
    "이동해서 공격" 이 아니게 된다

    상단 바 스텟은 그대로 둔다 (기사는 고르는 화면에서도 같은 기사다)

# 지역
## 고블린 숲
- [ ] 스테이지 스타일: 버티기
  - 지금은 퀘스트를 도는 곳이다. 버티기로 바꿀지는 안 정했다
- [x] 시작시 블로커 5개 내부 필드에 무작위 배치
- [ ] 3턴에 한마리씩 고블린 출현, 무한
- [ ] 10턴에 한마리씩 고블린 라이더 출현, 무한
- 지금 있는 퀘스트 셋(방향 움직이기 → 고블린 5마리 → 라이더 5마리)이
  고블린 숲의 내용이다. 들어가면 그 셋을 그대로 돈다
  - 위의 출현 규칙과 퀘스트의 출현 규칙이 서로 다르다. **퀘스트 쪽을 쓴다.**
    (3턴에 한 마리, 묶음마다 10마리까지). 지역 쪽 두 줄은 아직 안 켠 규칙이다

## 토끼굴
- [ ] 잠김. 규칙이 아직 없다

## 무한의 탑
- [x] 스테이지 스타일: 버티기
- [x] 시작시 블로커 5개 내부 필드에 무작위 배치
  - 플레이어 자리는 피한다. 안쪽 5*5 는 25칸이라 5개면 다섯 칸에 하나꼴이다
  - **시작 자리와 그 옆 네 칸은 비워 둔다.** 처음부터 갇히면 아무것도 못 한다.
    안쪽 25칸 중 5칸을 빼고 20칸에서 고른다
- [x] 0턴 부터 : 고블린 3턴에 한마리씩 생성
  - 0턴에도 한 마리 나온다. 끝이 없다 (총 마릿수 제한 없음)
- [x] 10턴 부터 : 고블린 라이더 5턴에 한마리씩 생성
- [x] 고블린과 고블린라이더 공격력, 체력은 10턴마다 10%씩 누적증가.
      최종 공체 표시에는 소수점 표시되지 않도록 반올림
  - **새로 나오는 놈만 오른다.** 이미 판에 있는 놈은 그대로다
  - 배수는 곱으로 쌓는다: `1.1^floor(턴/10)`. 10턴 1.1배, 20턴 1.21배, 30턴 1.331배
  - 반올림은 나올 때 한 번만 한다. `공 = round(기본공 * 배수)`,
    `체 = round(기본체 * 배수)` 로 굳혀서 내보낸다. 그러면 화면에도 계산에도
    소수가 아예 안 생긴다 (실수로 들고 다니다 표시만 반올림하면 12.1/13.2 같은
    체력이 안쪽에 남는다)
  - 고블린(공2/체12) 기준: 10턴 공2/체13, 20턴 공2/체15, 30턴 공3/체16
- [x] 10턴마다 고블린, 고블린 라이더 더 자주 생성.
  - 주기에 10턴마다 0.9 를 곱하고 반올림한다. 하한은 1턴.
    `주기 = max(1, round(기본주기 * 0.9^floor(턴/10)))`
  - 고블린(3턴): 0~19턴 3턴, 20~59턴 2턴, 70턴부터 1턴
  - 라이더(5턴): 10턴 5턴, 20턴 4턴, 40턴 3턴, 60턴 2턴
- [x] 끝이 없다. 쓰러질 때까지 버틴다
  - 깰 퀘스트가 없다. 퀘스트 바에는 `버틴 턴 · 공체 배수 · 지금 생성 주기` 를 적는다
  - 몇 턴 버텼는지를 남겨 두는(기록) 것은 아직 없다
