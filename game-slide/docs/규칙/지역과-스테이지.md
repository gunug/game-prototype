# 스테이지 고르기
- [x] 게임을 시작하면 스테이지 고르는 화면부터 시작
- [x] 게임판 그대로에서 고른다 (11*11, 안쪽 5*5)
  - 판·이동·공격 규칙을 그대로 쓴다. 고르는 조작이 곧 게임 조작이다
  - 몬스터도 퀘스트도 없다. 스테이지 블럭 셋과 기사뿐이다
- [x] 기사가 이동해서 스테이지 블럭을 공격하면 그 스테이지로 들어간다
  - 치는 모션(0.2초)이 끝나야 들어간다. 몬스터를 때리는 것과 같은 손맛이어야
    "공격해서 고른다" 가 말이 된다
- [x] 내놓는 것: 고블린 숲, 토끼굴(잠김), 무한의 아레나
  - 토끼굴은 규칙이 없다. 쳐도 안 들어가고 안내 문구만 바뀐다
- [x] 각 스테이지 블럭에 스테이지 이름
  - 위쪽에서 조금 내려 붙인다 (블럭 높이의 12%). 꼭대기에 붙이면 칸 테두리에 눌린다
  - 그림만으로는 무엇인지 모른다. 어두운 그라데이션을 깔고 그 위에 흰 글씨
- [x] 무한의 아레나 블럭 오른쪽 아래 1/4 칸에 최고 버틴 턴을 숫자로 크게
  - 아직 한 번도 안 해 봤으면 0턴
  - 층 개념은 없앴다. 기록도 표시도 턴 하나뿐이다.
    10턴마다 세지고 잦아지는 규칙은 그대로지만, 그것을 층이라 부르지 않는다
  - 남기는 때는 그 판이 끝나는 곳 하나다. 죽어서 끝나든 나가서 끝나든 같다
- [x] 스테이지에서 쓰러지면 단추 둘: `다시`(그 스테이지를 처음부터), `지역`
  - `지역` 단추는 고르는 화면에서는 감춘다. 이미 거기 있다
  - `다시` 는 지금 퀘스트 묶음을 처음부터다. 스테이지를 통째로 되돌리지 않는다
    (전에 정해 둔 규칙 그대로. 3번에서 쓰러졌는데 1번부터는 가혹하다)

  - 그림이 보이도록 빈 칸을 반투명으로 낮춘다. 안쪽은 많이 비치고(38%),
    바깥 띠는 덜 비친다(62%). 거기는 적이 어디서 나오는지만 알면 되는 자리다
  - 그림 위에 30% 검은 겹을 덮는다. 또렷하면 그 위의 블럭과 위험 표시가 안 읽힌다

- 파일 이름 `infinit_arena.png` 는 철자가 그렇게 되어 있다. 코드도 그대로 쓴다
- 이름을 `무한의 탑` 에서 `무한의 아레나` 로 바꿨다. 그림도 같이 갈았다.
  옛 그림 `infinit_tower.png` 는 지웠다
- 구현하며 정한 것
  - 자리: 고블린 숲 (3,5) 왼쪽, 토끼굴 (5,3) 위, 무한의 아레나 (7,5) 오른쪽.
    기사(5,5) 에서 한 칸 띄웠다. 붙여 두면 스와이프 한 번에 들어가 버려
    "이동해서 공격" 이 아니게 된다
  - 잠긴 것은 색을 빼고 어둡게 (`grayscale`). 있다는 것은 보이되
    고를 것으로는 안 읽히게. 자물쇠 딱지는 안 넣었다
  - 퀘스트 바에는 지역 목록을 적는다. 위험 표시는 몬스터가 없으니 저절로 없다.
    상단 바 스텟은 그대로 둔다 (기사는 고르는 화면에서도 같은 기사다)

## 튜토리얼
처음 들어온 사람에게 조작을 하나씩 가르치는 스테이지다.
스타일은 퀘스트. 묶음 넷을 차례로 돈다 ([[규칙/퀘스트|퀘스트]] 규칙 그대로).
체크박스 줄은 코드가 지켜야 할 규칙이고, `문구:` 는 화면에 그대로 뜨는 글이다.

### 스테이지
- [x] `id: tutorial`, 이름 `튜토리얼`. 고르는 화면에 블럭으로 세운다
  - 자리는 (5,7) 기사 아래. 다른 셋과 같이 한 칸 띄웠다
  - **블럭 그림이 아직 없다.** `images/player.png` 를 빌려 쓰고 있다.
    `images/stage/tutorial.png` 가 생기면 갈아 끼운다
- [x] 블로커 없다. 판이 비어 있어야 이동부터 가르칠 수 있다
- [x] 몬스터는 퀘스트 묶음이 정한 대로만 나온다.
      묶음에 출현 규칙이 없으면 한 마리도 안 나온다

### 묶음 1 — 이동
- [x] 항목 넷을 한꺼번에 띄운다: 위·아래·왼쪽·오른쪽으로 움직이기 (`type: 'dir'`)
- [x] 출현 없다 (`spawn: null`)
- [x] 네 방향을 다 밟으면 깬다. 순서는 상관없다. 벽에 막혀 못 간 방향은 안 센다
- 문구: `스와이프나 WASD 로 움직인다. 몬스터는 나오지 않는다`

### 묶음 2 — 대기
- [x] 항목 하나: 대기하기 (`type: 'wait'`)
- [x] 출현 없다
- [x] 묶음이 뜨는 순간 `대기` 단추(`#act-wait`)를 세 번 깜빡인다 (`blink`)
  - 깜빡임은 고를 것이 새로 떴을 때만 쓴다는 규칙 그대로다
- [x] 한 번 대기하면 깬다
- 문구: `아무것도 안 하고 한 턴을 넘긴다. 스페이스 · 또는 대기 단추`

### 묶음 3 — 전투
- [x] 묶음이 뜨는 그 턴에 고블린 5기가 한꺼번에 나온다. 뒤로는 더 안 나온다
  - 지금 출현 규칙은 `{ kind, every, max }` 뿐이라 한꺼번에 못 낸다.
    `{ kind: 'goblin', burst: 5 }` 를 새로 만들었다.
    묶음이 뜨는 `startGroup` 에서 다 낸다 — 턴을 기다리지 않는다
  - 자리는 늘 하던 대로 바깥 띠 무작위. 다섯이 한 칸에 겹치지 않게
- [x] 고블린 5마리를 잡으면 깬다 (`type: 'kill'`, `kind: 'goblin'`, `goal: 5`)
- 문구: `고블린 다섯이 한꺼번에 나온다. 몬스터 쪽으로 움직이면 공격이다`

### 묶음 4 — 마침
- [x] 깰 항목이 없다. 뜨는 순간 이미 다 깬 묶음이다
- [x] `종료` 단추(`#act-quit`)를 세 번 깜빡인다
- [x] `종료` 를 눌러야 스테이지가 끝난다. 저절로 나가지 않는다
  - 다른 스테이지는 다 깨면 바로 `게임 클리어` 가 뜬다. 여기서는 나가는 조작까지
    가르치는 것이 목적이라 사람이 눌러 끝내게 둔다
  - 지금 `종료` 는 `여기서 그만둘까` 를 띄운다. `hold` 묶음에서 누르면
    `게임 클리어` 로 띄운다
  - `다시` 는 `hold` 묶음에 와 있으면 묶음 1부터 준다. 마지막 묶음만 다시 주면
    단추만 한 번 더 누르는 꼴이다
- 문구: `모든 퀘스트를 깼다. 종료 단추로 나간다`

## 고블린 숲
- [ ] 스테이지 스타일: 퀘스트
- [x] 시작시 블로커 5개 내부 필드에 무작위 배치 (나무)
- [ ] 3턴에 한마리씩 고블린 출현, 무한
- [ ] 10턴에 한마리씩 고블린 라이더 출현, 무한
- 지금 있는 퀘스트 셋(방향 움직이기 → 고블린 5마리 → 라이더 5마리)이
  고블린 숲의 내용이다. 들어가면 그 셋을 그대로 돈다
  - 위의 출현 규칙과 퀘스트의 출현 규칙이 서로 다르다. **퀘스트 쪽을 쓴다.**
    (3턴에 한 마리, 묶음마다 10마리까지). 지역 쪽 두 줄은 아직 안 켠 규칙이다

## 토끼굴

## 무한의 아레나
- [x] 스테이지 스타일: 버티기
- [x] 시작시 블로커 5개 내부 필드에 무작위 배치 (돌)
  - 플레이어 자리는 피한다. 안쪽 5*5 는 25칸이라 5개면 다섯 칸에 하나꼴이다
  - **시작 자리와 그 옆 네 칸은 비워 둔다.** 처음부터 갇히면 아무것도 못 한다.
    안쪽 25칸 중 5칸을 빼고 20칸에서 고른다
- [x] 0턴 부터 : 고블린 3턴에 한마리씩 생성
  - 0턴에도 한 마리 나온다. 끝이 없다 (총 마릿수 제한 없음)
- [x] 10턴 부터 : 고블린 라이더 5턴에 한마리씩 생성
- [x] 고블린과 고블린라이더 공격력, 체력은 10턴마다 10%씩 누적증가.
      최종 공체 표시에는 소수점 표시되지 않도록 반올림
  - **새로 나오는 놈만 오른다.** 이미 판에 있는 놈은 그대로다
  - 배수는 곱으로 쌓는다: `1.1^floor(턴/10)`. 10턴 1.1배, 20턴 1.21배, 30턴 1.331배
  - 반올림은 나올 때 한 번만 한다. `공 = round(기본공 * 배수)`,
    `체 = round(기본체 * 배수)` 로 굳혀서 내보낸다. 그러면 화면에도 계산에도
    소수가 아예 안 생긴다 (실수로 들고 다니다 표시만 반올림하면 12.1/13.2 같은
    체력이 안쪽에 남는다)
  - 고블린(공2/체12) 기준: 10턴 공2/체13, 20턴 공2/체15, 30턴 공3/체16
- [x] 10턴마다 고블린, 고블린 라이더 더 자주 생성.
  - 주기에 10턴마다 0.9 를 곱하고 반올림한다. 하한은 1턴.
    `주기 = max(1, round(기본주기 * 0.9^floor(턴/10)))`
  - 고블린(3턴): 0~19턴 3턴, 20~59턴 2턴, 70턴부터 1턴
  - 라이더(5턴): 10턴 5턴, 20턴 4턴, 40턴 3턴, 60턴 2턴
- [x] 끝이 없다. 쓰러질 때까지 버틴다
  - 깰 퀘스트가 없다. 퀘스트 바에는 `버틴 턴 · 공체 배수 · 지금 생성 주기` 를 적는다
  - 몇 턴 버텼는지를 남겨 두는(기록) 것은 아직 없다
