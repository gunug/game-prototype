## 행동

## 생성
- [x] 특수한 몬스터 말고는 외부필드 가장 바깥 라인에서 생성된다
  - 테두리 한 줄(좌표 0 이나 10 이 걸리는 40칸)에서 무작위.
    자세한 것은 [[규칙/몬스터와-기물|몬스터와 기물]] 의 몬스터 기본규칙

# 등장
- [ ] 외부필드에서 내부필드로 진입시
- [ ] 몬스터에 명시된 대사가 있다면 대사중 랜덤하게 한 가지를 말함
- [ ] 대사마다 괄호에 표시된 숫자만큼 대사 빈도가 높다.

### 이동
- [ ] 한번 이동한다.
### 대기
- [x] 아무것도 안 하고 턴을 넘긴다
  - 이동·공격과 같은 한 행동이다. 그 사이 몬스터는 다 움직인다
  - 스페이스를 누르거나, 화면 어디든 3초 이상 누르고 있으면 된다
  - 지역 고르는 화면에서는 없다. 넘길 턴이 없다
### 공격
- [ ] 공격한다.
- [ ] 블럭이 공격하는 방향으로 빠르게 조금 이동후 제자리로 돌아옴.
### 피격
- [ ] 공격당한다.
- [x] 블럭이 빠르게 조금 작아진뒤 본래 크기로 돌아옴.
- [x] 맞을 때는 붉게 빛난다
  - 흰빛으로 밝히면 무엇에 맞았는지가 아니라 그냥 밝아진 것으로 보인다.
    붉은 겹을 한 장 덮어 색으로 알린다
  - 판의 블럭이든 드래프트 모달의 카드든 같은 규칙을 쓴다

## 사망
- [x] 피격당하여 현재체력이 0이 되면 사망한다
  - 밀려서 판 밖으로 나가도 같은 길을 탄다 (`defeat`)
- [x] 전리품이 있는 경우에는 전리품을 드랍한다
  - 전리품은 `BEINGS` 표에 몬스터마다 적어 둔다. 0 이면 아무것도 안 튄다
- [x] 드랍한 전리품은 곧바로 플레이어에게 흡수된다
  - 죽은 자리에서 사방으로 튄 뒤 플레이어에게 빨려 든다. 줍는 조작은 없다
  - 흡수가 끝나기 전에는 다음 놈이 행동하지 않는다
