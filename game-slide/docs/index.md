# 슬라이드 — 문서 목록

11*11 필드의 안쪽 5*5 를 플레이어가 한 칸씩 움직인다. 고블린이 매 턴 쫓아와 때린다.

문서는 두 갈래다.

- **규칙** — 무엇을 만들 것인가. 사용자가 적는다. 체크박스가 진행 상황이다.
- **기능** — 어떻게 만들었는가. 구현하면서 내린 결정과 그 이유를 적는다.

같은 주제가 양쪽에 다 있다. 규칙 쪽은 "무엇", 기능 쪽은 "왜 그렇게" 다.
