# 상태
- [x] `player` 와 `monsters` 는 통째로 갈아 끼우지 않고 안을 고친다
  - `player = {x,y}` 로 새 객체를 만들면 그것을 붙잡고 있던 쪽이 옛 좌표를 본다.
    `player.x = x` 로 바꾸고 `monsters` 도 `length = 0` 으로 비운다
- [x] `window.__t` 로 판을 원하는 상태로 놓을 수 있게 열어 뒀다
  - 스폰이 랜덤이라 이게 없으면 "고블린이 다가오는가" 를 재현성 있게 못 본다

# 초기화와 첫 판

- [x] `saved.seen` 은 "한 번이라도 시작해 봤나" 다. 부팅 끝에서 이것만 본다
  - `reset()` 으로 고르는 화면을 세운 뒤, 처음이면 그 위에서 튜토리얼로 들어간다.
    고르는 화면을 거치므로 뒤로 물러날 자리(`지역`)가 그대로 산다
- [x] `wipeSave()` 는 **판을 먼저 걷고 나서** 지운다
  - `clearBoard()` 안에서 기록을 남긴다. 지우고 나서 걷으면 방금 지운 것이
    되살아난다. 순서가 규칙이다
  - `localStorage` 가 막혀 있어도(`try`) 이 판의 값은 지운다
