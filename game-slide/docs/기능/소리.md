# 소리
- [x] 음원 파일 없이 WebAudio 로 그때그때 만든다
  - 받아 올 것이 없어 한 파일 그대로 돌아간다. 음원을 넣으면 파일이 늘고
    CSP·경로 문제가 붙는다
  - 감쇠하는 잡음 버퍼를 대역 필터(1600Hz → 360Hz)로 훑어 "휘두르는" 소리를 낸다
  - `lunge()` 안에서 낸다. 공격이 지나는 길목이 거기 하나뿐이라 헛치는 것도 같이 잡힌다
- [x] `AudioContext` 는 처음 필요할 때 만들고, 멈춰 있으면 깨운다
  - 브라우저는 사용자가 건드리기 전에는 소리를 막는다. 공격은 늘 입력 뒤라
    그 자리에서 깨워도 된다
  - `AudioContext` 가 없는 환경(검사·오래된 브라우저)에서는 조용히 넘어간다
- [x] 상단 바에 끄고 켜는 단추
  - 끌 방법 없는 소리는 민폐다. 켤 때 한 번 소리를 내서 켜진 것이 들리게 한다
- [x] 상단 바 체력은 `renderHp()` 안에서 같이 고친다
  - `updateStatus()` 는 페이즈 끝에 한 번만 돈다. 거기서만 고치면 한 대씩
    끊어 때리는 동안 상단 바만 옛 값에 머물러, 정작 언제 깎였는지가 안 보인다
- [x] 공격 연출은 `.glyph` 를 방향대로 밀고, 피격 연출은 `.glyph` 를 줄인다
  - 토큰의 `transform` 은 자리를 잡는 데 쓰고 있어서 못 건드린다.
    스프라이트 등장(`pop`), 피격(`struck`), 돌진(`lunge-*`) 이 전부 안쪽 요소에 걸린다
  - `.token.hit .glyph` 는 class 두 개라 `.monster .glyph` 보다 우선한다.
    안 그러면 등장 애니메이션이 피격 애니메이션을 덮는다
- [x] 체력바는 토큰 안에 넣고 `em` 으로 크기를 잡는다
  - 토큰 `font-size` 가 칸 크기에 맞춰 정해지므로, `em` 이면 리사이즈를 따라간다.
    px 로 박으면 작은 화면에서 체력바가 토큰을 덮는다
- [x] 공격력은 토큰 좌상단에 아이콘 하나로
  - 칼 위에 공격력. 색 바탕 대신 아이콘을 깐다
  - 방어력을 없애면서 우상단의 방패 칸도 같이 뺐다. `defMode` 와 방패 그림
    두 장(`defence`, `defence_reflect`)은 코드에서 빠졌다. 파일은 남겨 뒀다
  - 아이콘은 64px 을 19px 로 줄여 쓴다. 4배 축소라 `image-rendering` 은
    기본값(부드럽게)이 낫다. 캐릭터 스프라이트는 1:1 언저리라 `pixelated` 를
    쓰는데, 같은 파일 안에서 배율이 달라 선택도 다르다
  - 은색 아이콘을 19px 로 줄여 쓴다. 뒤에 오는 스프라이트가 어두울 때도(기사)
    밝을 때도(고블린) 있어서 `brightness(1.35)` 로 올리고 검은 그림자로 윤곽을 잡았다
- [x] 아이콘 파일 이름을 뜻대로 맞췄다
  - `attack1`(한번공격) / `attack2`(두번공격). 예전 이름(`onesword`)은 그림 생김새라
    무엇을 뜻하는지가 안 보였다
  - `defence`, `defence_reflect` 는 방어력을 없애면서 안 쓰게 됐다. 파일은 남겨 뒀다
- [x] 어떤 그림을 쓸지는 CSS 가 아니라 상태가 정한다
  - `atkMode`/`defMode` 를 class 로 내리고(`atk-single` 등) CSS 는 class → 파일만 잇는다.
    `renderHp()` 가 체력·공방 숫자와 같은 때에 class 도 갈아 끼운다
  - 파일을 CSS 에 바로 박아 두면 상태가 늘 때마다 CSS 와 JS 를 같이 고쳐야 한다
  - 한 번에 하나만 켜지도록 `classList.toggle` 로 전부 껐다 켠다.
    안 그러면 옛 class 가 남아 두 그림이 겹친다
  - 흰 숫자에는 검은 테를 둘렀다. 은색 아이콘 위에 흰 글씨라 안 그러면 안 읽힌다
  - 값은 `renderHp()` 가 체력과 같이 고친다. 지금은 안 변하는 값이지만
    버프가 들어오면 체력과 같은 때에 갱신되어야 하고, 부르는 곳을 늘리지 않는다
  - 위(공·방) 아래(체력)로 갈라 놓아 서로 안 겹친다.
    가운데는 타격 딱지 자리라 셋이 각자 층을 쓴다
  - `tiny` 토큰에서는 감춘다. 17px 토큰에서 2.5px 로 찍혀 못 읽는다
- [x] 체력 숫자는 체력바 안에 얹는다
  - 52px 칸에 스프라이트·바·숫자를 층층이 쌓을 자리가 없다. 바를 조금 키우고
    (`.22em` → `.42em`) 그 위에 숫자를 겹쳤다. 바는 채움, 숫자는 정확한 값을 맡는다
  - 스프라이트 높이를 86% → 72% 로 줄여 자리를 냈다
    (지금은 되돌렸다. 그림은 100% 고 바가 그 위에 얹힌다)
  - 외부 띠 토큰은 17px 이라 숫자가 2.7px 로 찍힌다. `tiny` 를 붙여 숫자만 감추고
    바는 남긴다. 문턱은 `TINY_TOKEN` 30px
  - `full` 일 때 숨기던 것을 없앴다. 숫자를 보여 주는 것이 목적이라 늘 떠 있어야 한다
- [x] 피격 표시는 `filter: brightness` 로 낸다
  - `transform` 은 자리를 잡는 데 쓰고 있어 흔들거나 키울 수가 없다.
    같은 이유로 몬스터 등장 효과도 안쪽 글자에만 걸려 있다
  - 연달아 맞을 때 애니메이션이 다시 재생되도록 class 를 뗐다 붙인다
- [x] 고블린 체력은 아직 줄어들 일이 없다
  - 플레이어 공격 규칙이 없다. 그래도 규칙이 "몬스터도 현재/최대 체력" 이라
    값과 체력바는 만들어 뒀다. `damage()` 는 대상을 안 가리므로 그대로 쓸 수 있다
