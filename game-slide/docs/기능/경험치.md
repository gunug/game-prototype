# 경험치

떨어지는 것 전체(경험치·코인)를 어떻게 한 길로 묶었는지는 [[기능/드랍|드랍]] 에 있다.

- [x] 죽은 자리에서 구슬이 튀고, 닿을 때마다 오른다 (`spawnExpOrbs`)
  - `expGain()` 으로 증가율을 먼저 먹이고, 그 값을 `orbSplit()` 이 나눈다.
    구슬마다 반올림하면 10 을 +10% 로 받아도 10 이 된다
  - `addXp()` 는 구슬 하나 몫만 올린다. `gainExp()` 는 증가율을 먹여
    `addXp()` 를 부른다. 부르는 쪽은 예전 그대로다
  - 판에 직접 붙인다. 데미지 숫자와 같은 이유다. 토큰 안에 두면 그 토큰의
    쌓임 맥락에 갇혀 옆 칸으로 못 나온다
  - 연출을 끄면(`tuning.orb = 0`) 첫 `await` 전에 그 자리에서 올린다.
    검사는 구슬이 아니라 결과를 본다
  - `defeat()` 는 그 연출의 약속을 `expShow` 에 담고, 공격이 끝나기 전에
    `drainExpShow()` 로 다 기다린다. 안 기다리면 레벨업이 페이즈 끝을 놓친다
  - 중간에 `다시` 를 누르면 `phaseId` 가 달라진다. 그때는 남은 구슬을 지우고
    경험치도 안 올린다
- [x] 증가율(`expBonus`)은 `gainExp()` 안에서 한 번만 먹인다
  - 부르는 쪽이 아니라 받는 쪽에서 곱하므로, 경험치가 어디서 들어오든 같이 오른다
  - `Math.round`. 라이더(경15)를 +10% 로 잡으면 16.5 → 17
- [x] 요구량은 표가 아니라 식이다 (`expNeeded`)
  - `20 + 5*n*(n-1)/2`. 규칙의 증가량(5*n)을 누적하면 나온다.
    적어 둔 일곱 개 값과 맞는지 먼저 확인하고 넣었다
  - 표로 두면 레벨에 끝이 생긴다. 규칙이 무한레벨이라 식이어야 한다
- [x] 남는 경험치는 다음 레벨로 넘긴다. `while` 이라 한 번에 여러 레벨도 오른다
- [x] 주는 경험치(`exp`)는 `BEINGS` 표에 같이 넣었다
  - 공·방·체와 같은 자리에 있어야 새 몬스터를 넣을 때 빠뜨리지 않는다
- [x] 경험치 바는 플레이어 토큰에만 있다
  - 체력 바를 위로 올리고(bottom 5% → 14%) 그 밑에 얇은 띠를 깔았다.
    스프라이트 높이도 72% → 65% 로 줄여 겹치지 않게 했다
  - 몬스터는 경험치 바가 없으므로 체력 바를 바닥에 그대로 둔다 (`.monster .hp`)
  - 수치는 안 적는다. 대신 레벨은 상단 바에 숫자로 적는다
