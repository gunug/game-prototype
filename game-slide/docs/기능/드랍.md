# 드랍

잡으면 떨어지는 것들. 지금은 경험치와 코인 둘이다.
구슬 연출 자체는 [[기능/경험치|경험치]] 에 적어 뒀다. 여기는 둘이 같은 길을
쓰게 만든 부분만 적는다.

- [x] 무엇이 떨어지는지는 `BEINGS` 표에 있다 (`exp`, `coin`)
  - 공·방·체와 같은 자리다. 새 몬스터를 넣을 때 빠뜨리지 않으려면 한 표여야 한다
  - 없으면 0 이다. 0 이면 구슬이 하나도 안 튄다
- [x] 나는 길은 하나다 (`spawnDrop`). 다른 것은 그림과 받는 곳뿐이다
  - `DROPS` 표가 그 둘을 가른다: `cls`(붙일 클래스)와 `take`(받는 함수)
  - 새 전리품이 생기면 표에 한 줄 늘리고 `defeat` 에 한 줄 더한다
  - 예전 이름 `spawnExpOrbs` 는 없앴다. 경험치만의 것이 아니게 됐다
- [x] 시작 각을 무리마다 굴린다 (`spin`)
  - 경험치와 코인이 같은 칸에서 같이 튄다. 둘 다 0 에서 고르게 벌리면
    두 줄이 포개져 한 무리처럼 보인다
- [x] `defeat` 는 두 연출의 약속을 모두 `dropShow` 에 담는다
  - 공격이 끝나기 전에 `drainDrops()` 로 다 기다린다.
    안 기다리면 레벨업이 페이즈 끝을 놓친다
  - `expShow`/`drainExpShow` 를 이름만 바꾼 것이다. 담기는 것이 늘었다

## 코인
- [x] 고블린 5, 라이더 10 (`BEINGS.coin`)
- [x] 가진 코인은 `player.purse`. 상단 바에 `코인 n`
  - 몬스터의 `coin` 은 "주는 값", 플레이어의 `purse` 는 "가진 값" 이다.
    경험치의 `exp`/`xp` 와 같은 짝이다
  - `다시` 를 누르면 0 으로 돌아간다
- [x] 증가율은 안 먹인다
  - `expBonus` 는 경험치 전용이다. 코인을 올려 주는 카드가 아직 없다.
    생기면 `defeat` 에서 경험치와 같은 자리에 한 줄 넣는다
- [x] 구슬 대신 `images/icon/coin.png` 를 깐다 (`.orb.coin`)
  - 둥근 테와 푸른 빛을 걷어 내야 그림이 그림으로 읽힌다.
    빛은 `drop-shadow` 로 노랗게 다시 준다
  - 열 개가 모이면 큰 구슬 하나가 되는 규칙은 경험치와 같다 (`orbSplit`).
    그래서 라이더의 10 은 큰 코인 하나로 온다
- [ ] 쓸 곳이 없다. 모으기만 한다
