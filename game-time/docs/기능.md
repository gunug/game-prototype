# 기능

시간(틱) 기반 카드 전투 프로토타입.
핵심: **예고를 읽고 카드를 골라 10틱 타임라인을 채운다.**

---

## 0. 결정된 골격

- [x] 틱 기반. 한 판(라운드) = **10틱**
- [x] 공간: 연속 2D, 쿼터뷰(아이소메트릭) 렌더
- [x] 지형 무제한 · 벽 없음 (샌드박스)
- [x] 승패 없음 (시스템 테스트용)
- [x] 손패 10장 / 덱 20장 (공격 5 · 이동 4 · 회피 3 · 선회 3 · 대기 3 · 선풍 2)
- [x] 카드는 10틱을 채울 때까지 계속 낼 수 있음
- [x] 제출한 순서대로 타임라인에 기록

### 카드 틱 규칙 (단순화)

한 카드는 **틱 수 하나만** 가진다. 시전/발동/후딜로 나누지 않는다.

- 효과는 **점유 첫 틱에 바로 발동**
- 남은 틱은 **경직** (다른 카드 못 냄)
- 예외: 이동은 점유 틱 동안 **균등 활주**해서 눈에 보이게 함

> 판단: "바로 시작하고 N틱 동안 묶인다"를 그대로 옮김.
> 이동만 순간이동이면 속도감이 죽으므로 점유 틱에 걸쳐 미끄러지게 함.

### 접촉거리

- [x] 접촉거리 **0.6** — 이보다 가까이는 못 붙는다
- [x] 이동은 접촉거리에서 멈춘다 (뚫고 지나가지 않음)

> 판단: "이미 끝까지 붙음" 을 판정하려면 최소 거리 정의가 필요해서 넣음.
> 벽은 없지만 몸통끼리는 겹치지 않는다. 회피에는 상한이 없다.

### 한 틱 해소 순서

1. 모든 **이동** 적용 (플레이어·몹 동시)
2. 모든 **공격** 판정

> 판단: 이동을 먼저 처리해야 "같은 틱에 빠져나가 회피" 가 성립함.
> 예고 읽기의 재미가 여기서 나옴.

- [x] 되돌리기(마지막 카드 빼기)

- [x] 덱 비면 버림더미를 섞어 되씀

## 1-2. 소용없음 표시

낸 카드가 그 틱의 실제 상태에서 아무 일도 못 하면 **✕ 소용없음** 으로 표시한다.
판정은 계획 중에 시뮬을 미리 돌려서 한다 — 앞 카드의 결과가 뒤 카드의 판정을 바꾼다.

| 카드 | 소용없음 조건 | 사유 문구 |
|---|---|---|
| 이동 | 이미 접촉거리까지 붙음 | 이미 끝까지 붙음 |
| 공격 | 사거리 안이지만 조준각 밖 | 조준 밖 |
| 공격 · 선풍 | 사거리 밖 | 사거리 밖 |
| 회피 · 선회 | 그 틱 이후로 들어올 적 공격이 없음 | 적 공격 없음 |
| 회피 · 선회 | 그 위협이 지금도 이미 안 닿음 | 이미 위협 밖 |
| 회피 | 물러나도 위협이 여전히 닿음 | 적 사거리를 못 벗어남 |
| 선회 | 돌아도 위협이 여전히 닿음 | 적 조준을 못 벗어남 |
| 전부 | 대상이 하나도 없음 | 대상이 없음 |

> 판단: 회피와 선회는 **판정 뼈대를 하나로 쓴다**.
> `위협이 있나` → `이미 안 닿나` → `해도 여전히 닿나` 세 단계가 같고,
> "어디로 가느냐" 와 마지막 사유 문구만 다르다.
>
> 판단: 닿는지 볼 때 **사거리와 조준각을 함께** 본다.
> 그래서 몹이 딴 데를 보고 있으면 회피도 `이미 위협 밖` 이 된다.
> 축을 나눠 두면 "적이 못 맞히는데 굳이 물러나는" 낭비를 못 잡는다.

- [x] 타임라인 칸을 빗금 + 회색으로 낮추고 이름 앞에 ✕
- [x] 칸에 마우스 올리면 사유 표시
- [x] 손패 카드에 미리보기 — "지금 끝에 붙이면 소용없는가"
- [x] 남은 틱이 모자라 못 내는 카드는 판정하지 않음
- [x] 하단에 소용없는 카드 장수 요약
- [x] 행동턴 기록에도 ✕ 사유를 적음

> 판단: 손패 미리보기는 **계획 끝에 붙였을 때** 를 기준으로 본다.
> 카드는 순서대로만 쌓이므로 그게 실제로 놓일 자리와 같다.
>
> 판단: 소용없어도 **막지는 않는다**. 틱을 일부러 흘려보내는 것도 수(手) 다.
>
> 판단: 회피의 "적 공격 없음" 은 **그 틱 이후** 로 본다.
> 물러난 거리는 남은 판 내내 유지되므로, 나중 틱의 공격에도 미리 대비가 된다.
> 그래서 공격보다 앞서 놓은 회피는 쓸모있고, 공격이 지나간 뒤의 회피만 소용없다.
>
> 판단: "적 공격 없음" 을 "사거리를 못 벗어남" 보다 먼저 본다. 위협 자체가 없는 쪽이 근본이다.
>
> 판단: 지금은 **아무 몹의 공격이든** 위협으로 센다.
> 몹이 여럿이 되면 A 를 피하다 B 에게 다가가는 경우를 따로 봐야 한다.

## 2-2. 쿼터뷰 예고 시각화

타임라인 바만으로는 "어디서 어디로" 가 안 보인다.
같은 예고를 무대 위에도 그린다. **나와 몹이 똑같은 표식 어휘를 쓴다.**

- [x] 표식은 시뮬 결과에서 뽑는다. 그리는 쪽은 규칙을 다시 계산하지 않는다
- [x] 표식 색은 타임라인 칸 색과 같다 (이동 청록 · 회피 초록 · 공격 빨강)

| 카드 | 무대 표식 |
|---|---|
| 이동 | 지면 화살표 `시작 → 끝` |
| 회피 | 같은 화살표, 방향만 반대 |
| 공격 | 효과 나는 순간 위치의 **사거리 고리** + 대상까지 선 |
| 대기 | 없음 |

- [x] 공격이 닿으면 대상 발밑에 표적 고리, 안 닿으면 ✕
- [x] 소용없는 표식은 호박색 점선으로 낮춤
- [x] 표식마다 **시작 틱 번호**를 동그라미로 붙여 타임라인 칸과 잇는다
- [x] 행동턴 재생 중 지나간 틱의 표식은 흐려진다
- [x] 무대 아래 범례
- [x] 내 현재 사거리는 늘 보이는 옅은 점선 기준선

> 판단: 좌표는 **틱별 스냅숏에서 가져온다**. 이동은 `시작 틱 위치 → 끝난 틱 위치`,
> 공격은 `t+1` 위치 — 한 틱 안에서 이동이 먼저 끝난 뒤의 자리다.
> 그래서 "움직이면서 때리는" 카드가 생겨도 표식이 저절로 맞는다.
>
> 판단: 소용없음 판정을 **몹에게도** 계산한다. 쓰는 곳은 표식뿐이지만,
> 어휘를 공통으로 두려면 판정도 공통이어야 한다.

## 2-3. 카드 모양과 모션

- [x] 손패 카드를 **세로로 긴 카드 비율(5:7)** 로 바꿈
- [x] 카드 면에는 짧은 문구, 원문은 마우스를 올리면 나옴
- [x] 종류 색은 카드 **윗변 띠** 로 (타임라인 칸 색과 같음)
- [x] 손패 좌우에 **덱 무더기** 와 **무덤 무더기** 를 둠. 장수도 거기 적음
- [x] 빈 손패 자리는 점선 틀로 남김

### 카드가 도는 길

- [x] **뽑기** — 덱 무더기에서 손패 자리로 날아온다. 40ms 씩 어긋나게
- [x] **사용** — 누른 카드가 타임라인의 제 칸으로 날아가 스며든다
- [x] **무덤** — 행동턴이 끝나면 타임라인 칸에서 무덤 무더기로 날아간다

> 판단: 날아가는 것은 **유령 사본** 이다. 진짜 카드는 실제 자리에 그대로 두고,
> 화면 맨 위 층에 사본을 띄워 옮긴 뒤 지운다.
> 그래야 모션이 규칙이나 판정에 전혀 손대지 않는다.
>
> 판단: 뽑는 동안 그 자리의 실물 카드는 잠깐 숨긴다.
> 안 숨기면 카드가 둘로 보인다. 도착하면 되돌린다.
>
> 판단: 무덤으로 보낼 위치는 **상태를 고치기 전에** 잰다.
> 계획을 비운 뒤에는 타임라인에서 그 칸을 찾을 수 없다.

> 선회는 그 위에 얹는 세 번째 축.

## 4-2. 방향과 조준각

공격은 **전방향이 아니다.** 바라보는 쪽 좌우 **30도** 안에 있어야 닿는다.
사거리는 *얼마나 멀리*, 조준각은 *어느 쪽으로* 를 나눠 맡는다.

- [x] 액터마다 **방향** 을 지속 상태로 갖는다 (각도 하나)
- [x] 공격은 `거리 ≤ 사거리` **그리고** `대상까지의 각 ≤ 조준각` 일 때만 닿는다
- [x] 조준각 기본 **30도** — 방향 기준 좌우 각각 30도, 합쳐 60도 부채꼴
- [x] 공격 카드는 **조준하지 않는다**. 그 순간 바라보는 쪽으로 나갈 뿐이다

> **왜 지속 상태여야 하는가 (가장 중요한 판단)**
>
> 지금 이동·회피는 늘 대상을 기준으로 움직인다. 방향까지 매번 대상 쪽으로
> 자동 갱신하면, 적이 하나일 때 대상은 **영원히 정면**이라 조준각이 한 번도 안 걸린다.
> 규칙만 늘고 게임은 그대로다.
>
> 그래서 방향은 **특정 카드만 바꾸는 지속 상태** 로 둔다.
> 그래야 "상대가 내 정면에서 벗어났다" 가 실제로 벌어지고, 선회가 수(手) 가 된다.

### 어떤 카드가 방향을 바꾸는가

| 카드 | 방향 |
|---|---|
| 이동 | 대상 쪽으로 **갱신** (다가가며 쳐다본다) |
| 회피 | 대상 쪽으로 **갱신** (마주 본 채 물러난다) |
| 선회 | **안 바꿈** ← 이게 선회의 값이자 대가 |
| 공격 · 대기 | 안 바꿈 |

### 회피와 선회 — 공격의 두 카운터

같은 위협을 서로 다른 축으로 무력화한다. 이게 이 카드들의 존재 이유다.

| 카운터 | 무엇을 깨나 | 뒤에 남는 상태 |
|---|---|---|
| 회피 | **거리** — 사거리 밖으로 뺀다 | 방향은 그대로라 되받아칠 수 있다. 대신 멀다 |
| 선회 | **각도** — 상대 조준각 밖으로 돈다 | 거리는 그대로. 대신 내 정면에서도 상대가 빠져 되받아칠 수 없다 |

> 판단: 선회는 **거리를 지키되 조준을 버린다**, 회피는 **조준을 지키되 거리를 버린다**.
> 대칭이라 둘 다 1틱으로 둔다. 어느 쪽이 나은지는 상대 사거리와 조준각이 정한다.
>
> 확인된 값: 선회 뒤 `공격` 은 `조준 밖` 이 된다. 되찾으려면 `이동` 한 장을 더 써야 한다.
> 대신 선회 뒤에도 `선풍` 은 닿는다 — 전방위라 조준을 안 쓴다.

> 판단: 허수아비는 안 움직이므로 방향이 처음 그대로 굳는다.
> 그래서 한 번 선회하면 그 뒤로는 영영 못 맞힌다 — 표적 인형으로는 맞는 동작이다.
> 제대로 된 몹은 패턴에 **조준(방향 되돌리기)** 을 넣어야 한다.

### 전방위 공격 = **선풍**

지금까지의 조준각 없는 공격에 이름을 붙인다. **선풍**(旋風).
선회의 `선(旋)` 을 나눠 써서 "돈다" 는 뜻을 잇고, 두 글자라 다른 용어와 결이 맞는다.

- [x] **선풍** — 4틱, 사거리 1.6, 피해 3, **전방위**
- 조준이 필요 없는 대신 느리고 짧다. 선회로 못 피한다
- 대안으로 굴렸던 이름: 휘두르기 · 난무 · 돌려베기

### 늘어나는 소용없음 판정

| 카드 | 조건 | 사유 문구 |
|---|---|---|
| 공격 | 대상이 조준각 밖 | 조준 밖 |
| 선회 | 그 틱 이후로 들어올 적 공격이 없음 | 적 공격 없음 |
| 선회 | 돌아도 여전히 상대 조준각 안 | 적 조준을 못 벗어남 |

### 무대 표식에 붙일 것

- [x] 공격 고리를 **부채꼴** 로 바꾼다 (조준각만큼만 칠함)
- [x] 액터 발밑에 방향 눈금
- [x] 선회는 대상을 축으로 한 **호(arc)** 화살표
- [x] 선풍은 온전한 고리 (부채꼴이 아님을 그림으로 구분)

## 5. 첫 수치 (임시)

거리 단위 1.0 = 몸통 하나 폭.

### 플레이어

| 값 | 수치 |
|---|---|
| 체력 | 20 |
| 공격력 | 3 |
| 사거리 | 2.0 |
| 이동거리 | 1.5 |
| 접촉거리 | 0.6 |
| 회피거리 | 2.0 |
| 조준각 | 30도 (좌우 각각, 합 60도) |
| 선회각 | 45도 |
| 방어력 | 0 (미구현) |

### 카드

| 카드 | 틱 | 효과 |
|---|---|---|
| 공격 | 3 | 가까운 적이 사거리 2.0 안이면 3 피해 |
| 이동 | 2 | 가까운 적을 향해 1.5 활주 |
| 회피 | 1 | 가까운 적의 반대로 2.0 물러남 |
| 대기 | 1 | 아무것도 하지 않고 한 틱 흘림 |

| 카드 | 틱 | 효과 |
|---|---|---|
| 선회 | 1 | 가까운 적을 축으로 45도 돎. 거리 유지, 방향 안 바뀜 |
| 선풍 | 4 | 사거리 1.6 안 **모두**에게 3 피해. 전방위 |

> 판단: 선회각 45도 > 조준각 30도. 한 번 돌면 상대 부채꼴을 벗어난다.
> 이 부등호가 깨지면 선회가 카운터로 성립하지 않으므로 같이 만져야 한다.

- [x] 위 수치로 구현

> 판단: 회피는 **1틱**. 예고된 공격 틱에 정확히 겹쳐 놓아야 피해진다.
> 한 틱 안 순서가 "이동 계열 먼저 → 그다음 공격" 이라 같은 틱 회피가 성립함.
> 한 틱 늦으면 그대로 맞는다. 이 정밀 타이밍이 예고 읽기의 핵심 보상.
>
> 판단: 회피가 이동(2틱 1.5)보다 빠르고 멀다. 대신 방향이 반대라 서로 대체 불가.
> 도망친 거리는 이동으로 더 느리게 되갚아야 하므로 값이 치러진다.
>
> 예외: 대상이 없거나 완전히 겹치면 회피는 +x 방향으로 물러난다.
>
> 판단: **대기** 는 타이밍 미세조정 카드다. 뒤 카드를 한 틱씩 밀어
> 예고된 공격 틱에 정확히 겹치게 만든다. 이게 없으면 카드 틱 수의
> 배수로만 정렬이 되어 예고 읽기가 뻑뻑해진다.
>
> 판단: 대기는 **소용없음 판정을 받지 않는다**. 아무것도 안 하는 게 그 카드의 일이다.
>
> 판단: 손패 10장이면 덱 10장은 전부 손에 들어와 무작위가 사라진다.
> 그래서 덱을 15장으로 늘렸다. 한 판에 4~6장쯤 내므로 세 판이면 한 바퀴 돈다.
