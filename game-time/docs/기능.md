# 기능

시간(틱) 기반 카드 전투 프로토타입.
핵심: **예고를 읽고 카드를 골라 10틱 타임라인을 채운다.**

---

## 0. 결정된 골격

- [x] 틱 기반. 한 판(라운드) = **10틱**
- [x] 공간: 연속 2D, 쿼터뷰(아이소메트릭) 렌더
- [x] 지형 무제한 · 벽 없음 (샌드박스)
- [x] 승패 없음 (시스템 테스트용)
- [x] 손패 5장 / 덱 10장 (공격 4 · 이동 3 · 회피 3)
- [x] 카드는 10틱을 채울 때까지 계속 낼 수 있음
- [x] 제출한 순서대로 타임라인에 기록

### 카드 틱 규칙 (단순화)

한 카드는 **틱 수 하나만** 가진다. 시전/발동/후딜로 나누지 않는다.

- 효과는 **점유 첫 틱에 바로 발동**
- 남은 틱은 **경직** (다른 카드 못 냄)
- 예외: 이동은 점유 틱 동안 **균등 활주**해서 눈에 보이게 함

> 판단: "바로 시작하고 N틱 동안 묶인다"를 그대로 옮김.
> 이동만 순간이동이면 속도감이 죽으므로 점유 틱에 걸쳐 미끄러지게 함.

### 접촉거리

- [x] 접촉거리 **0.6** — 이보다 가까이는 못 붙는다
- [x] 이동은 접촉거리에서 멈춘다 (뚫고 지나가지 않음)

> 판단: "이미 끝까지 붙음" 을 판정하려면 최소 거리 정의가 필요해서 넣음.
> 벽은 없지만 몸통끼리는 겹치지 않는다. 회피에는 상한이 없다.

### 한 틱 해소 순서

1. 모든 **이동** 적용 (플레이어·몹 동시)
2. 모든 **공격** 판정

> 판단: 이동을 먼저 처리해야 "같은 틱에 빠져나가 회피" 가 성립함.
> 예고 읽기의 재미가 여기서 나옴.

---

## 1. 라운드 흐름

- [x] **예고** — 시간 멈춤. 몹의 10틱 타임라인 확정·공개
- [x] **플레이** — 시간 멈춤. 손패에서 카드를 순서대로 놓아 10틱 채움
- [x] **행동턴** — 틱 0→9 순차 재생, 애니메이션
- [x] **드로우** — 손패 5장까지 보충

- [x] 남은 틱보다 큰 카드는 못 냄
- [x] 되돌리기(마지막 카드 빼기)
- [x] 다 안 채워도 확정 가능 (남은 틱은 대기)
- [x] 덱 비면 버림더미를 섞어 되씀

---

## 1-2. 소용없음 표시

낸 카드가 그 틱의 실제 상태에서 아무 일도 못 하면 **✕ 소용없음** 으로 표시한다.
판정은 계획 중에 시뮬을 미리 돌려서 한다 — 앞 카드의 결과가 뒤 카드의 판정을 바꾼다.

| 카드 | 소용없음 조건 | 사유 문구 |
|---|---|---|
| 이동 | 이미 접촉거리까지 붙음 | 이미 끝까지 붙음 |
| 공격 | 그 틱에 가까운 적이 사거리 밖 | 사거리 밖 |
| 회피 | 물러나도 그 적의 사거리 안 | 적 사거리를 못 벗어남 |
| 전부 | 대상이 하나도 없음 | 대상이 없음 |

- [x] 타임라인 칸을 빗금 + 회색으로 낮추고 이름 앞에 ✕
- [x] 칸에 마우스 올리면 사유 표시
- [x] 손패 카드에 미리보기 — "지금 끝에 붙이면 소용없는가"
- [x] 남은 틱이 모자라 못 내는 카드는 판정하지 않음
- [x] 하단에 소용없는 카드 장수 요약
- [x] 행동턴 기록에도 ✕ 사유를 적음

> 판단: 손패 미리보기는 **계획 끝에 붙였을 때** 를 기준으로 본다.
> 카드는 순서대로만 쌓이므로 그게 실제로 놓일 자리와 같다.
>
> 판단: 소용없어도 **막지는 않는다**. 틱을 일부러 흘려보내는 것도 수(手) 다.

## 2. 타임라인 바 (핵심 UI)

- [x] 10틱 = 10칸으로 표시
- [x] 몹 바와 내 바를 **세로로 겹쳐** 같은 틱이 같은 열에 오게
- [x] 카드가 점유한 틱은 한 덩어리로 칠함 (예: 이동 2칸, 공격 3칸)
- [x] 행동턴 중 현재 틱을 강조
- [x] 몹이 여럿이면 몹 바를 여러 줄로 쌓음

---

## 3. 대상 지정

- [x] `가까운` — 가장 가까운 적 (우선 구현)
- [x] 카드 설명문에 대상 단어를 명시 (예: "가까운 적에게")

> 판단: 이동 방향은 **카드 시작 틱에 고정**. 매 틱 재조준하지 않음.
> 유도되면 계획이 안 서고, 계획 게임이 아니게 됨.

---

## 4. 용어 (카드 문구의 핵심 단어)

| 용어 | 뜻 | 상태 |
|---|---|---|
| 이동 | 대상을 **향해** 감 | 구현 |
| 회피 | 대상의 **반대로** 감 | 구현 |
| 선회 | 대상을 **축으로 옆으로** 돎 | 미구현 |
| 방어 | 피해 감소 | 미구현 |

- [x] 이동
- [x] 회피
- [ ] 선회 — 적이 여럿 배치되므로 옆걸음이 실제 의미를 가짐
- [ ] 방어

> 메모: 적이 여러 방향에 배치되면 이동/회피만으로도 축이 하나가 아님.
> 선회는 그 위에 얹는 세 번째 축.

## 5. 첫 수치 (임시)

거리 단위 1.0 = 몸통 하나 폭.

### 플레이어

| 값 | 수치 |
|---|---|
| 체력 | 20 |
| 공격력 | 3 |
| 사거리 | 2.0 |
| 이동거리 | 1.5 |
| 접촉거리 | 0.6 |
| 회피거리 | 2.0 |
| 방어력 | 0 (미구현) |

### 카드

| 카드 | 틱 | 효과 |
|---|---|---|
| 공격 | 3 | 가까운 적이 사거리 2.0 안이면 3 피해 |
| 이동 | 2 | 가까운 적을 향해 1.5 활주 |
| 회피 | 1 | 가까운 적의 반대로 2.0 물러남 |

- [x] 위 수치로 구현

> 판단: 회피는 **1틱**. 예고된 공격 틱에 정확히 겹쳐 놓아야 피해진다.
> 한 틱 안 순서가 "이동 계열 먼저 → 그다음 공격" 이라 같은 틱 회피가 성립함.
> 한 틱 늦으면 그대로 맞는다. 이 정밀 타이밍이 예고 읽기의 핵심 보상.
>
> 판단: 회피가 이동(2틱 1.5)보다 빠르고 멀다. 대신 방향이 반대라 서로 대체 불가.
> 도망친 거리는 이동으로 더 느리게 되갚아야 하므로 값이 치러진다.
>
> 예외: 대상이 없거나 완전히 겹치면 회피는 +x 방향으로 물러난다.
