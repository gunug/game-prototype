# 아이콘 목록 — 카드 월드 RPG 2

> **v0.3.1** 기준. world2 화면에 실제로 나오는 그림만. `tools/make_icon.py`가 생성에 성공할 때마다 이 파일에 기록을 갱신한다 (같은 파일명은 덮어씀).
> 다시 뽑기: `python tools/make_icon.py --force --name <파일명> --label "<한글>" [--bg white] --prompt "<프롬프트>"` — 사물은 앞에 OBJECT 머리말 (레거시 `game-card-world/docs/아이콘_프롬프트.md` 규칙)
> 돌·부싯돌·열매·나무 프레임은 레거시 그림을 복사해 씀. 나무·풀은 world2에서 새로 뽑아 덮어씀 (레거시 그림은 통나무·마른 풀).
> 폴더에 남은 나머지 레거시 그림은 지금 안 씀.
> 필드 그림 4장(산·숲·강가·초원)은 v0.7.2에 새로 뽑음 (레거시의 산·강가 그림은 덮어씀). 강가·초원은 첫 결과에 사람 머리가 나와 다시 뽑음.
> **2티어 16장은 그림 없음** (v0.5.0, 이모지로 대신). 확정 후 생성.
