# 조합 고민 (2026-10-28 ~ 29 · 상담 기록)

> **전부 미확정.** 결정한 것은 없다. 다음 고민을 위해 지금까지의 생각을 남긴다.

## 1. 지금 상황

- 재료 151종 · 조합식 137 · 만들기 판 8 (조합 · 무기 · 갑옷 · 방패 · 장신구 · 도구 · 음식 · 약품)
- 두 판 넘게 쓰이는 재료 44 · 앞 단계 재료가 다른 판에 있는 조합식 18 → 판을 오가야 한다
- 폰에서 판이 꽉 차서 갈래로 나눴더니, 이제는 판이 많아 오가기가 잦다
- 조합법을 알려 주고 빛까지 내 주는 **강한 가이드** → 끌어 합치기가 '소개글대로 두 장 합치기'만 남았다

## 2. 흘러온 길 (사용자 설명)

1. 조합이 메인인 게임이었다. 조합이 적을 땐 헤매는 것도 재미였다.
2. 조합이 늘고 '조합 안 되는 카드'가 늘자 가이드 없이 헤매는 비중이 너무 커져 조합을 완성할 수 없었다.
3. 가이드를 넣었다. 가이드가 강해질수록 조합을 '찾는' 의미가 사라졌다.
4. **"알아냈다"의 쾌감은 없어진 지 오래.** 있는지도 모르는 것을 위해 재료를 구하는 건 동기가 안 생긴다.

## 3. 진단

- **수학의 벽**: 카드 n장이면 짝은 n² 으로 늘고 맞는 조합은 n 만큼만 는다. 151장이면 짝 1만+ 중 137 — 무작위로 맞을 확률 약 1%. 조합 발견형은 커지면 누구나 부딪힌다. 설계 실수가 아니라 장르의 한계
- **재미는 끌기가 아니라 짐작이 맞는 순간**이었다 (부싯돌 + 나무 → 도끼겠지 → 됨). 끌기는 그 확인 손짓일 뿐
- 지금 조합은 **목록**(외워야 앎)이다. 목록은 커질수록 무너진다

## 4. 진짜 엔진 = 목표 탭 (사용자 설명으로 드러남)

```
있다는 걸 안다 → 갖고 싶다 → 어떻게 만들지? → 목표 등록 → 움직인다
```

- 목표 탭은 이미 두 여정을 나눠 준다
  - 본 적 없는 재료 = **???** 실루엣 → **정체를 밝히러 가는** 여정
  - 아는 재료 = 그림이 보임 → **직접 가지러 가는** 여정
- 가이드가 강해진 것은 실패가 아니라, 게임이 원래 가고 싶던 쪽('갖고 싶음' 중심)으로 기운 것으로 볼 수 있다
- 그러면 "어떻게 만들지?"의 답은 '무엇과 무엇을 합치나'가 아니라 **'어디서, 무엇을 이기고 얻나'** — 조합표는 퍼즐이 아니라 길을 그린 지도

## 5. 생각해 본 방향들 (미확정)

### 5-1. 목록 → 규칙 (조합 찾기를 살리는 길)
- `날카로운 것 + 자루 = 무기` · `가죽 + 끈 = 갑옷` · `고기 + 불 = 음식` 처럼 규칙 몇 개
- 재료가 늘어도 규칙은 안 는다 → 처음 보는 재료도 짐작 가능 → 가이드 없이 버틴다
- 카드에 성질 꼬리표(날카로움 · 질김 · 탐 …)가 단서
- 같은 규칙이라도 재료 성질로 결과가 달라지면 '고르는 재미'까지
- 걸림: 조합표를 통째로 다시 짜야 한다. 사용자는 '알아냈다' 쾌감이 이미 없다고 했으므로 우선순위는 낮아 보임

### 5-2. 조합을 내려놓기 (재료를 모으면 결과로 바꿔 줌)
- 사냥형 게임처럼 만들기는 '바꿔 주는 창구', 재미는 얻으러 가는 길에 둔다
- 걸림: 지금 원정은 자동 전투 · 같은 땅 반복이 길다 → 조합을 빼면 "돌고 받고 바꾸고"만 남아 비어 보일 위험
- 전제: '갖고 싶다'와 '가졌다' 사이에 **시간이 아니라 판단**이 서 있어야 한다
  - 재료가 있는 땅의 수호자를 못 이긴다 → 파티를 어떻게 짜나
  - 곰 가죽 하나로 갑옷도 방패도 된다 → 무엇을 먼저 (두 판 이상 재료 44개가 이미 갈림길)
  - 드문 재료 → 누구에게 먼저

### 5-3. 끌기 = 완성 의식
- 퍼즐이 아니라 '갖고 싶던 바로 그것'을 만드는 마지막 순간의 의식으로 남긴다 (연출을 크게)
- 중간 단계(자루 · 날 …)는 가볍게 — 한 번 만든 조합은 버튼 반복 등
- 처음 만드는 조합만 끌기, 그 뒤는 '만들기 ×N' 버튼 안도 이야기됨

### 5-4. 그 밖에 나온 안 (앞 상담)
- 보조 수준: 지금 그대로 / 단서만(장인 대사 · 따뜻함·차가움) / 장인이 제 갈래 1~2단계만 / 목표로 건 것만 보조
- 재료 통칭: '가죽 아무거나' — 땅마다 통칭 2~3 + 그 땅만의 재료 1 → 151 → 60~70 (큰 공사)
- 만들기 탭: 한 탭 + 갈래 칩 7 / 관련 재료만 / 한 탭 + 칩 + 탭하면 아는 짝만 빛남 / 지금처럼 8

## 6. 가장 지루한 곳 = 확률 반복

- 사용자: 목표를 걸고 움직일 때 **확률 때문에 다시 도는 반복**이 가장 지루하다. 하지만 바로바로 나오면 의외성이 없어 튜토리얼 클릭 게임이 될 것 같다
- 시뮬에서도 가장 긴 반복은 헤이든 합류 때 산 반복 28~34분 (측정.md §7)

### 확률의 두 종류
- **거절하는 확률** (지금): 목표가 정해져 있다 → 갔다 → 안 나옴 → 또 감. 의외성이 아니라 허탕. 플레이어가 할 수 있는 게 없다
- **덤을 주는 확률**: 목표는 나오고, 뜻밖의 것이 하나 더 붙는다. 이게 의외성
- → 의외성을 없애는 게 아니라 **거절에서 덤으로 옮기는** 것

### 반복을 줄이되 결과는 흔들리게 (미확정 안)
1. **헛걸음이 쌓인다** — 못 얻을 때마다 확률이 오르고 3번째쯤엔 반드시. 보여 줘도 좋다 ("늑대 송곳니 — 다음엔 꼭")
2. **조각** — 안 나와도 조각 1, 3개면 하나. 운 좋으면 통째로
3. **판단이 확률을 바꾼다** — 그 재료를 지닌 놈을 노리면 오른다 · 장인을 데려가면 잘 벗긴다 (마르그 → 가죽). 반복이 '운 기다리기'에서 '판 짜기'로
4. **의외성은 길 위로** — 목표 재료는 거의 확실히, 대신 드문 놈 · 흔적 · 질 좋은 재료(그냥 가죽 / 좋은 가죽)가 흔들린다
- 상담 중 의견: 3 + 1 이 가장 맞아 보임 · 4 가 '클릭 게임' 걱정의 답 · 1 만 넣어도 헤이든 구간이 줄어 시뮬로 바로 잴 수 있다

## 7. 열린 질문

- 이 게임의 중심을 '갖고 싶은 것을 향해 길을 뚫는 게임'(만들기 = 지도 · 원정 = 벽 · 파티 = 벽을 넘는 수단)으로 둘 것인가
- 끌기는 의식으로 남기나, 줄이나, 빼나
- 원정에서 **좋은 쪽으로 놀란 순간**은 무엇이었나 — 덤 확률로 키울 씨앗
- '누구를 데려가면 무엇이 잘 나온다'가 생기면 파티 고르기가 채집 위주로 기울 수 있다 — 괜찮은가, 파티는 전투용으로 남길 것인가
- 존재를 알려 주는 순간(적이 쓰는 무기 · 장인의 대표작 · 콜렉터북 그림자 …)을 더 늘릴 것인가
