# 화면 구조 — 카드 월드 RPG 2

> 2026-09-18 사용자 확정, **v0.16.0에서 구현**. 실제 동작은 `게임_규칙.md` 1절.
> 화면을 **필드 · UI · 팝업** 세 부분으로 나눈다.

## 1. 필드 부분 — **1:1 비율**
- 가로 화면이든 세로 화면이든 **정사각형**. 모바일에서 손으로 쓰기 좋은 크기로 잡는다.
- 이 자리에 번갈아 들어오는 화면 셋

| 화면 | 내용 |
|---|---|
| **전투 화면** | 원정 트랙 — 기사 · 토끼 · 보스 · 채집 포인트 |
| **채집 장소 화면** | 필드 카드 4곳 (산 · 초원 · 숲 · 강가) |
| **크래프팅 카드 화면** | 카드를 놓고 끌어 조합하는 판 |

## 2. UI 부분 — **남는 공간**
- 필드(정사각형)를 뺀 나머지를 쓴다. 가로 화면이면 **오른쪽에 세로로 길게**, 세로 화면이면 **아래에 가로로 길게**.
- 들어가는 것

| UI | 내용 |
|---|---|
| **퀘스트** | 지금 할 일 · 진행 수 |
| **인스펙터** | 고른 카드 · 필드 · 기사 정보 |
| **설정 패널 · 버튼** | 설정, **채집 / 크래프팅 전환 버튼** |

## 3. 팝업 부분 — **1:1 비율, 덮는 레이어**
- 화면이 가로든 세로든 **정사각형**으로, 필드·UI 위에 **레이어로 덮여** 올라온다.
- 지금 여기 들어가는 것: **콜렉터북**

---

## 구현 (v0.16.0)
- 크기는 JS `layout()`이 잰다. **UI가 최소 240px**을 가져가고 나머지에서 정사각형을 잡는다.
  - 가로 화면: 필드 한 변 = `min(높이, 너비 − 240)`, 왼쪽에 세로 가운데 정렬. UI는 오른쪽 전체
  - 세로 화면: 필드 한 변 = `min(너비, 높이 − 240)`, 위쪽에 가로 가운데 정렬. UI는 아래 전체
  - 필드 한 변은 최소 220px
- **카드 크기도 필드 기준**: 한 변 ÷ 6.4 (44~87px), 세로는 1.36배
- UI는 위에서부터 **퀘스트 줄 · 인스펙터(남는 높이, 스크롤) · 버튼 줄**
- 버튼 줄: `🧺 채집` · `🔨 크래프팅` · `📖`(새 카드 수 뱃지) · `⚙`
- `⚙` → 버튼 줄 위로 **설정 패널**: 발견 수 · 처음부터 · 버전. 바깥을 누르면 닫힘
- 상단 막대는 없앰 (내용은 전부 UI로 옮김)
- 콜렉터북은 화면 짧은 변의 **92% 정사각형**, 한가운데에서 커지며 덮임 (뒤는 어둡게)
- 알림은 필드 위쪽 가운데에 뜸

## 옮기기 전 모습 (v0.15.2까지)
- 지금은 필드가 정사각형이 아니라 남는 공간을 전부 채운다 (`.table` · `.gather`가 좌우 끝까지).
- 지금 인스펙터는 가로 화면 오른쪽 22vw · 세로 화면 아래 28vh로 따로 잡혀 있고, 퀘스트 줄은 상단 막대 아래 32px 띠다. → **UI 부분 하나로 합쳐야 한다.**
- 탭 줄(채집 · 크래프팅)이 상단 막대에 있다. → **UI 부분의 버튼으로 옮긴다.**
- 콜렉터북은 아래에서 올라오는 모달(최대 높이 82vh)이다. → **1:1 레이어로 바꾼다.**
- 설정 패널은 아직 없다.
