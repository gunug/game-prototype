# 기능 — 카드 월드 RPG 2

> 설계 원문은 `card-world-rpg` 저장소의 `00_확정사항.md`. 이 문서는 프로토타입에 구현할 범위만 적는다.
> `game-card-world`(v0.147.1)는 **레거시** — 더 고치지 않는다. 2는 그 설정·조합식·그림·카드 모양을 복사해 새로 시작한다.
> 구현된 규칙 정리: `게임_규칙.md` · `카드_목록.md` · `조합식.md` · `아이콘_목록.md` (구현된 것만 적음)
> 구현은 했지만 **플레이 검증 전**이라 체크하지 않았다. 플레이로 확인한 항목부터 체크한다.

## 0. 방향 (v0.1.0)
- 필드 하나에 전부 올리던 레거시 대신 **탭으로 나눔**. 이번엔 **크래프팅 탭만** 만든다.
- 앞으로의 방향 (상상 단계, 아직 구현 안 함)
  - 재료를 장소·quest에 직접 넣는 행동 없앰
  - quest는 카드가 아니라 **상단 글 + 수량**. 재료 탭에서 모으거나 만들면 완료
  - "모든 것은 카드" 포기 — 많은 카드를 UI로
  - 장비는 캐릭터 탭의 **무기 버튼 → 드롭다운**

## 1. 복사해 온 것
- [ ] 카드 정의(`DEFS`) · 설명(`DESC`) · 조합식(`RECIPES`) · 태그 레벨 규칙(`tagLevel`, `sideMatch`, `usableRecipes`) — 레거시 v0.147.1 그대로
- [ ] 그림: `images/icon`, `images/frame`, `images/portrait`
- [ ] 카드 모양: 크기 공식(짧은 변 ÷ 7.375, 57~87px, 세로 1.36배), 프레임(캐릭터 금·장소 돌·나머지 나무), 조합 대상 테두리, 등장·튕김·사라짐 연출, 알림
- [ ] 월드 최대 생성 `SPAWN_CAP = 3` — 같은 카드가 3장 있으면 더 생성 안 됨, 빠진 것은 `누락:` 알림
- [ ] 저장 키는 레거시와 따로 (`card-world2.v1`)

## 2. 화면
- [ ] 상단 막대: 제목 · 탭 줄(**크래프팅** 하나) · 발견 수 · 처음부터 · 버전
- [ ] 가운데 필드, 인스펙터는 가로 화면 오른쪽 / 세로 화면 아래 (레거시와 같은 자리)
- [ ] 필드 왼쪽 아래 **신의 선물** 버튼, 오른쪽 아래 **버리기** 칸

## 3. 크래프팅 탭
- [ ] 크래프팅 탭에 올라오는 카드 = 재료 · 음식 · 도구 · 불 · container · 지도 (캐릭터·크리처·장소·quest·package 없음)
- [ ] **신의 선물** 버튼 → 5장 무작위 (가중치 풀). 상한에 걸린 카드는 `누락:`
  - 판단: 풀에서 토끼(크리처) 뺌. 사냥·산·강가가 없으므로 **토끼 사체 · 나무 · 오징어 사체**를 풀에 넣음
- [ ] 카드를 끌어 다른 카드에 놓으면 조합 (레거시 조합식 그대로, 익히기·태우기 포함)
  - 끄는 동안 조합되는 카드에 노란 테두리
  - `keep` 쪽(도구·불)은 남고 나머지는 사라짐. 결과는 놓은 자리 옆에 튀어나옴
  - 재료가 사라진 뒤 상한을 셈. 결과가 하나도 못 나오면 조합 안 됨 (재료 그대로, 빨간 깜빡임)
  - 판단: 한 조합에 맞는 조합식이 여럿이면 첫 번째
- [ ] 조합이 없는 카드에 놓으면 옆으로 비켜 놓임
- [ ] **버리기** 칸에 놓으면 카드 사라짐 (되돌리기 없음)
- [ ] 처음 본 카드는 `새 카드` 알림 + 발견 수 증가
- [ ] 카드 탭 → 인스펙터: 그림 · 이름 · 설명 · 태그 · 공격력/방어 · **쓰이는 조합**(결과는 발견 전이면 ???) · **만드는 법**(발견한 카드만)
  - 판단: 부실한 자루는 담기 기능 없이 카드로만 (담기는 다음 탭 설계 때)
  - 판단: 풀 깔개·모닥불은 장소 태그가 있어도 크래프팅 카드로 둠 (돌 프레임). 장소가 없어지는 조합(태우기)은 레거시처럼 안 됨
  - 판단: 인질 → 건축가 조합은 캐릭터가 없어 크래프팅 탭에선 안 보임

## 4. 끌 때 흐려짐 (v0.1.1)
- [ ] 카드를 끌기 시작하면 **그 카드와 조합이 안 되는 카드는 흐려짐** (어둡고 저채도, 레거시 '흐려짐'과 같은 모양)
  - 조합되는 카드는 그대로 + 노란 테두리. 놓으면 원래대로

## 5. 밀어내기 · 조합 하이라이트 없앰 (v0.2.0)
- [ ] **카드끼리 서로 밀어냄** — 겹치면 덜 겹친 축(가로/세로)으로 양쪽이 반씩 벌어짐, 틈 4px. 매 프레임 조금씩 (부드럽게)
  - 끄는 중인 카드는 밀지도 밀리지도 않음 (조합 대상 위에 올릴 수 있게). 놓으면 그때부터 밀어냄
  - 필드 벽에 붙은 카드는 못 밀리고 반대쪽 카드가 더 밀려남
  - 예전의 "옆 빈자리로 미끄러짐"(조합 안 될 때·조합 뒤 남는 카드·상한 실패) 없앰 → 밀어내기가 대신함
  - 밀려난 뒤 0.5초 조용하면 저장
  - 판단: 새로 나오는 카드는 여전히 빈자리를 찾아 나옴
- [ ] **조합되는 카드의 노란 테두리·번쩍임 없앰** — 끌 때는 조합 안 되는 카드가 흐려지는 것만으로 구분
  - 판단: 새 카드 노란 깜빡임(3초)·상한 실패 빨간 깜빡임은 그대로

## 6. 새 카드 하이라이트 (v0.2.1)
- [ ] 새 카드 표시(3초)를 깜빡임 대신 **예전 조합 대상 하이라이트 모양**으로 — 노란 테두리가 숨쉬듯 퍼졌다 좁아짐 (0.5초 왕복)
  - 판단: 상한 실패 빨간 깜빡임은 그대로

## 7. 제작 성공 깜빡임 복구 (v0.2.2)
- [ ] **조합으로 나온 카드는 3초 동안 노란 테두리 깜빡임** (레거시 모양, 0.5초 간격 켜짐/꺼짐) — 새 카드가 아니어도 매번
  - 신의 선물로 나온 새 카드는 6절 하이라이트(숨쉬는 테두리)
  - 판단: 조합으로 나온 카드가 새 카드이기도 하면 **깜빡임이 우선** (둘 다 테두리라 하나만). 새 카드 알림은 그대로 뜸

## 8. 새 카드 하이라이트 없앰 (v0.2.3)

  - 조합으로 나온 카드의 제작 성공 깜빡임(7절)은 그대로

## 9. 1티어 원물 12장 · 콜렉터북 (v0.3.0)
> 확정 48 (card-world-rpg): 1티어 = 자연에서 얻는 원물 + 2티어 재료. 필드마다 3종
- [ ] **레거시 카드·조합식을 모두 뺌** — 카드는 1티어 12장뿐, 조합식 없음 (2티어 설계 후 채움)
  - ⛰️ 산: 돌 · 부싯돌 · 광석 / 🌲 숲: 나무 · 열매 · 수액 / 🏞️ 강가: 물 · 흙 · 모래 / 🌾 초원: 풀 · 짐승 · 씨앗
  - 카드마다 티어·필드 값, 새 설명 12줄
  - 판단: 예전 저장의 레거시 카드는 불러올 때 버림 (돌·부싯돌·열매·나무·풀은 id가 같아 발견 기록이 남음)
  - 판단: 조합 처리 코드(3장 제한·제작 성공 깜빡임)는 남겨 둠. 조합식이 없어서 끌면 다른 카드가 전부 흐려짐
- [ ] **신의 선물은 1티어만**, 12장 모두 같은 확률
- [ ] **새 그림 8장** (ComfyUI): 광석 · 수액 · 물 · 흙 · 모래 · 풀 · 짐승 · 씨앗. **나무**도 통나무 → 살아 있는 나무로 새로 뽑음. 돌 · 부싯돌 · 열매는 레거시 그림 그대로
  - 생성 도구를 `tools/make_icon.py`로 복사 (결과·기록이 world2 폴더에 남게, 레거시 안 건드림). 이번 일괄 생성은 `tools/gen_tier1.sh`
  - 흙은 사람 모양으로 두 번 나와 머리말을 더 붙여 다시 뽑음
- [ ] **콜렉터북** — 상단 📖 버튼으로 여닫음, 필드 자리를 덮음
  - 티어 탭 (지금은 1티어만) · 발견 n/12
  - 필드별 묶음 (산 · 숲 · 강가 · 초원) 3칸씩, 미발견은 검은 실루엣 + ???
  - 칸 탭 → 인스펙터 (미발견이면 ??? · 티어 · 필드만)
  - 판단: 미발견이어도 필드 이름은 보임 (어디서 나오는지 힌트)
- [ ] 인스펙터: `1티어 · ⛰️ 산` 표시, 종류·태그 줄 없앰
- [ ] 안내 글: 신의 선물 · 콜렉터북 안내로 바꿈

## 11. 콜렉터북 모달 · 슬리브 끼우기 (v0.4.0)
- [ ] 콜렉터북을 **화면 아래에서 올라오는 모달**로 — 뒤는 어둡게 가림, 최대 높이 82vh, 위쪽 둥근 모서리 + 손잡이 막대
  - 닫기: ✕ · 어두운 뒤쪽 탭 · 상단 📖 버튼 (모달이 상단 막대를 가리므로 실제로는 앞의 둘)
  - 카드 칸 → **슬리브**(투명 비닐 주머니). 앞면 아래 58%에 덮개가 카드 위로 겹쳐 '끼워진' 모양
  - 판단: 모달이 인스펙터를 가리므로, 슬리브를 탭하면 **책 위쪽 설명 줄**에 이름 · 티어 · 필드 · 설명 (미발견이면 ???). 인스펙터로 보내지 않음
- [ ] **새 카드를 발견하면 콜렉터북이 열리고, 그 슬리브에 카드가 위에서 아래로 끼워짐**
  - 순서: 모달 올라옴(0.42초) → 그 티어로 바꾸고 슬리브가 보이게 스크롤 → 실루엣이 흐려지며 빠지고 카드가 위에서 쑥 내려와 끼워짐(0.7초) + 슬리브 노란 빛 퍼짐 → 1초 뒤 다음 카드
  - 신의 선물 한 번에 새 카드가 여럿이면 **차례로 하나씩** 끼움
  - 끼우기 전까지 그 슬리브는 실루엣 · 발견 수에도 안 셈
  - 다 끼우면 0.25초 뒤 닫힘. 원래 열어 둔 상태였으면 열린 채로 둠
  - `✨ 새 카드` 알림은 모달 위에 보이게 올림
- [ ] **끼우는 동안 게임 일시정지**
  - 필드 카드 끌기 · 밀어내기 멈춤, 필드 카드 연출(튀어나옴 등)도 멈춤
  - 콜렉터북 닫기(✕ 흐려짐) · 탭 · 슬리브 탭 · 처음부터 막힘
  - 판단: 끌던 카드가 있으면 그 자리에 놓고 멈춤 (발견은 신의 선물·조합 때라 실제로는 거의 없음)
