# 카드 목록 — 카드 월드 RPG 2

> **v0.5.1** 기준. 구현된 카드만. 티어표 원문은 `card-world-rpg/00_확정사항.md` 48절.
> 1티어는 확정. **2티어 16장은 추천안을 그대로 넣은 체험용 (미확정)**.
> 그림: 1티어는 `images/icon/card_<id>.png`, 2티어는 그림 없이 이모지.

## 2티어 (16장) — 1차 가공품

| 묶음 | id | 이름 | 이모지 | 만드는 법 | 설명 (인스펙터) |
|---|---|---|---|---|---|
| 🛠️ 도구 · 불 | `blade` | 날돌 | 🔪 | 돌 + 돌 | 돌이 돌을 때렸다. 이긴 쪽이 날이 됐다. |
| 🛠️ 도구 · 불 | `whetstone` | 숫돌 | 🪨 | 모래 + 돌 | 모래에 문질러 매끈해진 돌. 이제 남을 매끈하게 만든다. |
| 🛠️ 도구 · 불 | `ember` | 불씨 | 🔥 | 부싯돌 + 석탄 | 작고 뜨겁고 쉽게 삐진다. 입김은 살살. |
| 🛠️ 도구 · 불 | `firewood` | 장작 | 🪵 | 돌 + 나무 | 나무였을 땐 그늘이었고, 이제는 온기가 될 차례. |
| 🧱 건축 재료 | `clay` | 점토 | 🟤 | 물 + 흙 | 물과 흙이 손잡았다. 모양은 네가 정해라. |
| 🧱 건축 재료 | `cord` | 노끈 | 🧶 | 풀 + 풀 | 풀도 꼬면 쓸모가 생긴다. 사람도 그렇다던데. |
| 🧱 건축 재료 | `wax` | 밀랍 | 🕯️ | 돌 + 벌집 | 벌들이 공들여 지은 집의 벽. 미안하게 됐다. |
| 🧱 건축 재료 | `crushedore` | 부순 광석 | ⛏️ | 돌 + 광석 | 부숴 보니 반짝이는 게 조금 더 많아졌다. |
| 🍖 음식 | `meat` | 날고기 | 🥩 | 부싯돌 + 짐승 | 아직은 짐승이었던 기억이 남아 있다. |
| 🍖 음식 | `fillet` | 생선살 | 🍣 | 부싯돌 + 물고기 | 뼈를 발라냈더니 표정이 사라졌다. |
| 🍖 음식 | `honey` | 꿀 | 🍯 | 돌 + 벌집 | 끈적한 행복. 손가락이 먼저 찾아간다. |
| 🍖 음식 | `flour` | 곡물 가루 | 🥣 | 돌 + 씨앗 | 빻아서 고와졌다. 재채기 조심. |
| 🧪 몸 · 약 | `hide` | 가죽 | 🧤 | 부싯돌 + 짐승 | 털은 짐승에게, 가죽은 우리에게. |
| 🧪 몸 · 약 | `bone` | 뼈 | 🦴 | 부싯돌 + 짐승 | 짐승의 뼈대 있는 유산. |
| 🧪 몸 · 약 | `juice` | 열매즙 | 🧃 | 열매 + 물 | 열매를 물에 설득했더니 색이 우러났다. |
| 🧪 몸 · 약 | `salve` | 약초 연고 | 🧴 | 약초 + 수액 | 쓴 약초를 끈적한 수액이 달래 준다. 바르면 좀 낫다. |

- 모든 카드: 종류 재료, 나무 프레임, 태그·수치 없음
- 필드(1티어)·묶음(2티어)은 콜렉터북 묶음과 인스펙터 표시에만 쓰임
- 신의 선물에서는 1티어만 나옴. 2티어는 조합으로만
