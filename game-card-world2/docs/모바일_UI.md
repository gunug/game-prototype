# 모바일 UI 가이드 — 카드 월드 RPG 2

> 2026-11-03 초안. **규칙만** 적는다 — 지금 코드가 지키는지는 따로 본다.
> 기준 기기: **세로 폰 360~430px** (기준 412 × 915 — 설정의 모바일 모드와 같은 크기). 가로 · 태블릿 · PC 는 이 규칙을 넓혀 쓴다.
> 화면 세 부분(필드 · UI · 팝업)은 `화면_구조.md` · `게임_규칙.md` 1절을 따른다. 이 문서는 그 위에서 **무엇을 어디에 얼마나 보여 줄지**를 정한다.

## 1. 정보 분류 — 넣기 전에 먼저 가른다

새 정보(수치 · 글 · 버튼 · 그림)를 화면에 넣기 전에 두 축으로 가른다.

| | **자주 본다** (매 초 ~ 매 행동) | **가끔 본다** (판단할 때 · 찾을 때) |
|---|---|---|
| **급하다** (놓치면 진다 · 막힌다) | **A. 늘 보임** | **C. 알림으로 밀어 줌** |
| **안 급하다** | **B. 한 번 탭** | **D. 찾아 들어감** |

| 등급 | 예 (world2) | 원칙 |
|---|---|---|
| **A** | 체력 막대 · 공격 대기 파이 · 지금 탭 · 지금 할 일 한 줄 | 그림 · 막대 · 숫자 하나로. 글 문장 금지 |
| **B** | 고른 카드의 이름 · 수치 · 쓰이는 조합 | **길게 누르기 엿보기** (인스펙터는 숨김 — v11.2.0). 손 하나로 바로 나와야 한다 |
| **C** | 새 카드 · 레벨 업 · 원정 끝 · 막힘 | 뱃지 · 단추 위 말풍선 · 흔적 카드. 토스트는 숨김 (v3.13.2) |
| **D** | 콜렉터북 · 무기 트리 · 설정 · 버전 | 팝업 · ☰ 메뉴. 찾아 들어가는 것 |

- 한 정보는 **한 등급**에만 둔다. A 에 있는 수치를 B 에서 다시 길게 풀어 쓰는 건 된다 (같은 값, 다른 깊이).
- 등급을 모르겠으면 **한 칸 아래**(B → D 쪽)로 둔다. 올리는 건 플레이로 필요가 확인된 뒤.

## 2. 뎁스 — 세 겹까지

| 깊이 | 자리 | 들어가는 법 | 나가는 법 |
|---|---|---|---|
| **0** | 필드 + UI 줄 | 늘 있음 | — |
| **1** | 엿보기 말풍선 · 설정 패널 · 2뎁스 칩 화면 | 길게 누르기 · 탭 한 번 | 손 뗌 · 바깥 탭 · 뒤로 가기 |
| **2** | 팝업 (콜렉터북 · 흔적 · 확인 창) | 깊이 0/1 의 단추 | 닫기 단추 · 바깥 탭 · 뒤로 가기 |
| ~~3~~ | — | 만들지 않는다 | |

- **팝업 위에 팝업 금지.** 팝업 안에서 더 볼 것은 팝업 **안에서 바꿔 보여 준다** (갈래 탭 · 펼침).
- 깊이 1 은 **필드가 보이게** 연다 — 시트는 화면 아래 절반까지만. 필드가 움직이는 동안(전투) 판단에 쓰는 정보이기 때문.
- 깊이 2 는 필드를 **가린다**(뒤 어둡게). 전투는 그동안에도 흐른다는 것을 잊지 않는다 — 급한 일(A · C 등급)은 팝업 위로도 알림을 띄운다.
- 어디서든 **두 번 안에** 깊이 0 으로 돌아온다.

## 3. 생략 — 좁으면 이 순서로 줄인다

폭이 모자라면 아래 순서대로 한 단계씩 줄인다. 앞 단계로 되는데 뒤 단계를 쓰지 않는다.

1. **여백 · 장식**을 줄인다 (틈 8 → 4px, 그림자 · 테두리 장식 뺌)
2. **글 → 그림**: 이름 글자를 빼고 아이콘만 (길게 누르면 이름)
3. **수치 → 막대 · 점**: `14/20` → 체력 막대. 정확한 값은 깊이 1 로
4. **목록 → 개수**: 카드 일곱 장 → `그림 + ×7` 뱃지. 펼치면 목록
5. **설명 → 첫 줄**: 첫 줄만 두고 `더 보기`
6. **접기**: 단추 여럿 → `☰` 하나 (지금 탭 이름은 옆에 남긴다)

- **A 등급은 생략하지 않는다.** 줄일 수는 있어도(3 · 4) 숨기지는 않는다.
- 생략한 것은 반드시 **어디서 다시 보이는지** 하나 있어야 한다 (길게 누름 · 인스펙터 · 펼침).
- 생략했다는 표시를 남긴다: 잘린 글은 `…`, 접힌 목록은 개수 뱃지, 숨은 단추는 `☰`.

## 4. 배치 — 정보 꼴에 따라 UI 를 고른다

| 정보 꼴 | 쓰는 UI | 자리 | 하지 않는 것 |
|---|---|---|---|
| 늘 바뀌는 상태 (체력 · 대기) | 막대 · 파이 · 칩 | 그 대상 **바로 곁** (발치) | 화면 구석 HUD 로 떼어 놓기 |
| 지금 할 일 한 줄 | 띠 (한 줄, 넘치면 `…`). 처음 하는 조작 안내만 둘째 줄 허용 | 아래 메뉴 바로 위. 탭하면 위로 펼침 | 두 줄 이상 |
| 고르기 — 5개 이하 | 세그먼트 · 아래 탭 줄 | 엄지 닿는 곳 (아래) | 드롭다운 |
| 고르기 — 6개 이상 | `☰` 판 (묶음별 세로 나열) | 탭 줄 자리에서 내려옴 | 가로 스크롤 탭만으로 버티기 |
| 고른 것의 자세한 정보 | **길게 누르기 엿보기** (손가락 위 말풍선). 인스펙터를 되살리면 반 높이 바텀 시트 | 대상 위 | 가운데 모달 |
| 큰 모음 · 계보 | 전체 팝업 (가장자리 여백만) | 화면 전체 | 시트 안에 넣기 |
| 잠깐 알림 | 토스트 (1.5~3초) — **지금은 숨김**, 되살리면 이 자리 | 필드 위쪽 가운데 | 손가락 밑 (아래쪽) |
| 쌓이는 알림 | 뱃지 (숫자 · NEW) | 그 정보가 사는 단추 위 | 알림 목록 화면 |
| 되돌릴 수 없는 일 (버리기 · 처음부터) | 확인 다이얼로그 또는 길게 누르기 | 가운데 | 한 번 탭으로 바로 실행 |
| 카드에 딸린 행동 | 카드 곁 작은 액션 칩 · 끌어 놓기 | 카드 옆 | 화면 끝의 따로 떨어진 단추 |
| 왜 안 되는지 (잠금 · 사거리 부족) | 그 단추 바로 위 말풍선 (≈1.8초) | 단추 위 | 토스트로 멀리 띄우기 |

### 4-1. 세로 폰 화면 띠 (위 → 아래)

| 띠 | 높이 | 등급 | 내용 |
|---|---|---|---|
| 노치 여백 | `safe-area-inset-top` | — | 비움 |
| 필드 | 남는 높이 전부 | A | 전투 줄 · 카드 판 |
| 2뎁스 칩 | 48px | A | 필드 · 던전 · 레이드 / 목표 · 조합 · 생산 / 편성 1~5 |
| 할 일 띠 | 한 줄 (≈32px) | A | 퀘스트 한 줄 + 진행 수 |
| 아래 메뉴 | 56~64px | A | 전투 · 편성 · 제작 · 퀘스트 · 📖 · ⚙ |
| 홈 표시줄 여백 | `safe-area-inset-bottom` | — | 비움 |

- **엄지 영역**: 화면 아래 1/3 에 자주 누르는 것(탭 · 시트 손잡이). 위 1/3 엔 보기만 하는 것(알림 · 진행).
- 오른손 기준으로 짜되, **좌우 끝 16px 안에는 누르는 것을 두지 않는다** (뒤로 가기 제스처와 겹친다).

## 5. 레이아웃 · 해상도

- 기준 412 × 915. **360 에서 깨지지 않고, 430 에서 비어 보이지 않게.** 320 은 깨지지만 않으면 된다.
- 높이는 `100vh` 대신 **`100dvh`** — 주소창이 들고 나도 아래 탭 줄이 가려지지 않게.
- 노치 · 홈 표시줄: `viewport-fit=cover` + `env(safe-area-inset-*)` 로 띠마다 여백을 준다. 필드는 노치 밑까지 깔아도 되지만 **누르는 것 · 글자는 안전 영역 안에**.
- 크기는 **필드 짧은 변(FS)** 하나에서 나온다 (카드 · 칸 · 글자). 새 요소도 고정 px 대신 FS 비례 + 최솟값 · 최댓값을 준다.
- 전투 무대는 어느 화면이든 **5.5칸** (`STAGE_KAN`). 폰 세로에서 보이는 칸 수가 곧 한계다 — 사거리 · 시야를 늘리는 기획은 이 숫자부터 본다.
- **가로 스크롤 금지** (페이지 전체). 판 · 줄 안의 스크롤만 된다.
- 기기 회전: 세로가 기준, 가로는 필드가 왼쪽 · UI 가 오른쪽으로 옮겨 가는 것만으로 되게 한다. 회전 때 상태(고른 카드 · 열린 시트)를 잃지 않는다.

## 6. 터치 · 조작

### 6-1. 크기
- 누르는 것은 **최소 44 × 44px** (보이는 그림이 작아도 누르는 범위는 44). 이웃과 **틈 8px** 이상.
- 카드는 그 자체가 누르는 것 — 카드 폭 최솟값 44px 를 지킨다.

### 6-2. 몸짓 — 한 대상에 뜻 하나씩

| 몸짓 | 뜻 | 비고 |
|---|---|---|
| 탭 | 고르기 → 인스펙터 | 모든 것의 기본 |
| 끌기 | 조합 · 놓기 · 출전 | 6~8px 움직이면 끌기로 판정 |
| 길게 누르기 (≈400ms) | 이름 · 설명 엿보기, 되돌릴 수 없는 일 확인 | 손을 떼면 닫힘 |
| 위아래 밀기 | 목록 스크롤 | 카드 위에서도 스크롤이 먼저 |
| 옆으로 밀기 | 줄 · 갈래 넘기기 | |
| ~~두 번 탭~~ · ~~두 손가락~~ | 쓰지 않는다 | 화면 확대와 겹친다 |

- **호버로만 보이는 정보 금지.** PC 의 호버 툴팁은 폰에서 길게 누르기로 바꾼다.
- 한 카드에 **끌기와 스크롤이 겹치면 방향으로 가른다** — 위아래는 스크롤, 옆은 넘김, 길게 누른 뒤 움직이면 집기. 어느 쪽인지 대상마다 정해 `touch-action` 에 적는다.
- 끄는 카드는 **손가락보다 위로** 띄워 보여 준다 (손가락에 가려 놓을 자리가 안 보이지 않게). 놓일 자리는 테두리로 미리 보인다.
- 잘못 놓으면 제자리로 돌아온다. **놓는 것만으로 사라지는 일**(버리기 칸)은 되돌리기를 주거나 확인을 받는다.

### 6-3. 브라우저 몸짓 막기
- 판 · 줄: `touch-action` 으로 필요한 방향만 연다. 화면 전체엔 `touch-action: manipulation` (두 번 탭 확대 끔).
- `overscroll-behavior: none` — 끌어내려 새로 고침 · 튕김 막기.
- 길게 누르기 메뉴 · 글자 선택: 게임 판에선 `user-select: none` · `-webkit-touch-callout: none`. 설명 글은 선택 가능하게 둬도 된다.
- 손가락 하나만 받는다 — 끄는 중에 두 번째 손가락이 닿으면 무시.

### 6-4. 손에 주는 답
- 누르면 **100ms 안에** 눈에 보이는 반응 (눌림 · 테두리).
- 진동(`navigator.vibrate`)은 쓰지 않는다 — iOS 에서 안 되고, 되는 쪽만 다른 경험이 된다.

## 7. 글자 · 아이콘 · 카드 크기

### 7-1. 글자

| 쓰임 | 최소 | 권장 |
|---|---|---|
| 본문 · 설명 | 13px | 14~15px |
| 카드 이름 | 10px | 카드 폭의 ≈ 1/6 |
| 뱃지 · 수량 · 막대 위 숫자 | 10px | 11px, 굵게 |
| 머리말 · 딱지 (묶음 이름 · 수첩 머리) | 12px | 12px, 굵게 |
| 제목 | 15px | 16~18px |
| 입력란 | **16px** | 16px (그보다 작으면 iOS 가 확대해 버린다) |

- 한글은 **한 줄 14자 안팎**이 폰에서 읽힌다. 길면 생략 3절 5번.
- 글자는 그림 위에 바로 얹지 않는다 — 판 · 그림자 · 테두리 중 하나를 깐다.
- 대비: 본문 4.5 : 1 이상. 흐려진(조합 안 되는) 카드도 이름은 읽혀야 한다.

### 7-2. 아이콘
- **이모지 직접 쓰기 금지** — `ICONS` 표의 그림으로 (CLAUDE.md "UI 아이콘").
- 원본 64px 아이콘은 **화면에서 32px 이상**으로 보여 준다. 24px 아래로 내려가면 64px 그림은 뭉개진다 → 그 자리는 납작한 실루엣 UI 아이콘(`--no-style`)을 따로 둔다.
- 아이콘만 있는 단추는 길게 누르면 이름이 나와야 한다 (3절 2번).
- 화면 배율(`devicePixelRatio` 2~3)에서 흐려지지 않게 — 작게 보여 줄 그림은 정수 배로 줄인다 (64 → 32), 픽셀 그림이면 `image-rendering: pixelated`.

### 7-3. 카드
- 폭 = FS ÷ 6.4, **44~87px**, 세로 = 폭 × 1.36. 폰 세로에서 대략 60~70px.
- 카드 위에 얹는 것은 **셋까지** — 수량 알약(오른쪽 위) · NEW(왼쪽 위) · 막대 하나(아래). 넷째가 필요하면 인스펙터로.
- 카드 한 장 안의 글은 **이름 하나**. 수치는 넣지 않는다 (B 등급).

## 8. 성능 · 브라우저 제약

### 8-1. 프레임
- 목표 **60fps**, 버티는 선 30fps. 기준 기기는 중급 안드로이드 (갤럭시 A 급).
- 움직임은 `transform` · `opacity` 만. `top/left/width` 를 매 프레임 바꾸지 않는다.
- `filter`(blur · brightness) 는 **화면에 몇 장만**. 많은 요소에 걸리면 폰에서 가장 먼저 무너진다 — 미리 구운 그림으로 바꾼다.
- `box-shadow` 를 움직이는 요소에 걸지 않는다. 그림자는 정지 요소에만.
- 매 프레임 일은 `requestAnimationFrame` 한 곳에서. 끄는 중 DOM 을 새로 만들지 않는다.
- 탭이 숨으면(`visibilitychange`) 그리기를 멈춘다 — 게임 시간은 돌아와서 몰아 계산.

### 8-2. 메모리 · 그림
- 그림은 **보여 줄 크기의 2배까지만** 실어 보낸다 (원경 576×512 · 카드 64 · 초상 192×256 수준). 원본 큰 그림을 화면에서 줄여 쓰지 않는다.
- 한 화면에 쓰지 않는 탭의 그림은 미리 다 띄우지 않는다.
- iOS Safari 는 메모리가 넘으면 **경고 없이 페이지를 새로 고친다** — 저장은 자주, 짧게.

### 8-3. 브라우저별
| 것 | 주의 |
|---|---|
| iOS Safari | `100vh` 가 주소창을 포함 → `dvh`. 소리는 첫 터치 뒤에만 재생. 진동 없음. 사파리 사설 창은 `localStorage` 가 막힐 수 있음 |
| 안드로이드 크롬 | 아래 주소창이 숨었다 나오며 높이가 바뀜 → `resize` 에서 다시 잼. 뒤로 가기 단추는 팝업 · 시트 닫기로 받는다 (`history` 한 칸) |
| 공통 | `localStorage` 는 `try/catch` 로 감싸고, 못 써도 게임은 돈다 |
