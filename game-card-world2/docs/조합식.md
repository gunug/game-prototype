# 조합식 — 카드 월드 RPG 2

> **v0.20.0** 기준. 2·3티어는 **미확정**(체험용).

## 규칙
- 카드를 끌어 다른 카드에 놓으면 조합. 어느 쪽을 끌어도 같음
- **두 재료 모두 수량 -1** (남는 쪽 없음 — 확정 48)
- 결과는 대상 카드 자리에서 튀어나오고 3초 동안 노란 깜빡임
