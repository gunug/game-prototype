# 조합식 — 카드 월드 RPG 2

> **v9.104.0** 기준 · 2026-10-19 · `node tools/gen_docs.mjs` 로 만든 문서 — **손으로 고치지 않는다** (데이터가 바뀌면 다시 돌린다)

## 규칙

- 카드를 끌어 다른 카드 위에 놓으면 조합. 어느 쪽을 끌어도 같다.
- 조합식은 탭마다 있다. 그 탭을 맡은 장인이 여관에서 합류해야 그 탭에서 만든다 (조합 탭은 처음부터).
- **같은 두 재료의 결과는 하나뿐.** 같은 결과로 가는 길은 여럿일 수 있다 (땅마다 다른 재료로).
- **단계 규칙** — 결과 단계 = 두 재료 가운데 높은 단계 + 1, 두 재료의 단계 차는 1 이하.
- 무기끼리는 합치지 않는다 (무기 + 무기재료만).
- 위 규칙은 `node tools/check.mjs` 가 검사한다.
