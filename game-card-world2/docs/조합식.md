# 조합식 — 카드 월드 RPG 2

> **v0.1.1** 기준. 레거시 v0.147.1의 `RECIPES`를 그대로 복사하고, **크래프팅 탭 카드로 양쪽을 채울 수 있고 결과도 크래프팅 카드인 것**만 쓴다.

## 규칙
- 카드를 끌어 다른 카드에 놓으면 조합. 어느 쪽을 끌어도 같음
- 한쪽은 **카드** 또는 **태그 레벨**(요구 레벨 이상이면 맞음 — 상위 도구가 하위 손질도 함)
- **남음** 표시 쪽은 조합해도 사라지지 않음 (도구·불). 나머지는 사라짐
- 익히기: 불 + 날것 → 그 날것의 익은 카드 (익힘 짝이 있는 카드만)
- 태우기: 불 + 불에 타는 → 재. 장소 태그가 있는 카드(풀 깔개·모닥불)가 없어지는 조합은 안 됨
- 맞는 조합식이 여럿이면 목록의 첫 번째
- 결과는 월드 같은 카드 3장 제한을 받음 — 재료가 사라진 뒤로 셈. 하나도 못 나오면 조합 안 됨, 일부만 나오면 나머지 `누락:`

## 태그를 가진 카드

- **손질**: 돌 (lv1), 뗀석기 (lv2), 단검 (lv2)
- **불**: 모닥불
- **날것**: 열매, 조갯살, 고기, 오징어살
- **불에 타는**: 나뭇가지, 마른 풀, 불쏘시개, 풀 깔개, 나무방패, 나무판자, 톱밥, 나무
