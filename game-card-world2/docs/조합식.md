# 조합식 — 카드 월드 RPG 2

> **v0.13.0** 기준. **2티어 추천안 그대로 (미확정)**. 1티어 + 1티어 → 2티어.

## 규칙
- 카드를 끌어 다른 카드에 놓으면 조합. 어느 쪽을 끌어도 같음
- **남음** 쪽은 조합해도 사라지지 않음. 돌·부싯돌을 남기는 건 도구 특별 규칙이 정해질 때까지의 가안
- 결과는 대상 카드 자리에서 튀어나오고 3초 동안 노란 깜빡임 (제작 성공)
- 같은 카드는 필드에 3장까지. 재료가 사라진 뒤로 셈. 결과가 하나도 못 나오면 조합 안 됨, 일부만 나오면 나머지 `누락:`
