# 화면구성
- [x] 격자형 타일맵
- [x] 격자는 가로 10칸, 세로 10칸이 되도록 1:1 비율의 조작 공간을 구성하고. 디바이스 화면 크기에 맞춰 리사이즈 하도록 한다.
  - 칸 크기는 min(가용 너비, 가용 높이) / 10 을 내림한 정수 px. 판은 남은 영역 중앙 정렬
  - 좌측 스테이지 패널(220px)을 뺀 나머지가 가용 영역. 640px 이하에서는 패널이 상단 가로줄로 바뀐다

# 용어
## 필드
- [x] 블럭이 칠해질 수 있는 공간
  - 활성 칸만 칠할 수 있고, 비활성 칸은 포인터를 무시한다
## 칠
- [x] 색이 없는 필드에서 드래그를 시작하면 하나의 색이 배정되고 드래그 하면 색이 이어짐
- [x] 색이 배정될때 이미 필드에 있는 색이라면 배정되지 않는다.
  - 칠 하나마다 색이 하나씩 필요하므로 팔레트를 100색(칸 수)으로 잡고 황금각으로 색상환을 돈다
- [x] 이미 색이 들어있는 필드에서 드래그를 시작하면 기존의 색이 이어짐
- [x] 이미 색이 들어있는 필드를 클릭하면 색이 지워짐
  - 클릭 = 다른 칸으로 이동 없이 뗀 경우. 드래그 취소(pointercancel/blur)는 지우지 않음
## 모양
- [x] 어떤 칠이 연속드로 배치된 형태
  - 같은 색으로 4방향 연결된 덩어리 하나 = 칠 하나
- [x] 각 모양은 0,90,180,270 회전한 형태는 같은 모양으로 본다.
  - 좌우 반전은 다른 모양으로 본다 (스펙에 반사 언급이 없어 회전만 인정)

# 스테이지
- [x] 좌측에 리스트 형태로 스테이지를 출력한다.
  - 스테이지 6개
- [x] 클리어한 스테이지는 체크표시 한다.
  - LocalStorage(`exact-cover.cleared`)에 저장해 다시 열어도 유지

## 문제
- [x] 칠해야할 모양을 보여준다
  - 좌측 패널에 미니 격자로 표시
- [x] 칠해야할 모양으로 채울 수 있는 필드를 생성 (칠할 필요 없는 필드는 비활성화)
  - `tools/generate.py` 가 OR-Tools CP-SAT 로 미리 풀어 만들고, 게임은 구운 결과만 읽는다.
    런타임 생성기(`buildField`, `mulberry32`)는 삭제
  - 모델: 칸마다 `그 칸을 덮는 조각 수 == 활성 여부`, 조각 총합 고정.
    이 제약이 정확한 덮개를 보장하므로 만들어진 필드는 항상 풀린다
  - 조밀도(frac)로 필드 생김새를 조절한다. 1.0 이면 항상 직사각형이 나와서
    0.6~0.82 대를 쓰고, 그 안에서 무작위 가중치로 골라 스테이지마다 다르게 만든다
  - 이전 성장식 생성기는 뚱뚱한 필드를 만들지 못했다 (42칸 요청에 18칸에서 멈춤)
  - `python tools/generate.py --verify` 로 구운 필드를 다시 풀어 확인. 6개 모두 통과
  - 스테이지 구성

    | # | 모양 | 조각 | 칸 |
    |---|---|---|---|
    | 1 | 트로미노 L | 10 | 30 |
    | 2 | 트로미노 I | 12 | 36 |
    | 3 | 테트로미노 O | 12 | 48 |
    | 4 | 테트로미노 T | 13 | 52 |
    | 5 | 테트로미노 L | 14 | 56 |
    | 6 | 펜토미노 L | 14 | 70 |

    순서는 조각 크기와 칸 수 기준. 난이도 측정은 아직 안 함

## 클리어 조건
- [x] 모든 필드를 칠해야한다
- [x] 모든 칠은 같은 모양을 가지고 있어야한다.
  - 드래그를 뗄 때마다 판정하고, 만족하면 판 위에 "클리어!" 배너를 띄운다
