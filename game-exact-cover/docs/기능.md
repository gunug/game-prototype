# 화면구성
- [x] 격자형 타일맵
- [x] 각 격자는 100px * 100px
  - 격자 수는 뷰포트 크기에 맞춰 채우고, 리사이즈시 재구성
  - HUD에 현재 색 표시 · 지우기 버튼 · 목록 링크 추가 (스펙 외 최소 편의)

## 칠
- [x] 색이 없는 필드에서 드래그를 시작하면 하나의 색이 배정되고 드래그 하면 색이 이어짐
  - 배정은 8색 팔레트 순환 (스펙에 배정 방식이 없어 정한 기본값)
- [x] 이미 색이 들어있는 필드에서 드래그를 시작하면 기존의 색이 이어짐
  - 이 경우 팔레트 순환 인덱스는 넘어가지 않는다
- [x] 빠른 드래그로 격자를 건너뛰어도 빈칸이 없도록 직선 보간
