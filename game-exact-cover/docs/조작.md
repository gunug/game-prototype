# 조작

## 지금 방식
- 빈 칸 드래그 → 새 색 배정, 지나간 칸이 칠해짐
- 칠한 칸 드래그 → 그 색이 이어짐
- 칠한 칸 클릭 → 한 칸 지움
- 칠한 칸 3초 홀드 → 그 색 전체 지움
- 상단 `지우기` → 판 전체 리셋

## 문제
- [ ] T4 · T5 · Y5 는 한 붓에 못 그린다
  - 가지가 있어 단순 경로가 아니다. 떼고 칠한 칸에서 다시 시작해야 이어진다
  - 쓰는 9종 중 3종. 어디에도 안내가 없다
  - 한 붓으로 되는 것 — L3 L4 L5 P5 V5 W5
- [ ] 3초 홀드가 너무 길다 (`HOLD_MS = 3000`)
  - 틀린 조각 지우기는 가장 자주 하는 조작인데 3초를 기다린다
  - 3초를 견디게 하려고 글로우 게이지를 넣은 것 자체가 신호다
- [ ] 한 칸 지우기가 쓸모없다
  - 정확한 덮개 게임이라 덩어리 반쪽만 남은 상태는 절대 쓸 일이 없다
  - 오히려 덩어리를 둘로 쪼개 이상한 상태를 만든다
- [ ] 되돌리기가 없다
  - `지우기` 는 판 전체 리셋뿐이다. 한 수 무르기가 없어 실수 비용이 판 전체다
- [ ] 한 칸 넘게 그으면 되돌릴 방법이 없다
  - 떼고 그 칸을 클릭해서 지워야 한다. 획 도중 복구가 안 된다
- [ ] 칠 크기에 상한이 없다
  - 4칸 조각인데 40칸을 한 색으로 칠할 수 있다. 규칙상 불가능한 상태를 UI 가 허용한다
- [ ] 오답 피드백이 없다
  - 그리는 중인 덩어리와 틀린 덩어리가 화면상 같다. 둘 다 유리질감이 없을 뿐이다
- [ ] 손가락이 목표 칸을 가린다
  - 360px 폰에서 칸이 36px. 5칸 모양을 정밀 드래그하는데 접점이 가려진다

## 조각 스탬프 (구현됨, 기본값)
조각 모양은 이미 정해져 있다. 그리기는 퍼즐이 아니라 마찰이다.

- [x] 누른 칸을 기준점으로 잡고, 끌면 그 방향에 맞는 배치를 고른다. 떼면 놓인다
  - 지나간 칸을 **모두 덮는** 배치만 후보로 남긴다. 그어 갈수록 후보가 좁혀진다
  - 후보가 여럿이면 끌어간 방향과 배치 무게중심 방향의 코사인이 가장 큰 것
  - 거의 안 끌었으면 누른 칸이 가장 가운데 오는 배치. 탭 한 번으로 놓인다
  - 후보를 늘리는 칸은 무시한다. 지나쳐도 손해가 없어야 하기 때문
  - 누른 칸으로 되돌아오면 조건이 초기화된다. 잘못 지나간 칸에 갇히지 않게
- [x] 떼기 전에 놓일 자리를 고스트로 보여 준다. 들어갈 자리가 없으면 누른 칸이 붉어진다
- [x] 놓인 조각을 누르면 통째로 지워진다. 3초 홀드도 한 칸 지우기도 필요 없다
  - 뗄 때 판정한다. 끌고 나가면 안 지운다. 스치기로 조각을 날리지 않으려는 것
- [x] 회전 버튼이 없다. 끄는 방향이 회전을 겸한다
- [x] 항상 조각 모양 그대로만 놓이므로 틀린 덩어리 자체가 나올 수 없다
- [x] 조각 크기가 다른 두 종에서, 작은 조각이 큰 조각 안에 통째로 들어간다
      (L3 는 L5 의 끝자락과 같은 모양이다). 지나간 칸 수와 조각 칸 수가 딱 맞으면
      그 배치를 먼저 본다. 안 그러면 L3 를 아무리 정확히 그어도 L5 에 삼켜진다
- [x] 배치는 스테이지를 열 때 한 번만 센다. 회전형 x 100칸이라 드래그 중엔 훑기만 한다
- [ ] 탭으로 후보를 순환시키는 방식은 안 쓴다. 두 종은 칸당 후보가 13.3개라 탭이 너무 많다

## 설정
- [x] 상단 바와 목록 화면 머리말의 톱니로 연다. 조작 방식을 고른다
  - `조각 스탬프` (기본) / `자유 드로잉`
  - `exact-cover.mode` 로 LocalStorage 에 남는다
  - 방식을 바꾸면 판을 새로 연다. 자유 드로잉으로 그린 덩어리는
    스탬프로 이어 놓을 수 없기 때문
  - 배경을 누르거나 Esc 로 닫힌다

## 자유 드로잉에 남은 문제
스탬프가 기본이라 급하지 않지만, 이 방식을 계속 쓴다면 남아 있다.

- [ ] 되짚기 지우개 — 드래그 도중 방금 칠한 칸으로 되돌아가면 지워진다 (Flow Free 방식)
- [ ] 칠 크기 상한 = 조각 칸 수. 넘으면 더 안 칠해진다
- [ ] 홀드 3000ms → 600ms
- [ ] 되돌리기 (Ctrl+Z + 버튼) — 획 단위 스택
- [ ] 오답 붉은 틴트 — 조각 칸 수를 넘은 덩어리는 즉시 빨강
