# 조작

## 지금 방식
- 빈 칸 드래그 → 새 색 배정, 지나간 칸이 칠해짐
- 칠한 칸 드래그 → 그 색이 이어짐
- 칠한 칸 클릭 → 한 칸 지움
- 칠한 칸 3초 홀드 → 그 색 전체 지움
- 상단 `지우기` → 판 전체 리셋

## 문제
- [ ] T4 · T5 · Y5 는 한 붓에 못 그린다
  - 가지가 있어 단순 경로가 아니다. 떼고 칠한 칸에서 다시 시작해야 이어진다
  - 쓰는 9종 중 3종. 어디에도 안내가 없다
  - 한 붓으로 되는 것 — L3 L4 L5 P5 V5 W5
- [ ] 3초 홀드가 너무 길다 (`HOLD_MS = 3000`)
  - 틀린 조각 지우기는 가장 자주 하는 조작인데 3초를 기다린다
  - 3초를 견디게 하려고 글로우 게이지를 넣은 것 자체가 신호다
- [ ] 한 칸 지우기가 쓸모없다
  - 정확한 덮개 게임이라 덩어리 반쪽만 남은 상태는 절대 쓸 일이 없다
  - 오히려 덩어리를 둘로 쪼개 이상한 상태를 만든다
- [ ] 되돌리기가 없다
  - `지우기` 는 판 전체 리셋뿐이다. 한 수 무르기가 없어 실수 비용이 판 전체다
- [ ] 한 칸 넘게 그으면 되돌릴 방법이 없다
  - 떼고 그 칸을 클릭해서 지워야 한다. 획 도중 복구가 안 된다
- [ ] 칠 크기에 상한이 없다
  - 4칸 조각인데 40칸을 한 색으로 칠할 수 있다. 규칙상 불가능한 상태를 UI 가 허용한다
- [ ] 오답 피드백이 없다
  - 그리는 중인 덩어리와 틀린 덩어리가 화면상 같다. 둘 다 유리질감이 없을 뿐이다
- [ ] 손가락이 목표 칸을 가린다
  - 360px 폰에서 칸이 36px. 5칸 모양을 정밀 드래그하는데 접점이 가려진다

## 추천 1 — 조각 스탬프 (본안)
조각 모양은 이미 정해져 있다. 그리기는 퍼즐이 아니라 마찰이다.

- [ ] 누른 칸을 기준점으로 잡고 **드래그 방향으로 회전·배치를 고른다**. 떼면 확정
- [ ] 놓기 전 고스트로 칠할 칸을 미리 보여 준다
- [ ] 항상 조각 모양 그대로만 생기므로 틀린 덩어리 자체가 나올 수 없다
- [ ] 놓은 조각을 **탭하면 통째로 지워진다**. 3초 홀드와 한 칸 지우기는 폐기
- [ ] 회전 버튼이 없다. 방향 드래그가 회전을 겸한다
- [ ] 탭으로 후보를 순환시키는 방식은 dual 에 안 맞는다. 칸당 후보가 13.3개라 탭이 너무 많다

## 추천 2 — 지금 방식을 유지하고 값싸게 고치기
스탬프 전환이 부담이면 이것만이라도.

- [ ] 되짚기 지우개 — 드래그 도중 방금 칠한 칸으로 되돌아가면 지워진다 (Flow Free 방식).
      오버런을 획 안에서 바로 복구한다
- [ ] 칠 크기 상한 = 조각 칸 수. 넘으면 더 안 칠해진다. dual 은 큰 쪽 기준
- [ ] 홀드 3000ms → 600ms, 또는 조각 탭 = 통째 삭제로 교체
- [ ] 되돌리기 (Ctrl+Z + 버튼) — 획 단위 스택
- [ ] 오답 붉은 틴트 — 조각 칸 수를 넘은 덩어리는 즉시 빨강

## 우선순위
1. 되짚기 지우개 + 칠 크기 상한 — 가장 싸고 효과가 크다
2. 홀드 단축 또는 조각 탭 삭제
3. 되돌리기
4. 스탬프 방식 전환
