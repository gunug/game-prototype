# 아이콘 생성 절차

ComfyUI `icon_work_game` 워크플로우로 게임 아이콘을 만들어 `images/icon/` 에 넣는다.

## 절차

1. 요청받은 아이콘마다 **영문 프롬프트**와 **파일명**을 정한다.
2. ComfyUI(`http://127.0.0.1:8188`)가 켜져 있는지 확인한다.
3. `tools/make_icon.py` 실행:

   ```bash
   python tools/make_icon.py --name card_stone --prompt "A stylized game icon of a single rounded grey stone ..."
   ```

4. 결과
   - `images/icon/<name>.png` — 64×64 투명 배경, 32색 (게임에서 쓰는 파일)
   - ComfyUI `output/game-card-world/<name>_full_00001_.png` — 1024 원본 (확인용, 복사 안 함)
5. 64px 결과를 눈으로 확인. 마음에 안 들면 `--force` 로 다시 돌린다 (시드는 매번 랜덤).

## 파일명 규칙

형식: **`<분류>_<id>`** — 확장자 없이 적는다 (`.png` 자동). 스크립트가 형식을 검사한다.

| 분류 | 쓰임 | id | 예 |
|---|---|---|---|
| `card` | 카드 아이콘 | `index.html` `DEFS` 의 키 **그대로** | `card_stone`, `card_campfire`, `card_roastmeat` |
| `tag` | 태그 표시 | 태그 뜻의 영문 | `tag_flammable` |
| `status` | 상태 (빈사·허기짐 …) | 상태 뜻의 영문 | `status_dying`, `status_hungry` |
| `ui` | 버튼·메뉴·콜렉터북 | 기능 영문 | `ui_collector-book` |
| `fx` | 연출용 | 연출 영문 | `fx_heal` |

- `_` 는 분류와 id 사이 **한 번만**. id 안에서 단어를 나눌 땐 `-` (`ui_collector-book`)
- id 는 영문 소문자·숫자·`-` 만
- 카드는 **id 하나에 파일 하나**. 코드에서 `images/icon/card_${id}.png` 로 바로 찾을 수 있게 한다
  - 카드 id 가 바뀌면 파일명도 같이 바꾼다
  - 다시 뽑을 땐 같은 이름에 `--force` (이전 버전은 git 기록에 남음)
- 분류가 더 필요하면 스크립트 `CATEGORIES` 와 이 표에 같이 추가한다
- 같은 이름이 있으면 멈춘다. 덮어쓰려면 `--force`.

## 그림체 (통일 키워드)

방향: **밝은 분위기 · 어린이용 아님 · 실사 아님 · 슈퍼 데포르메(SD)** — 손그림 세미 리얼 판타지 RPG 아이콘에 SD 비율로 작게 보여도 읽히게.

스크립트가 모든 프롬프트 **앞에** 자동으로 붙인다 (`STYLE_PREFIX`):

```
Stylized fantasy RPG game icon, super deformed (SD) style with chunky exaggerated proportions,
characters have an oversized head and a small compact body,
hand-painted semi-realistic illustration style, bold readable shapes with clean dark outlines,
painterly brush texture, soft cel-shaded volumes,
bright warm lighting, rich vivid colors, grounded mature art direction for teen and adult players.
```

- 그림체 변경 기록 (2026-09-15)
  1. 손그림 세미 리얼 → 좋지만 카드 위에서 자잘함
  2. 굵은 외곽선·적은 디테일로 단순화 → **단조롭고 결과가 나빠 폐기**
  3. 1번 + 슈퍼 데포르메 (현재)
- `--prompt` 에는 **무엇을 그릴지만** 적는다. 그림체 단어(realistic, cute, chibi, photo, 3D render …)는 넣지 않는다 → 섞이면 그림체가 흔들린다
- 디테일을 일부러 빼지 않는다 (단순화하면 단조로워짐)
- **캐릭터 카드는 얼굴 위주** — `close-up face portrait, the head fills most of the frame, of ...` 로 시작. 손은 나와도 됨 (전신·상반신 금지)
  - 얼굴 초상은 목 아래 어두운 옷·갑옷이 검은 배경과 붙어 덩어리로 남는다 → **캐릭터는 처음부터 흰 배경**(`--no-suffix` + `simple solid #ffffff white background`)
- 빛 번짐(glow)은 배경 제거에서 잘린다 → 후광 같은 건 `solid opaque ... ring, no glow` 로 적는다
- 고리·틈처럼 **배경이 갇히는 모양**(후광, 손잡이 …)은 검은 배경이 막대처럼 남는다 → `--no-suffix` 로 꼬리말을 직접 적고 배경만 `simple solid #ffffff white background` 로 바꾼다 (갓이 이렇게 해결됨)
- 그림체를 바꿀 땐 `STYLE_PREFIX` 한 곳만 고치고, 이미 만든 아이콘은 `--force` 로 다시 뽑는다
- 안 붙이려면 `--no-style` (실험용)

## 프롬프트 요령

- 오브젝트 **하나**만, 무엇인지 + 재질 + 각도 + 특징을 적는다.
  - 예: `a sharp knapped flint hand axe, chipped facets, grey-brown stone, three-quarter view`
- 캐릭터는 **상반신(bust)** 으로, 성격이 보이는 표정·소품을 적는다.
- 스크립트가 끝에 배경 제거용 꼬리말을 자동으로 붙인다:
  `single object, centered composition, isolated object, clean readable silhouette, simple solid #000000 background, no text, no characters, no additional objects`
  - 안 붙이려면 `--no-suffix`.
- 검은 오브젝트(숯, 재 등)는 검은 배경과 섞여 배경 제거가 망가질 수 있다 → `--no-suffix` 로 `simple solid #ffffff background` 등을 직접 적는다.

## 파라미터

| 옵션 | 기본 | 설명 |
|---|---|---|
| `--name` | (필수) | 파일명 |
| `--prompt` | (필수) | 영문 프롬프트 |
| `--seed` | 랜덤 | 같은 결과를 다시 뽑을 때 (실행 로그의 `seed=` 값) |
| `--size` | 64 | 최종 픽셀 크기 |
| `--colors` | 32 | 팔레트 색 수. 레트로 느낌은 16·8 |
| `--no-style` | 꺼짐 | 그림체 머리말 안 붙임 |
| `--no-suffix` | 꺼짐 | 꼬리말 안 붙임 |
| `--force` | 꺼짐 | 같은 이름 덮어쓰기 |
| `--url` | `http://127.0.0.1:8188` | ComfyUI 주소 |

## 파이프라인 (워크플로우와 동일)

FLUX.2 Klein 9B INT8 + pixel-surgeon LoRA, 1024×1024, 4 step / cfg 1 / euler / simple
→ birefnet 배경 제거 → 알파 부착 → 마스크 크롭 → `ImageResize+`(area, pad) → 알파 분리 → `ImageQuantize`(dither none) → 알파 재결합

- 워크플로우 원본은 ComfyUI의 `icon_work_game.json`. 스크립트는 그 그래프를 API 형식으로 옮겨 적은 것이라, 워크플로우를 고치면 스크립트도 같이 고쳐야 한다.
- 필요 커스텀 노드: ComfyUI-KJNodes(`ImageCropByMask`), ComfyUI_essentials(`ImageResize+`)
