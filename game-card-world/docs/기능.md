# 기능 — 카드 월드 RPG

> 설계 원문은 `card-world-rpg` 저장소의 `00_확정사항.md`. 이 문서는 프로토타입에 구현할 범위만 적는다.
> **v0.2.0** — 구현은 했지만 **플레이 검증 전**이라 체크하지 않았다. 플레이로 확인한 항목부터 체크한다.

## 0. 범위
- 판을 깔기 전, 월드의 튜토리얼 구간만.
- 판 · 출전 · 전투 · container · party · 장비는 아직 없다.

---

## 1. 테이블
- [ ] 뷰포트 전체가 테이블
- [ ] 상태를 localStorage에 저장하고 다시 열면 복원
- [ ] "처음부터" 버튼 (시스템 메뉴라 카드 아님)

## 2. 오픈
- [ ] 시작은 테이블 가운데 `package` 한 장
- [ ] 좌상단 점선 모서리(택)를 일정 길이 이상 당기면 오픈
- [ ] 일정 길이 미만에서 놓으면 되돌아감
- [ ] 탭만으로는 열리지 않음
- [ ] 오픈되면 찢어지는 연출 → package 제거 → 내용물 생성
- [ ] package 몸통을 잡으면 그냥 이동
  - 판단: 당김 기준 길이 = 카드 너비의 0.9배

## 3. package 내용
- [ ] 첫 package: 기사, 갓, 재료 5장
- [ ] request 보상 package: 재료 5장
- [ ] 재료 8종 풀에서 가중치로 5장 뽑기, 중복 허용
  - 돌 18 / 열매 18 / 나뭇가지 16 / 마른 풀 14 / 뼈 12 / 조개껍데기 12 / 동물 사체 6 / 부싯돌 4

## 4. 쌓기
- [ ] 카드를 다른 카드 위에 드래그 드롭
- [ ] 결과는 대상 카드 + 올리는 카드 조합으로 정해짐
- [ ] 결과가 없으면 원래 자리로 되돌아감
- [ ] 빈 자리에 놓으면 그 자리로 이동
- [ ] 드래그 중 아래 카드 하이라이트 (되는 조합은 노랑, 안 되는 조합은 회색)
  - 판단: 재료끼리 조합은 어느 쪽을 올려도 같음
  - 판단: 도구 역할(돌·뗀석기·모닥불)은 조합해도 남음

## 5. 조합 (2장)
- [ ] 돌 + 돌 → 뗀석기
- [ ] 돌 + 뼈 → 골수 (돌 남음)
- [ ] 돌 + 조개껍데기 → 조갯살 (돌 남음)
- [ ] 돌 + 부싯돌 → 불씨 (돌 남음)
- [ ] 뗀석기 + 뼈 → 골수 (뗀석기 남음)
- [ ] 뗀석기 + 조개껍데기 → 조갯살 (뗀석기 남음)
- [ ] 뗀석기 + 동물 사체 → 고기 + 가죽 (뗀석기 남음)
- [ ] 뗀석기 + 나뭇가지 → 뾰족한 막대 (뗀석기 남음)
- [ ] 마른 풀 + 나뭇가지 → 불쏘시개
- [ ] 마른 풀 + 마른 풀 → 풀 깔개
- [ ] 불씨 + 불쏘시개 → 모닥불
- [ ] 모닥불 + 고기 → 구운 고기 (모닥불 남음)
- [ ] 모닥불 + 조갯살 → 구운 조개 (모닥불 남음)

## 6. 제출 (`request`)
- [ ] 갓이 request 생성: "아무거나 3개만 줘봐"
- [ ] 보상(📦)이 미리 보임
- [ ] 제출한 카드가 request 위에 쌓임
- [ ] 정산 전에는 쌓인 카드를 끌어내 꺼낼 수 있음
- [ ] 다 쌓이면 한 번에 정산 → 제출 카드와 request 제거, 그 자리에 package 생성
- [ ] 캐릭터 · package · request는 제출 불가

## 7. 갓의 request 공급
- [ ] 첫 발견 전: request와 package가 테이블에 없으면 새 request (5개 받고 3개 내기 반복)
- [ ] 첫 발견 후: 테이블에서 가능한 조합이 하나도 없을 때만 새 request (고착 방지)
  - 판단: 제출할 카드가 3장 미만이면 요구 수를 그만큼 줄임
  - 판단: 제출할 카드가 0장이면 request 없이 package를 바로 줌 (고착 방지 예외)

### 7-1. 고착 점검 (v0.1.1)
- [ ] 고착 = 테이블에 package가 없고, 가능한 조합이 없고, 남은 request를 전부 채울 수 없음
  - 채울 수 없음 = request에 쌓인 수 + 테이블의 제출 가능한 카드 수 < 요구 수
- [ ] 고착이면 갓이 멘트를 하고 request를 다시 줌
- [ ] 다시 줄 때 기존 request에 쌓여 있던 카드는 테이블로 돌려주고 기존 request는 제거
- [ ] 새 request의 요구 수는 지금 제출 가능한 카드 수에 맞춤 (최대 3)
- [ ] 상태가 바뀔 때마다 점검 + 5초마다 한 번 더 점검
  - 판단: 가능한 조합이 남아 있으면 고착으로 보지 않음 (조합으로 카드가 늘어날 수 있음)

## 8. 그 밖의 쌓기
- [ ] 불 + "불에 타는" 카드 → 태우기 (카드 제거) — v0.2.0부터 조합표에 포함
- [ ] 캐릭터 + 음식 → 체력 회복. 체력이 가득이면 되돌아감
  - 판단: 월드에서는 체력이 안 깎이므로 지금은 항상 되돌아감

## 9. 캐릭터
- [ ] 기사: 대사 없음, 체력 10
- [ ] 갓: 말풍선 대사, 체력 1
- [ ] 갓 대사: 등장 / request / 정산 / 첫 발견 / 발견 / 쌓기 실패(가끔) / 막힘

## 10. 콜렉터북 (카드 아님)
- [ ] 오른쪽 위 버튼으로 열기, 등장 수 표시
- [ ] 페이지 "석기시대 초기": 등장한 카드만 공개, 나머지는 ??? 칸
- [ ] 발견한 조합 목록, 모르는 조합은 ??? 칸으로 전체 수를 보여줌
- [ ] 새 카드 · 새 조합 알림
  - 미구현: 페이지 완료 보상

## 11. 아직 없는 것
- 판, 출전, 전투, 체력 감소, 부활
- container, party, 장비
- 자세히 보기 (탭은 아직 미정)
