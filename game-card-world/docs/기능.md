# 기능 — 카드 월드 RPG

> 설계 원문은 `card-world-rpg` 저장소의 `00_확정사항.md`. 이 문서는 프로토타입에 구현할 범위만 적는다.
> **v0.63.0** — 구현은 했지만 **플레이 검증 전**이라 체크하지 않았다. 플레이로 확인한 항목부터 체크한다.

## 0. 범위
- 판을 깔기 전, 월드의 튜토리얼 구간만.
- 판 · 출전 · 전투 · container · party · 장비는 아직 없다.

- [ ] 좌상단 점선 모서리(택)를 일정 길이 이상 당기면 오픈
- [ ] 일정 길이 미만에서 놓으면 되돌아감
- [ ] 탭만으로는 열리지 않음
- [ ] (v0.15.0) 택에 **화살표** — 당기는 방향(왼쪽 위 바깥)으로 움직이며 반복
  - (v0.16.1) 화살표를 택 모서리 쪽으로 붙임. 카드 밖으로는 몇 px만 나감

  - 안 열면 약 10초마다 재촉 한마디 ("모서리를 잡아당기라고!" 등)
  - 열리면 남은 재촉 대사는 버리고 갓 소개 대사로 넘어감
  - (v0.34.1) **찢는 순간 "꺼내줘" 말풍선이 바로 꺼짐** — 떠 있던 남은 시간과 상관없이. 그 뒤 콜렉터북 → 갓 소개 대사 순서
  - 판단: 찢는 중엔 재촉하지 않음
- [ ] (v0.28.4) **첫 package는 달그락거림** — 안에 갇힌 갓이 두드리듯 톡톡 두 번 흔들리고 쉬기를 2.2초마다 반복. 택을 당기기 시작하면 멈춤
- [ ] (v0.14.1) 좌상단 택이 **깜빡임** (노란 삼각형과 점선이 1.1초 주기로 밝아졌다 어두워짐) → 택을 끌어내면 열린다는 걸 알림
- [ ] 오픈되면 찢어지는 연출 → package 제거 → 내용물 생성
- [ ] package 몸통을 잡으면 그냥 이동
  - 판단: 당김 기준 길이 = 카드 너비의 0.9배
- [ ] (v0.13.0) 택을 당기면 **카드에서 택 조각이 떨어져 나오고, 카드의 그 모서리가 뜯겨 나간 모양**이 됨 (들쭉날쭉한 뜯긴 선)
- [ ] (v0.13.0) 택 조각은 마우스를 그대로 따라가지 않음 — **가까울 땐 카드에 붙어 버티고, 멀어질수록 떨어짐** (고무줄처럼)
- [ ] (v0.13.0) 당기는 동안 카드도 당기는 쪽으로 살짝 끌려오고 기울어짐
- [ ] (v0.13.0) 기준 길이 미만에서 놓으면 택 조각이 제자리로 붙고 카드 모양이 온전하게 돌아옴
- [ ] (v0.13.0) 뜯기면 택 조각은 당긴 방향으로 날아가 사라지고, 카드는 뜯긴 모서리를 가진 채 가운데가 들쭉날쭉 찢어져 둘로 갈라짐
  - 판단: 택 조각이 버티는 정도 = 당긴 거리 × (진행도^1.8). 진행도는 기준 길이 대비 비율
  - 판단: 3px 이상 당겨야 뜯기기 시작 (탭만으로는 모양이 안 바뀜)

- [ ] (v0.16.5) 원래 자리가 그사이 다른 카드로 막혔으면 **가장 가까운 빈자리**로 되돌아감
- [ ] (v0.16.5) 되돌아가는 카드는 다른 카드 위로 지나감 (맨 위 유지). 되돌아가는 0.24초 동안은 새로 잡지 않음

- [ ] 빈 자리에 놓으면 그 자리로 이동
- [ ] 드래그 중 아래 카드 하이라이트 (되는 조합은 노랑, 안 되는 조합은 회색)
- [ ] (v0.7.1) 대상 판정 범위 넓힘: 끌고 있는 카드와 **카드 넓이 15% 이상 겹친** 카드가 대상
  - 여러 장과 겹치면 겹친 넓이가 큰 쪽. 되는 조합이면 2배로 쳐서 우선
  - 겹친 카드가 없으면 예전처럼 포인터 아래 카드
  - 이유: 밀어내기가 켜져 있으면 대상을 살짝 빗나가 놓았을 때 합쳐지지 않고 밀려나는 일이 많았음
  - 판단: 재료끼리 조합은 어느 쪽을 올려도 같음
  - 판단: 도구 역할(돌·뗀석기·모닥불)은 조합해도 남음

## 5. 조합 (2장) — v0.2.0 태그 조합으로 개편
- [ ] 조합 한쪽은 카드 또는 태그
- [ ] 레벨 태그: `손질 lv1`, `손질 lv2`… 상위 레벨은 하위 레벨 조합도 됨, 반대는 안 됨
- [ ] 조합끼리 겹치면 제작자 알림 (화면 왼쪽 아래 빨간 상자 + 콘솔). 겹침은 해소해야 함
- [ ] 날것·익힘 태그가 한 카드에 같이 있으면 제작자 알림 (상극)
- [ ] 날것 카드에 익힌 결과가 없으면 제작자 알림

| 조합 | 결과 | 남는 쪽 |
|---|---|---|
| 돌 + 돌 | 뗀석기 | — |
| 돌 + 부싯돌 | 불씨 | 돌 |
| 손질 lv1 이상 + 뼈 | 골수 | 도구 |
| 손질 lv1 이상 + 조개 | 조갯살 | 도구 |
| 손질 lv2 이상 + 동물 사체 | 고기 + 가죽 | 도구 |
| 손질 lv2 이상 + 나뭇가지 | 뾰족한 막대 | 도구 |
| 마른 풀 + 나뭇가지 | 불쏘시개 | — |
| 마른 풀 + 마른 풀 | 풀 깔개 | — |
| 불씨 + 불쏘시개 | 모닥불 | — |
| 불 + 날것 | 익힌 것 (고기 → 구운 고기, 조갯살 → 구운 조개, 열매 → 구운 열매) | 불 |
| 불 + 불에 타는 | **재** (v0.4.0. 태운 카드가 재로 바뀜) | 불 |

  - 판단: 돌 = 손질 lv1, 뗀석기 = 손질 lv2
  - 판단: 겹침이 실제로 생기면 목록 순서상 앞 조합을 씀 (알림은 뜸)
  - 판단: 익힘은 카드 종류가 바뀌는 것으로 구현 (날것 태그 떨어지고 익힘 태그 붙은 카드)
  - 판단: 골수는 날것 태그 없음 (익힌 결과를 아직 안 만듦)
  - 판단: 예전 저장의 발견 조합 기록은 조합 id가 바뀌어 사라짐
