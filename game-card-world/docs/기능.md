# 기능 — 카드 월드 RPG

> 설계 원문은 `card-world-rpg` 저장소의 `00_확정사항.md`. 이 문서는 프로토타입에 구현할 범위만 적는다.
> **v0.15.0** — 구현은 했지만 **플레이 검증 전**이라 체크하지 않았다. 플레이로 확인한 항목부터 체크한다.

## 0. 범위
- 판을 깔기 전, 월드의 튜토리얼 구간만.
- 판 · 출전 · 전투 · container · party · 장비는 아직 없다.

---

## 1. 테이블
- [ ] 뷰포트 전체가 테이블
- [ ] 상태를 localStorage에 저장하고 다시 열면 복원
- [ ] "처음부터" 버튼 (시스템 메뉴라 카드 아님)

## 2. 오픈
- [ ] 시작은 테이블 가운데 `package` 한 장
- [ ] 좌상단 점선 모서리(택)를 일정 길이 이상 당기면 오픈
- [ ] 일정 길이 미만에서 놓으면 되돌아감
- [ ] 탭만으로는 열리지 않음
- [ ] (v0.15.0) 택에 **화살표** — 당기는 방향(왼쪽 위 바깥)으로 움직이며 반복
- [ ] (v0.15.0) **첫 package에서만** 안에 갇힌 갓이 말함: "…거기 누구 있어? 여기 좀 꺼내줘!" → "왼쪽 위 모서리! 그걸 잡아당겨!"
  - 말풍선이 package에 달림 (package가 말하는 것처럼 오해돼도 됨)
  - 안 열면 약 10초마다 재촉 한마디 ("모서리를 잡아당기라고!" 등)
  - 열리면 남은 재촉 대사는 버리고 갓 소개 대사로 넘어감
  - 판단: 찢는 중엔 재촉하지 않음
- [ ] (v0.14.1) 좌상단 택이 **깜빡임** (노란 삼각형과 점선이 1.1초 주기로 밝아졌다 어두워짐) → 택을 끌어내면 열린다는 걸 알림
- [ ] 오픈되면 찢어지는 연출 → package 제거 → 내용물 생성
- [ ] package 몸통을 잡으면 그냥 이동
  - 판단: 당김 기준 길이 = 카드 너비의 0.9배
- [ ] (v0.13.0) 택을 당기면 **카드에서 택 조각이 떨어져 나오고, 카드의 그 모서리가 뜯겨 나간 모양**이 됨 (들쭉날쭉한 뜯긴 선)
- [ ] (v0.13.0) 택 조각은 마우스를 그대로 따라가지 않음 — **가까울 땐 카드에 붙어 버티고, 멀어질수록 떨어짐** (고무줄처럼)
- [ ] (v0.13.0) 당기는 동안 카드도 당기는 쪽으로 살짝 끌려오고 기울어짐
- [ ] (v0.13.0) 기준 길이 미만에서 놓으면 택 조각이 제자리로 붙고 카드 모양이 온전하게 돌아옴
- [ ] (v0.13.0) 뜯기면 택 조각은 당긴 방향으로 날아가 사라지고, 카드는 뜯긴 모서리를 가진 채 가운데가 들쭉날쭉 찢어져 둘로 갈라짐
  - 판단: 택 조각이 버티는 정도 = 당긴 거리 × (진행도^1.8). 진행도는 기준 길이 대비 비율
  - 판단: 3px 이상 당겨야 뜯기기 시작 (탭만으로는 모양이 안 바뀜)

## 4. 쌓기
- [ ] 카드를 다른 카드 위에 드래그 드롭
- [ ] 결과는 대상 카드 + 올리는 카드 조합으로 정해짐
- [ ] 결과가 없으면 원래 자리로 되돌아감
- [ ] 빈 자리에 놓으면 그 자리로 이동
- [ ] 드래그 중 아래 카드 하이라이트 (되는 조합은 노랑, 안 되는 조합은 회색)
- [ ] (v0.7.1) 대상 판정 범위 넓힘: 끌고 있는 카드와 **카드 넓이 15% 이상 겹친** 카드가 대상
  - 여러 장과 겹치면 겹친 넓이가 큰 쪽. 되는 조합이면 2배로 쳐서 우선
  - 겹친 카드가 없으면 예전처럼 포인터 아래 카드
  - 이유: 밀어내기가 켜져 있으면 대상을 살짝 빗나가 놓았을 때 합쳐지지 않고 밀려나는 일이 많았음
  - 판단: 재료끼리 조합은 어느 쪽을 올려도 같음
  - 판단: 도구 역할(돌·뗀석기·모닥불)은 조합해도 남음

## 5. 조합 (2장) — v0.2.0 태그 조합으로 개편
- [ ] 조합 한쪽은 카드 또는 태그
- [ ] 레벨 태그: `손질 lv1`, `손질 lv2`… 상위 레벨은 하위 레벨 조합도 됨, 반대는 안 됨
- [ ] 조합끼리 겹치면 제작자 알림 (화면 왼쪽 아래 빨간 상자 + 콘솔). 겹침은 해소해야 함
- [ ] 날것·익힘 태그가 한 카드에 같이 있으면 제작자 알림 (상극)
- [ ] 날것 카드에 익힌 결과가 없으면 제작자 알림

| 조합 | 결과 | 남는 쪽 |
|---|---|---|
| 돌 + 돌 | 뗀석기 | — |
| 돌 + 부싯돌 | 불씨 | 돌 |
| 손질 lv1 이상 + 뼈 | 골수 | 도구 |
| 손질 lv1 이상 + 조개 | 조갯살 | 도구 |
| 손질 lv2 이상 + 동물 사체 | 고기 + 가죽 | 도구 |
| 손질 lv2 이상 + 나뭇가지 | 뾰족한 막대 | 도구 |
| 마른 풀 + 나뭇가지 | 불쏘시개 | — |
| 마른 풀 + 마른 풀 | 풀 깔개 | — |
| 불씨 + 불쏘시개 | 모닥불 | — |
| 불 + 날것 | 익힌 것 (고기 → 구운 고기, 조갯살 → 구운 조개, 열매 → 구운 열매) | 불 |
| 불 + 불에 타는 | **재** (v0.4.0. 태운 카드가 재로 바뀜) | 불 |

  - 판단: 돌 = 손질 lv1, 뗀석기 = 손질 lv2
  - 판단: 겹침이 실제로 생기면 목록 순서상 앞 조합을 씀 (알림은 뜸)
  - 판단: 익힘은 카드 종류가 바뀌는 것으로 구현 (날것 태그 떨어지고 익힘 태그 붙은 카드)
  - 판단: 골수는 날것 태그 없음 (익힌 결과를 아직 안 만듦)
  - 판단: 예전 저장의 발견 조합 기록은 조합 id가 바뀌어 사라짐

## 6. 제출 (`request`)
- [ ] 갓이 request 생성: "아무거나 3개만 줘봐"
- [ ] 보상(📦)이 미리 보임
- [ ] 제출한 카드가 request 위에 쌓임
- [ ] 정산 전에는 쌓인 카드를 끌어내 꺼낼 수 있음
- [ ] 다 쌓이면 한 번에 정산 → 제출 카드와 request 제거, 그 자리에 package 생성
- [ ] 캐릭터 · package · request는 제출 불가

## 7. 갓의 request 공급
- [ ] 첫 발견 전: request와 package가 테이블에 없으면 새 request (5개 받고 3개 내기 반복)
- [ ] 첫 발견 후: 테이블에서 가능한 조합이 하나도 없을 때만 새 request (고착 방지)
  - 판단: 제출할 카드가 3장 미만이면 요구 수를 그만큼 줄임
  - 판단: 제출할 카드가 0장이면 request 없이 package를 바로 줌 (고착 방지 예외)

### 7-1. 고착 점검 (v0.3.0에서 개편)
- [ ] request가 있는데 3개를 달성할 수 없으면 (쌓인 수 + 테이블의 제출 가능한 카드 수 < 3) 갓이 **package**를 줌
  - request는 그대로 둠. package를 열면 반드시 채울 수 있음
- [ ] request가 없고 제출 가능한 카드가 3장 미만이면 request 대신 package
- [ ] 첫 발견 뒤: 플레이어가 **이미 발견한 조합**으로 할 게 없을 때만 줌 (모르는 조합은 셈하지 않음)
- [ ] 갓은 **멘트를 다 끝낸 다음** request나 package를 줌
- [ ] 줄 게 정해지면 잠금 → 멘트 중 중복 지급 없음
- [ ] 줄 때 한 번 더 판단 → 멘트 동안 필요 없어졌으면 취소하고 다시 판단
- [ ] request·package가 **갓에게서 튀어나오는** 애니메이션
- [ ] 상태가 바뀔 때마다 점검 + 5초마다 한 번 더
  - 폐기: v0.1.1의 "쌓인 카드 돌려주고 요구 수를 줄여 다시 주기"
  - 판단: request 요구 수는 항상 3
  - ~~알려진 편법: 태워서 3장 밑으로 → package 다시 뽑기~~ → v0.4.0에서 태워도 재가 남아 카드 수가 줄지 않으므로 사라짐

## 8. 그 밖의 쌓기

## 13. 기사의 첫 퀘스트 (v0.7.0)
- [ ] 기사는 체력 0/10, **빈사** 상태로 등장
- [ ] 기사가 "..." 대사 후 request **뼛가루의 치유력** — 골수 2개, 보상 표시 "빈사 → 허기짐"
- [ ] 완료하면 기사 상태 **빈사 → 허기짐**, 대사 "배고파"
- [ ] 대사가 끝나면 request **밥이 보약** — 음식을 먹여 기사 체력을 가득 채우기 (조건형, 카드 제출 안 받음)
- [ ] 밥이 보약 완료 → 빈사 해결 (상태 태그 없어짐)
- [ ] (v0.11.1) **부러진 칼자루는 밥이 보약의 보상** — 칼자루가 먼저 나오고, 기사가 "고맙다", 대사가 끝나면 칼을 들어라 request
- [ ] 음식 회복: 날것 +1, 익힘 +2
- [ ] 골수 = **빈사 치유**. 빈사 캐릭터에 쌓으면 빈사 → 허기짐
- [ ] 빈사 상태엔 일반 음식이 안 먹힘 (되돌아감)
- [ ] 허기짐은 체력을 최대치까지 채우면 해결
- [ ] 상태 태그(빈사·허기짐)는 카드 태그 줄에 빨간 글씨로
- [ ] request에 진행 표시: `🥣 골수 0 / 2`, `체력 3 / 10`
- [ ] 기사 request는 기사에게서 튀어나오고 기사와 실선으로 연결
- [ ] 갓은 자기 request만 보고 판단 (기사 퀘스트는 갓의 고착 점검에 안 섞임)
- [ ] (v0.7.1) 열매는 **날것** → +1
  - (v0.8.0) 불 + 열매 → **구운 열매** (익힘 +2, 합칠 수 있음). 제작자 알림 해소
- [ ] (v0.7.1) 골수·음식은 기사에게 **직접 먹여도 되고 request에 내려놓아도 됨**
  - 뼛가루의 치유력이 떠 있으면 기사에게 직접 준 골수도 그 request에 들어감 (진행 동일)
  - 밥이 보약에 음식을 내려놓으면 기사에게 먹인 것과 같음
- [ ] (v0.7.1) 태그 추가: 기사 **과묵**, 갓 **수다쟁이**
  - 판단: 골수는 빈사가 아닌 캐릭터에겐 효과 없음 (회복량 0 → 되돌아감)
  - 판단: 빈사 치유를 써도 체력은 0 그대로. 체력은 밥이 보약에서 채움
  - 판단: 허기짐을 먼저 풀어버리면 밥이 보약은 나오자마자 완료됨
  - 판단: 대사가 끝난 뒤 request를 줌. 기사가 대사 중이면 기다림
  - 판단: 제출형 request는 요구 수만큼 차면 더 안 받음
  - 판단: 저장 키를 v2로 바꿔 예전 저장은 새로 시작 (밀어내기 설정은 유지)

## 14. request와 발주자 끌려다니기 (v0.8.0)
- [ ] request와 발주자(준 캐릭터)는 선으로 이어질 뿐 아니라 **일정 거리를 유지**함
- [ ] request를 끌면 발주자가 따라옴, 발주자를 끌면 request가 따라옴
- [ ] 가까워지면 밀리고 멀어지면 끌려감 (막대처럼 거리 고정)
- [ ] 밀어내기 체크와 상관없이 항상 작동
  - 판단: 거리는 카드 중심 사이 카드 너비의 1.6배 (밀어내기 최소 간격보다 길게 해서 서로 싸우지 않게)
  - 판단: 아무것도 안 끌 때 거리가 틀어지면 request 쪽이 천천히 제 거리로 돌아감 (발주자는 제자리)
  - 판단: 벽에 막히면 그만큼 거리가 짧아질 수 있음
  - 판단: 되돌아가기·정산·오픈 연출 중에는 잠시 멈춤
  - 알려진 어색함: request를 엉뚱한 카드에 놓아 되돌아가면, 끌려갔던 발주자는 옮겨진 자리에 남고 request가 다시 그쪽으로 끌려감

- [ ] (v0.8.0) 재료 이름 **조개껍데기 → 조개** (속이 빈 껍데기가 아니므로)

## 15. 장비 (v0.9.0)
- [ ] 기사는 **칼 · 방패** 두 칸을 장비할 수 있음
- [ ] 장비할 카드를 기사에게 드래그 드롭하면 장비
- [ ] 같은 칸에 다른 장비가 올라오면 **이전 장비는 방출** (기사 옆으로 튀어나옴)
- [ ] **부러진 칼자루**: 칼 칸, 공격력 +1
- [ ] 장비 카드엔 이름 아래 `⚔ +1` 표시
- [ ] 기사 카드엔 장비 칸(장비한 아이콘 / 빈 칸 이름)과 왼쪽 위 공격력 합계 `⚔ N` 표시
  - 판단: 어느 칸에 들어가는지는 태그로 정함 (부러진 칼자루 = 태그 "칼")
- [ ] 기사 **기본 공격력 0** (v0.9.1 확정). 왼쪽 위 표시는 기본 + 장비 합계
  - 판단: 빈사 상태에서도 장비 가능
- [ ] (v0.9.1) 기사 카드의 장비 아이콘을 **드래그해서 뺄 수 있음**
  - 빈 자리에 놓으면 테이블에 남음. 다른 캐릭터나 조합 대상에 놓으면 그 판정대로
  - 안 되는 곳에 놓으면 원래 칸으로 되돌아감
  - 판단: 방패 아이템은 아직 없음

## 16. 칼을 들어라 (v0.10.0)
- [ ] 밥이 보약 완료 뒤 기사가 request **칼을 들어라**를 줌
- [ ] 기사의 칼 칸에 **"칼" 태그 장비를 아무거나** 장비하면 완료 (부러진 칼자루가 아니어도 됨)
- [ ] request에 칼을 놓아도 기사에게 장비한 것과 같음
- [ ] 진행 표시: `칼 칸: 비어 있음` / `칼 칸: 🗡️`
  - 판단: 보상 없음 ("보상 없음"으로 표시)
  - 판단: 기사 대사 없이 바로 줌
  - 판단: 이미 칼을 들고 있으면 나오자마자 완료

## 17. 장소와 방문 (v0.11.0)
- [ ] 태그 이름 변경: **출전 가능 → 캐릭터** (기능은 같음)
- [ ] 모닥불에 **장소** 태그 추가
- [ ] 장소에 캐릭터를 드래그 드롭 = **방문**
- [ ] 방문한 캐릭터는 장소와 **선으로 연결** (주황색 선)
- [ ] request와 똑같이 **일정 거리를 유지하며 밀리고 끌려감**
- [ ] 연결이 이어져 있으면 사슬처럼 차례로 끌려감 (예: request 끌기 → 기사 → 모닥불)
  - 판단: 방문 효과는 아직 없음 (연결만)
  - 판단: 한 장소에 여러 캐릭터 방문 가능. 한 캐릭터는 한 장소만 — 다른 장소에 놓으면 옮겨감
  - 판단: 방문을 끝내는 방법은 아직 없음
  - 판단: 아무도 안 끌 때 거리가 틀어지면 방문자 쪽이 천천히 돌아감 (장소는 제자리)

## 18. 필드 상태 복사 (v0.12.0)
- [ ] 오른쪽 위 **📋 복사** 버튼 (시스템 메뉴, 카드 아님)
- [ ] 누르면 현재 필드 상태를 **JSON**으로 만들어 클립보드에 복사
- [ ] 담기는 것: 버전, 시각, 테이블·카드 크기, 밀어내기 설정, 카드 목록, 콜렉션 기록, 발견 조합, 진행 플래그
- [ ] 카드마다: id, 종류, 이름, 위치, 태그(조합 가능·상태 포함), 체력, 장비 칸, 방문 장소, package 내용
- [ ] request는 추가로: 제목, 퀘스트 id, 발주자, 진행 표시, 보상 표시, 쌓인 카드
  - 판단: 발주자·방문 장소는 `이름#id`로 적어서 사람이 읽기 쉽게
  - 판단: 클립보드 API가 막힌 환경이면 예전 복사 방식으로 재시도, 그래도 안 되면 콘솔에 출력

## 19. 대사 우선순위 (v0.14.0)
- [ ] 말풍선은 **한 번에 한 사람만**
- [ ] 한쪽 대화가 **다 끝나야** 다음 사람이 말함 (말하는 중엔 끼어들지 않음)
- [ ] 둘 다 할 말이 대기 중이면 우선순위 순: **갓 → 기사**
- [ ] 우선순위가 낮아도 다른 사람이 말하는 중이 아니면 바로 말함
  - 판단: 한 사람이 이어서 할 말이 줄 서 있으면 그 사람 대사를 끝까지 이어감
  - 판단: 대사 뒤에 이어지는 일(기사의 다음 request, 갓의 request·package 지급)은 그 사람 대사가 끝난 뒤 실행
  - 판단: 대사 한 줄 길이 = 최소 1.8초, 글자당 0.11초 (기사도 갓과 같게 맞춤)
