# 아이콘 프롬프트 기록

**확정 스타일 (2026-09-15)** — 이 문서의 프롬프트를 기준으로 새 아이콘을 만든다.
절차·옵션은 `아이콘_생성.md`.

## 공통 규칙

- 그림체 머리말은 스크립트가 자동으로 붙인다 (`tools/make_icon.py` 의 `STYLE_PREFIX`):

  ```
  Stylized fantasy RPG game icon, super deformed (SD) style with chunky exaggerated proportions,
  characters have an oversized head and a small compact body,
  hand-painted semi-realistic illustration style, bold readable shapes with clean dark outlines,
  painterly brush texture, soft cel-shaded volumes,
  bright warm lighting, rich vivid colors, grounded mature art direction for teen and adult players.
  ```

- 디테일은 빼지 않는다. 대상의 특징·재질·표정을 구체적으로 적는다
- 캐릭터
  - 시작: `close-up face portrait, the head fills most of the frame, of ...`
  - 얼굴 위주, 손은 나와도 됨. 전신·상반신 금지
  - 끝(흰 배경 꼬리말 앞)에 **강한 음영** (아래 `SHADE`) — 사용자 요청으로 음영을 더 강하게
  - `--no-suffix` + 끝에 **흰 배경 꼬리말** (아래 `WHITE`)
- 동물·사물: 스크립트 기본 꼬리말(검은 배경) 그대로
  - 고리·틈처럼 배경이 갇히는 모양이면 흰 배경 꼬리말로

`SHADE` (캐릭터 강한 음영):
```
strong shading with deep defined shadows, high contrast between light and shadow, dramatic directional key light from the upper left, shadowed side of the face clearly darker
```

`WHITE` (흰 배경 꼬리말):
```
single object, centered composition, isolated object, clean readable silhouette, simple solid #ffffff white background, no text, no additional objects
```

## 새 아이콘 추가할 때

1. 위 공통 규칙대로 프롬프트 작성 → 생성 → 64px 확인
2. 확정되면 이 문서 `카드 아이콘` 에 이름·옵션·seed·프롬프트 추가
3. 게임에 쓰려면 `index.html` 카드 정의에 `icon:true`
