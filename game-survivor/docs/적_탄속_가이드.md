# 적 탄속 가이드

> 적이 쏘는 곧은 탄(곡사 말고)의 빠르기를 정할 때 보는 기준. 값은 `index.html` 의 `ENEMY_TYPES[*].shot.spd` · `MOB_SHOT_MAX`.

## 규칙 (0.140.4, 사용자)

- **적 곧은 탄은 115 px/초를 넘지 않는다** — 잡몹 · 엘리트 · 보스 모두 (보스는 0.140.5 부터). 아무리 빨라도 이 탄속이 상한.
  - 처음 정한 계기: 월드 1 총잡이 좀비 탄 230 이 너무 빨라 절반(115)으로 내림 → 그 값을 상한으로.
  - 코드에서도 막아 둠: 모든 곧은 탄이 지나는 `fireShot` 에서 `Math.min(spd, MOB_SHOT_MAX)`. 표에 더 큰 값을 적어도 115 로 나간다.
- 엘리트도 잡몹과 같은 탄을 쓰므로 같은 상한.
- 물결(sine) · 나선(spin) 탄은 앞으로 나아가는 빠르기가 이 값이다 (옆으로 흔들리는 몫은 따로).
