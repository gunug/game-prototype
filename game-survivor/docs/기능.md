# 서바이버 (뱀서류)

몰려오는 적을 피하며 버티는 생존 게임. 공격은 자동, 플레이어는 움직이기만 한다.
레벨업마다 업그레이드 3종 중 하나를 고른다. 월드마다 정해진 시간을 버티면 클리어.

# 버전
- 형식 `주.부.수` — 기능 추가는 부(0.x.0), 수정 · 작은 변경은 수(0.0.x). 업데이트(커밋)마다 올린다
- 값은 `index.html` 의 `VERSION` 한 곳. 커밋 메시지도 `game-survivor vX.Y.Z: …`
- [x] 화면 우하단에 `vX.Y.Z` 표시. 모든 창(레벨업 · 일시정지 · 게임오버) 위에 뜬다 (z-index 최대), 누르기는 막지 않음

# 월드
- [x] 게임을 열면 **월드 선택 화면**부터 보인다. 눌러서(또는 숫자 키) 고른다
  - 칸은 3개. 아직 없는 월드는 `준비 중` 으로 잠겨 있다
  - 월드마다 이름 · 땅 설명 · 시간 · 최고 기록 · 클리어 표시
- [x] 한 월드는 정해진 시간을 버티면 클리어 (무한 생존은 없앰)
  - 월드1: **10분** — 레벨업 약 20번이면 빌드가 갖춰지고, 끝 무렵 적 체력 ×5.5 · 방어 +15 로 지금 수치와 맞는다 (5 · 10 · 15분 중 추천해 고름)
  - 표는 `index.html` 의 `WORLDS`. 머리말 시간은 `지난 시간 / 월드 시간`
- [x] 클리어 화면: 나가기(월드 선택) · 다시하기(R) · 다음 월드(N)
  - 다음 월드가 아직 없으면 `다음 월드 (준비 중)` 으로 막혀 있다
- [x] 게임오버 화면: 나가기 · 다시하기(R). 일시정지 화면에도 나가기
- [x] 기록은 월드별로 저장 (`survivor.w1` — 최고 생존 · 최고 처치 · 클리어 여부)

  - 레벨업 창이 뜨는 동안 게임은 멈춘다. 창이 뜬 뒤 0.35초는 키 입력을 막는다

- [x] 모바일 터치 — 동적 조이스틱

  - 반지름 밖으로 더 끌면 중심이 손가락을 따라 옮겨온다 → 반대로 끌면 바로 방향이 바뀐다
  - 손가락 하나만 받는다. 마우스 드래그로도 된다 (PC 시험용). 키보드가 눌려 있으면 키보드가 먼저
  - 누르는 동안 중심 원과 손잡이를 반투명하게 그린다
- [x] 모바일 화면
  - 오른쪽 위 `II` 버튼으로 일시정지, 일시정지 화면을 누르면 계속
  - 레벨업 카드는 눌러서 고른다. 창이 뜬 뒤 0.35초는 탭도 막는다 (끌던 손가락에 잘못 눌리지 않게)
  - 확대 · 스크롤 · 길게 눌러 선택 · 메뉴를 막는다. 폭 700px 아래면 레벨업 카드를 세로로 쌓아 줄이고, 키보드 안내를 숨긴다
  - 터치 기기면 시작 · 레벨업 · 일시정지 안내 글이 터치용으로 바뀐다
- [x] 창 밖을 누르면(포커스 아웃) 저절로 일시정지, 돌아오면 저절로 다시 감

# 업그레이드
## 기본
- [x] 공격력 +20%
- [x] 공격속도 (쿨다운 ×0.85)
- [x] 사거리 +15%
- [x] 체력 최대치 +25 (그만큼 회복)
- [x] 방어력 +2 (받는 피해에서 뺌, 최소 1)

## 확장
- [x] 투사체 갯수 +1 — 부채꼴로 퍼져 나감
- [x] 연속공격 +1 — 한 번 쏠 때 0.1초 간격으로 한 번 더
- [x] 넉백 — 맞은 적이 총알이 날던 방향으로 밀려난다 (Lv1 약 40px, 레벨당 +25px)
  - 처음엔 도탄(다음 적으로 튕김)으로 만들었다가 넉백으로 바꿈 (2026-11-11)
  - 큰 적은 덜 밀린다 (반지름 15 기준, 골렘은 약 0.6배). 밀린 속도는 매 초 e^-8 로 잦아든다
- [x] 스플래시 — 맞은 지점 둘레에 피해 (Lv1: 반경 45 · 피해 40%, 레벨당 반경 +12 · 피해 +15%)
- 확장은 레벨 3 부터 후보에 섞인다. 각 업그레이드 최대 레벨이 있다 (기본 무제한, 확장 5)

# 적
- 생성 속도: 초당 1.2 + 0.06×초 마리, 1분마다 둘레에서 한 무리 (20 + 초/6). 최대 500
- 너무 멀어진 적은 화면 둘레로 다시 옮긴다
- [x] 화면 밖 둘레에서 생겨 플레이어를 쫓는다
- [x] 시간이 갈수록 체력이 늘고 (분당 +45%), 나오는 수도 늘어난다
- [x] 종류: 슬라임(보통) · 박쥐(빠르고 약함, 1분부터) · 골렘(느리고 단단함, 3분부터)
- [x] 닿으면 피해. 맞은 뒤 0.5초 무적
- [x] 방어력: 받는 피해 = 공격력 - 방어력. 방어가 더 높아도 **최소 1** 은 들어간다 (플레이어 · 적 같은 규칙)
  - 적 기본 방어: 슬라임 0 · 박쥐 0 · 골렘 3. 시간이 갈수록 분당 +1.5
  - 체력 · 방어는 적이 **생길 때** 그 시각 기준으로 정해진다. 이미 나와 있는 적은 그대로
  - 스플래시처럼 약한 피해는 방어에 많이 깎인다. 반 넘게 막힌 숫자는 회색으로 뜬다
- [x] 죽으면 경험치 보석을 떨군다. 가까이 가면 끌려온다
