# 서바이버 (뱀서류)

몰려오는 적을 피하며 버티는 생존 게임. 공격은 자동, 플레이어는 움직이기만 한다.
레벨업마다 업그레이드 3종 중 하나를 고른다. 월드마다 정해진 시간 끝에 나오는 최종 보스를 잡으면 클리어.
배경은 **현대물** — 좀비가 들끓는 도심, 플레이어는 권총을 든 생존자 (0.8.0 부터. 그 전은 판타지).

# 대전제
- **모든 UI 는 방사형 메뉴로도 고를 수 있어야 한다** (2026-11-11 확정). 버튼을 바로 눌러도 되지만, 끌면 둥근 메뉴가 열리고 그 안에 그 창의 선택지가 모두 있어야 한다
  - 새 창 · 새 버튼을 만들면 `rmItems` 에 칸을 더하고, 그 창 id 를 방사형 메뉴 `pointerdown` 목록에 넣는다
  - 규칙: 누른 곳이 중심(끌려가지 않음) · 가운데서 떼면 취소 · 칸에서 떼면 고름
  - **방사형 메뉴는 두 가지** (2026-11-11 확정)
    - **선택형** — 화면에 놓인 방향과 같은 방향으로. 월드 · 캐릭터 · 무기 · 업그레이드 카드 (왼→오른 그대로). 월드 선택은 위 = 월드 · 아래 = 캐릭터 (화면에서도 월드가 위, 캐릭터가 아래)
    - **확인형** — **긍정 · 확인은 위, 부정 · 취소 · 나가기 · 뒤로는 아래.** 캐릭터 선택 (위 캐릭터 · 아래 뒤로) · 쓰러졌다 (위 다시하기 · 아래 나가기) · 클리어 (위 다시하기 · 다음 월드 · 아래 나가기) · 일시정지 (위 계속 · 아래 나가기) · 무기 선택의 뒤로
    - 부정 버튼엔 HTML 에 `data-neg` 를 단다 → 확인형 메뉴에서 저절로 아래로 감
    - 한 창에 둘이 섞이면 선택지는 위(선택형 순서), 부정 · 취소는 아래. 아래가 빌 땐 나중에 리롤 같은 보조를 놓을 자리
  - 키보드 · 게임패드 커서(테두리)로도 고를 수 있어야 한다 (`NAV_ROWS`)

# 버전
- 형식 `주.부.수` — 기능 추가는 부(0.x.0), 수정 · 작은 변경은 수(0.0.x). 업데이트(커밋)마다 올린다
- 값은 `index.html` 의 `VERSION` 한 곳. 커밋 메시지도 `game-survivor vX.Y.Z: …`
