# 사거리 가이드

> 무기 사거리를 정할 때 보는 기준. 값은 `index.html` 의 `WEAPONS[*].range` · `RANGE_CAP`.

## 1. 화면 크기 기준

사거리는 **주인공에서 화면 끝까지 거리**와 견주어 정한다. 화면 밖 적을 쏘면 무엇을 맞히는지 안 보인다.

| 화면 | 가로 반 | 세로 반 | 비고 |
|---|---|---|---|
| 폰 세로 (375×812) | 약 187 | 약 406 | **기준 화면** — 가로가 가장 좁다 |
| 태블릿 (768×1024) | 384 | 512 | |
| PC (1556×1250 예) | 약 780 | 약 625 | |

- 적은 화면 대각선 반 + 60px 밖에서 생긴다 → 사거리 안으로 들어오기까지 시간이 있다.
- 주인공 둘레 점선 원 = 가진 무기 중 가장 긴 사거리.

## 2. 거리 단계

| 단계 | 시작 사거리 | 뜻 |
|---|---|---|
| 근거리 | ~130 | 적이 꽤 다가와야 쏜다 |
| 중거리 | ~145 | 기준 무기 (권총) |
| 원거리 | 215 | 폰 가로 끝을 조금 넘는다. 다가오기 전에 쏜다 |

## 3. 지금 무기 (0.31.2)

| 무기 | 시작 | 최종 (시작 × 1.4) | 단계 |
|---|---|---|---|
| 굴곡 레이저 | 120 | 168 | 근거리 — 연쇄 · 다단히트로 보상 |
| 기관총 | 130 | 182 | 근거리 — 연사 · 발사각 넓음 |
| 권총 | 145 | 203 | 중거리 — 기준 무기 |
| 저격총 | **215** | **301** | 원거리 — 가장 먼 적을 노림 |

## 4. 규칙

1. **최종 사거리의 기준은 저격총 최종 ≈ 300.** (0.31.1 에서 저격총 *시작* 사거리 300 이 너무 길었다 — 그 값이 다 올린 뒤의 끝이 되게 모든 무기를 ÷1.4)
2. **저격총이 늘 가장 길다.** 시작도, 최종도. 새 무기의 시작 사거리는 저격총 시작(215)보다 길게 하지 않는다.
3. **최종 = 무기마다 시작 × `RANGE_CAP`(1.4).** 모든 무기가 같은 배율이라 다 올려도 순서가 바뀌지 않는다.
4. 사거리 업그레이드: +15% 씩, **최대 3번** (1.15 → 1.32 → 1.52 지만 1.4 에서 멈춤). 세 번이면 최종.
5. 사거리를 길게 주는 무기는 다른 쪽(피해 · 연사 · 발사각)에서 덜 준다. 짧은 무기는 연쇄 · 확산 · 다단히트 같은 보상을 준다.
6. 사거리에 기대는 다른 값도 같이 본다: 레이저 연쇄 거리 `hop` 은 사거리 비율로 늘고, 총알은 사거리 × 1.25 까지 날아간다. 총알 연쇄 거리 `CHAIN_HOP` 170 은 고정.
