# UI
- [x] '초기화' 버튼 — 저장된 상태를 지우고 처음 나열 배치로 되돌린다
- [x] 현재 상태를 LocalStorage에 저장하고, 다시 열면 그대로 복원한다
- [x] 배출되어 있는 칩은 저장 대상이 아니다. 새로고침 하면 삭제된다.
- [x] 뷰포트 전체가 게임 화면 (별도 페이지 UI 없음)
- [x] 뷰포트 크기에 따라 블럭 크기와 배치를 바꾼다 (모바일 대응)
- [x] 화면에는 기본적으로 블럭이 존재하지 않는다

- [x] 구현된 블럭이 하나씩 나열
- [x] 1/2크기로 표시
- [x] 서랍에서 드래그 하면 본래 사이즈의 블록 생성
- [x] 블록을 서랍에 드래그 드롭하면 제거

- [x] 블럭의 depth 순서
  - [x] 행동중인 블럭
  - [x] 반응중인 블럭
  - [x] 하단
  - [x] 우측
  - [x] 상단
  - [x] 좌측

# 블럭(block)
- [x] 블럭은 1:1 비율
- [x] 블럭은 4방향에 다른 블럭을 붙일 수 있다.
- [x] 블럭은 4방향에 각각 하나씩만 붙을 수 있다. 이미 붙어있는 블럭이 있다면 추가 붙기 금지.
- [x] 블럭을 드래그 하여 때어낼 수 있다.
- [ ] 블럭은 다른 블럭에 의해서 밀려남. 연결된 블럭은 통째로 밀림

## 종류
### builder
### crefter
### assembler
### pusher
### timer
### loader
### unloader
### clicker
  - [x] 사용자가 클릭하면 반응한다.
  - [x] 반응시 행동을 생성한다.
### void
  - [x] 행동을 받으면 반응한다.
  - [x] 반응시 행동을 전달한다.
### beeper (구 deeper)
  - [x] 음표 이모티콘
  - [x] 행동을 받으면 반응한다
  - [x] 반응시 deep 소리가 난다.
  - [x] 콤보박스 형태로 음계를 선택할수 있음 (66건반 피아노 전음계)
  - [x] 음역은 C2~F7 (MIDI 36~101), 기본값 C4
### drummer
  - [x] 드럼 이모티콘
  - [x] 행동을 받으면 반응한다
  - [x] 반응시 drum 소리가 난다.
  - [x] 콤보박스 형태로 킥, 스네어, 하이햇, 크래시 심벌, 탐, 플로어탐 등을 선택할 수 있음
### beater
  - [ ] beeper와 거의 동일
  - [ ] 킥, 스네어, 하이햇, 크래시 심벌, 탐, 플로어탐 등을 등록할수 있음 (등록방법 미정)
### delay
  - [ ] 행동을 받으면 카운트를 시작한다
  - [ ] 카운트가 모두 끝나면 반응한다
  - [ ] 반응하면 행동을 전달한다.
### mover
  - [x] 드래그시 이동시 인접블럭 및 관련블럭이 모두 이동한다.
  - [x] 더블클릭 후 드래그시 인접블럭 무시. 혼자이동한다.
### maker
  - [x] 행동을 받으면 반응한다
  - [x] 반응시 칩을 생산한다.
### counter
  - [x] 행동을 받으면 카운트가 올라간다.
  - [x] 더이상 칩을 등록하거나 받지 않는다.
  - [x] 카운트리미트를 올리고 내릴 버튼이 있다. 기본카운트는 1이다.
  - [x] 카운트가 카운트 리미트에 도달하면 0으로 초기화 되고 반응한다.
  - [x] 반응하면 행동을 전달한다.
  - [x] 리미트 범위는 1~99. 리미트를 현재 카운트보다 낮추면 카운트는 0으로 리셋된다.
### seller
  - [ ] 자원을 받으면 저장한다.
  - [ ] 행동을 받으면 반응한다.
  - [ ] 반응시 자원을 판매한다.
### collector
  - [x] 칩을 받으면 등록한다.
  - [x] 행동을 받으면 반응한다.
  - [x] 반응시 등록된것과 같은 유형의 칩을 약간 끌어당긴다.
  - [x] 아무것도 등록되지 않았다면 아무것도 끌어당기지 않는다.
  - [ ] 끌어 당겨진 칩중에 블록에 닿은 칩을 저장한다. (드래그 도중 닿거나 등록된것과 다른 유형의 칩을 저장하지 않는다)
### adder
  - [x] + 이모티콘
  - [x] 칩을 드래그 드랍으로 받으면 등록한다.
  - [x] 칩을 배송 받으면 등록한다.
  - [x] 행동을 받으면 반응한다.
  - [x] 반응시 등록된 칩을 모두 더하기 한 칩을 생산한다.
  - [x] 반응시 더하기 할수 없는 칩은 각각의 칩을 배출한다.
  - [x] 굴러 닿기만 한 칩은 등록되지 않는다 (드래그 드롭 / 배송으로만 받음)

# 더하기(add)
- [x] 같은 유형의 칩은 더하기 된다 칩에 표시된 수량이 합산된다.
- [x] 다른 유형의 칩은 더하기 되지 않는다.

# 등록(register)
- [x] 칩을 드래그 드롭하면 블록에 칩이 기록됨
- [x] 블록의 특수 기능의 변수로 사용됨
- [x] 등록된 칩은 작게 블록의 상단에 표시됨. overflow hidden 상태로 수량이 많을시 가로 스크롤
- [x] 칩이 근처에 있다고 해서 드래그 드롭 없이 자동으로 등록되지 않음.

# 저장(store)
- [x] 대상 칩이 사라지고 블록에 칩에대한 카운트가 증가함

# 인접(attach)
- [x] 블럭을 드래그 드롭시 가까이에 있는 블럭이 각블럭의 4면에 연결됨
- [ ] 인접한 블럭 사이에는 링크 아이콘이 표시됨
- [ ] 인접이 해제되면 링크 아이콘이 표시되지 않음

# 연결(connect)
- [x] 인접한 블럭은 연결되고 행동과 자원을 주고 받을 수 있음

---

# 생산(generate)
- [x] 새로운 칩을 생성함
- [x] 인접한 칩을 받는 블럭이 있을경우 배송함
- [x] 인접한 칩을 받는 블럭이 없을경우 배출함

## 생성(create)
- [x] 새로운 고유 uid를 부여한 새로운 객체를 만듬

## 배송(delivery)
- [x] 칩을 인접한 블럭으로 바로 등록
- [x] 시각적으로는 칩이 생성되고 인접 블럭으로 이동하고 등록됨
- [x] 여러개의 인접 블록이 있을 경우. 상,우,하,좌 순으로 로테이션 되면서 배송됨

## 배출(eject)
- [x] 칩에대한 카운트가 감소하고 대상 칩이 생성됨
- [x] 배출시 약간의 물리력을 가지고 팅겨나가는 모습
- [ ] 배출시 칩은 블럭의 상단 60도 각도로 랜덤하게 방향성을 갖음


---

# 행동(action)
- [x] 행동은 인접한 블럭에 기본딜레이 후에 전달된다.
- [x] 행동은 고유 uid가 있다.

## 전달(transfer)
- [x] 본래 고유 uid를 그대로 전달

## 반응(reaction)
- [x] 행동을 전달받은 블럭이 반응
- [x] 이미 한 행동에 의해 반응한 적이 있다면 같은 uid의 행동이 여러번 다시 전달 되어도 중복 반응하지 않는다.
- [x] 반응을 했다는 의미로 블럭이 한번 깜빡인다.
- [x] 반응이 없는 블럭은 행동을 받아도 깜빡이지 않는다.

# 칩(chip)
- [x] 칩은 동그란 프레임. 블럭의 1/3크기.
- [x] 칩은 드래그 가능
- [x] 칩에는 숫자가 표기되어있음 기본값은 1임

## 자원(resource)
- [ ] 칩의 부분집합

# 핵심
- [ ] 조립과 분해가 쉬어야함 (이게 공장형 게임들이 가지는 스트레스 요인)

# 언락과 게임의 경험
## 수공업 - 클리커 게임
- [ ] 버튼을 일일히 눌러서 자원을 얻어야한다
- [ ] 자원을 일일히 드래그 해서 팔아야한다
- [ ] 각 공정의 클릭 버튼을 눌러서 한 공정씩 진행해야한다
## 자동 - 공장 컨베이어 게임
- [ ] 부분된 공정을 하나의 클릭으로 합친다.
- [ ] 자동화 블럭을 구성
- [ ] 병목을 해결
- [ ] 효율을 높임
## 설계 - 퍼즐게임
- [ ] 특수한 물질을 생산하기 위해 미션을 클리어 해야한다
- [ ] 특수한 블럭을 언락하기 위해 미션을 클리어 해야한다

# 디버깅
- [x] 드래그 도중 마우스가 밖으로 나간뒤 mouseup을 하면 드래그가 해제되지 않는 버그. mouseup을 하면 마우스 커서가 블럭위가 아니라도 드래그 해제가 되어야 한다. 
- [x] 드래그를 빨리하여 마우스가 블럭을 벗어나면 블럭이 더이상 따라오지 않는다. 블럭에서 아웃되어도 드롭전까지는 블럭이 따라와야한다.
- [x] 블럭을 드롭할때 인접 블럭 연결은 1개가 아닌 근접대상 모두 한꺼번에 연결
