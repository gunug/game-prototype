# 블럭
## 설명
* 블럭은 1:1 비율
* 드래그 가능
* 블럭은 4방향에 다른 블럭을 붙일 수 있다.
* 한번 붙은 블럭은 같이 이동한다.
* 더블클릭하면 블럭이 분해 된다. (무게 중심을 기준으로 바깥 방향으로 물리적 움직임)
* 각 블럭은 

## 종류
* pusher
* timer
* loader
* unloader
* clicker
* deeper
  * action을 받으면 deep 소리가남
* delay
  * action을 받으면 카운트를함
  * 카운트가 끝나면 action을 내놓음
