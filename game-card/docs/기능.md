# 블럭(block)
- [x] 블럭은 1:1 비율
- [x] 블럭은 4방향에 다른 블럭을 붙일 수 있다.
- [x] 블럭은 4방향에 각각 하나씩만 붙을 수 있다. 이미 붙어있는 블럭이 있다면 추가 붙기 금지.
- [x] 블럭을 드래그 하여 때어낼 수 있다.

## 종류
### builder
### crefter
### assembler
### pusher
### timer
### loader
### unloader
### clicker
  - [x] 사용자가 클릭하면 반응한다.
  - [x] 반응시 행동을 생성한다.
### deeper
  - [x] 행동을 받으면 반응한다
  - [x] 반응시 deep 소리가 난다.
### delay
  - [ ] 행동을 받으면 카운트를 시작한다
  - [ ] 카운트가 모두 끝나면 반응한다
  - [ ] 반응하면 행동을 전달한다.
### mover
  - [x] 드래그시 이동시 인접블럭 및 관련블럭이 모두 이동한다.
  - [x] 더블클릭 후 드래그시 인접블럭 무시. 혼자이동한다.
### maker
  - [x] 행동을 받으면 반응한다
  - [x] 반응시 칩을 생성한다.
  - [x] 생성된 칩은 약간의 물리력을 가지고 팅겨나간다.
### counter
  - [ ] 행동을 받으면 카운트가 올라간다.
  - [ ] 카운트가 일정 숫자에 다다르면 반응한다.
  - [ ] 반응하면 행동을 전달한다.
### seller
  - [ ] 자원을 받으면 저장한다.
  - [ ] 행동을 받으면 반응한다.
  - [ ] 반응시 자원을 판매한다.
### collector
  - [x] 칩을 받으면 등록한다.
  - [x] 행동을 받으면 반응한다.
  - [x] 반응시 등록된 칩을 약간 끌어당긴다.
  - [x] 블록에 닿은 칩을 저장한다.

# 기본딜레이
- [x] 행동이 인접 블럭에 전달되기 위해 소요되는 기본값
- [x] 0.1초

# 등록(register)
- [ ] 칩을 당기면 블록에 칩이 기록됨
- [ ] 블록의 특수 기능의 변수로 사용됨

# 저장(store)
- [ ] 대상 칩이 사라지고 블록에 칩에대한 카운트가 증가함

# 배출(eject)
- [ ] 칩에대한 카운트가 감소하고 대상 칩이 생성됨

# 인접(attach)
- [ ] 블럭을 드래그 드롭시 가까이에 있는 블럭이 각블럭의 4면에 연결됨
- [ ] 인접한 블럭 사이에는 링크 아이콘이 표시됨
- [ ] 인접이 해제되면 링크 아이콘이 표시되지 않음

# 연결(connect)
- [ ] 인접한 블럭은 연결되고 행동과 자원을 주고 받을 수 있음

# 생성(create)
- [x] 새로운 고유 uid를 부여한 새로운 객체를 만듬

# 전달(transfer)
- [x] 본래 고유 uid를 그대로 전달

# 행동(action)
- [x] 행동은 인접한 블럭에 기본딜레이 후에 전달된다.
- [x] 행동은 고유 uid가 있다.

# 반응(reaction)
- [x] 행동을 전달받은 블럭이 반응
- [x] 이미 한 행동에 의해 반응한 적이 있다면 같은 uid의 행동이 여러번 다시 전달 되어도 중복 반응하지 않는다.
- [x] 반응을 했다는 의미로 블럭이 한번 깜빡인다.
- [x] 반응이 없는 블럭은 행동을 받아도 깜빡이지 않는다.

# 칩(chip)
- [x] 칩은 동그란 프레임. 블럭의 1/3크기.
- [x] 칩은 드래그 가능
- [x] 칩에는 숫자가 표기되어있음 기본값은 1임
## 자원(resource)
- [ ] 칩의 부분집합

# 핵심
- [ ] 조립과 분해가 쉬어야함 (이게 공장형 게임들이 가지는 스트레스 요인)

# 언락과 게임의 경험
## 수공업 - 클리커 게임
- [ ] 버튼을 일일히 눌러서 자원을 얻어야한다
- [ ] 자원을 일일히 드래그 해서 팔아야한다
## 자동 - 공장 컨베이어 게임
- [ ] 자동화 블럭을 구성
- [ ] 병목을 해결
- [ ] 효율을 높임
## 설계 - 퍼즐게임
- [ ] 특수한 물질을 생산하기 위해 미션을 클리어 해야한다
- [ ] 특수한 블럭을 언락하기 위해 미션을 클리어 해야한다

# 디버깅
- [x] 드래그 도중 마우스가 밖으로 나간뒤 mouseup을 하면 드래그가 해제되지 않는 버그. mouseup을 하면 마우스 커서가 블럭위가 아니라도 드래그 해제가 되어야 한다. 
- [x] 드래그를 빨리하여 마우스가 블럭을 벗어나면 블럭이 더이상 따라오지 않는다. 블럭에서 아웃되어도 드롭전까지는 블럭이 따라와야한다.
- [x] 블럭을 드롭할때 인접 블럭 연결은 1개가 아닌 근접대상 모두 한꺼번에 연결
