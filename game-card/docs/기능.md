# 블럭
## 설명
* 블럭은 1:1 비율
* 드래그 가능
* 블럭은 4방향에 다른 블럭을 붙일 수 있다.
* 한번 붙은 블럭은 같이 이동한다.
* 더블클릭하면 블럭이 분해 된다. (무게 중심을 기준으로 바깥 방향으로 물리적 움직임)
* 각 블럭은 

## 종류
### pusher
### timer
### loader
### unloader
### clicker
  * 사용자가 클릭하면 반응한다.
  * 반응시 행동을 생성한다.
### deeper
  * 행동을 받으면 반응한다
  * 반응시 deep 소리가 난다.
### delay
  * 행동을 받으면 카운트를 시작한다
  * 카운트가 모두 끝나면 반응한다
  * 반응하면 행동을 전달한다.

# 기본딜레이
* 행동이 인접 블럭에 전달되기 위해 소요되는 기본값
* 0.1초

# 생성(create)
* 새로운 고유 uid를 생성

# 전달(Send)
* 본래 고유 uid를 그대로 전달

# 행동(action)
* 행동은 인접한 블럭에 기본딜레이 후에 전달된다.
* 행동은 고유 uid가 있다.

# 반응(reaction)
* 행동을 전달받은 블럭이 반응
* 이미 한 행동에 의해 반응한 적이 있다면 같은 uid의 행동이 여러번 다시 전달 되어도 중복 반응하지 않는다.
* 반응을 했다는 의미로 블럭이 한번 깜빡인다.
* 반응이 없는 블럭은 행동을 받아도 깜빡이지 않는다.
