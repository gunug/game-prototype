# 시스템
# UI
* 화면에 5장의 블럭

---

# 블럭
## 설명
* 블럭은 1:1 비율
* 드래그 가능
* 블럭은 4방향에 다른 블럭을 붙일 수 있다.
* 한번 붙은 블럭은 같이 이동한다.
* 더블클릭하면 블럭이 분해 된다. (무게 중심을 기준으로 바깥 방향으로 물리적 움직임)

## 종류
* pusher
* timer
* loader
* unloader
* clicker

---

# 자원
* 자원은 동그란 프레임. 블럭의 1/3크기.
* cliker는 클릭할때 마다 action을 배출한다.

## 종류
* action

---

# 핵심
* 조립과 분해가 쉬어야함 (이게 공장형 게임들이 가지는 스트레스 요인)

# 언락과 게임의 경험
## 수공업 - 클리커 게임
* 버튼을 일일히 눌러서 자원을 얻어야한다
## 자동 - 공장 컨베이어 게임
* 자동화 블럭을 구성
* 병목을 해결
* 효율을 높임
