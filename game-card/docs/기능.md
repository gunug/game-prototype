# 블럭(block)
- [x] 블럭은 1:1 비율
- [x] 블럭은 4방향에 다른 블럭을 붙일 수 있다.
- [ ] 블럭은 4방향에 각각 하나씩만 붙을 수 있다. 이미 붙어있는 블럭이 있다면 추가 붙기 금지.
- [x] 블럭을 드래그 하여 때어낼 수 있다.

## 종류
### pusher
### timer
### loader
### unloader
### clicker
  - [x] 사용자가 클릭하면 반응한다.
  - [x] 반응시 행동을 생성한다.
### deeper
  - [x] 행동을 받으면 반응한다
  - [x] 반응시 deep 소리가 난다.
### delay
  - [ ] 행동을 받으면 카운트를 시작한다
  - [ ] 카운트가 모두 끝나면 반응한다
  - [ ] 반응하면 행동을 전달한다.
### mover
  - [x] 드래그시 이동시 인접블럭 및 관련블럭이 모두 이동한다.
  - [x] 더블클릭 후 드래그시 인접블럭 무시. 혼자이동한다.

# 기본딜레이
- [x] 행동이 인접 블럭에 전달되기 위해 소요되는 기본값
- [x] 0.1초

# 인접(attach)
- [ ] 블럭을 드래그 드롭시 가까이에 있는 블럭이 각블럭의 4면에 연결됨

# 연결(connect)
- [ ] 인접한 블럭은 연결되고 행동과 자원을 주고 받을 수 있음

# 생성(create)
- [x] 새로운 고유 uid를 생성

# 전달(Send)
- [x] 본래 고유 uid를 그대로 전달

# 행동(action)
- [x] 행동은 인접한 블럭에 기본딜레이 후에 전달된다.
- [x] 행동은 고유 uid가 있다.

# 반응(reaction)
- [x] 행동을 전달받은 블럭이 반응
- [x] 이미 한 행동에 의해 반응한 적이 있다면 같은 uid의 행동이 여러번 다시 전달 되어도 중복 반응하지 않는다.
- [x] 반응을 했다는 의미로 블럭이 한번 깜빡인다.
- [x] 반응이 없는 블럭은 행동을 받아도 깜빡이지 않는다.

# 자원(resource)
- [ ] 자원은 동그란 프레임. 블럭의 1/3크기.
